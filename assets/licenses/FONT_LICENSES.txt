NIARIM に同梱しているフォントの著作権表示とライセンス
========================================================

このファイルは、SIL Open Font License 1.1（OFL）で配布されている
フォントを本アプリへ同梱・再配布するにあたり、OFL第2条が求める
「著作権表示とライセンス本文の同梱」を満たすためのものです。

各フォントの著作権表示・ライセンス表記は、同梱しているフォント
ファイル自身の name テーブル（nameID 0＝著作権、13＝ライセンス、
14＝ライセンスURL）から抜き出した原文をそのまま記載しています。

              Version 1.1. This license is available with a FAQ at:
              https://openfontlicense.org
License URL : https://openfontlicense.org

Copyright   : Copyright 2020 The Dela Gothic Project Authors
              (https://github.com/syakuzen/DelaGothic),flopdesign.com
License     : SIL Open Font License 1.1
              ※このファイルの name テーブル nameID 13 には OFL の記載が無く、
                フォント編集ソフトが書き込んだと思われる管理用の文字列
                （Cr:... Mo:...）が入っている。配布元の表記に基づき OFL 1.1
                として扱っているが、公開前に配布元同梱の OFL.txt を入手して
                本ファイルへ差し替えること（要確認事項）。
License URL : https://openfontlicense.org
