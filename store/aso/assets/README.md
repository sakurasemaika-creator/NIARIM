# Store listing images

Images for the Google Play listing, made from the app's own brand assets
(`assets/icon/app_icon.png`, `assets/logo/app_logo.svg`, `assets/logo/title_logo.svg`,
the Kuramubon font, and Noto Sans KR/SC Black subsets for Korean and Chinese).

| File                           | Play Console field                   | Size                |
| ------------------------------ | ------------------------------------ | ------------------- |
| `play-icon-512.png`            | App icon                             | 512×512, 32-bit PNG |
| `feature-graphic/<locale>.png` | Feature graphic (per store language) | 1024×500            |

Taglines: ja-JP「描いて、動かす。」, en-US "Draw it. Bring it to life.", fr-FR
"Dessinez. Animez.", es-ES "Dibuja. Dale vida.", ko-KR「그리고, 움직이다.」, zh-CN
「画出来，动起来。」, zh-TW「畫出來，動起來。」.

Still to be made by a person before release: phone and tablet screenshots that show
real artwork drawn in the current app (the captures used on the website show empty
canvases and an older track name), in each store language.
