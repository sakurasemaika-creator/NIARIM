# NIARIM 動作確認方法

## 環境情報

- Flutter: 3.44.7 stable
- Flutter SDK: `C:\flutter\flutter\bin`
- プロジェクト: `C:\Users\user\Downloads\NIARIM`

---

## Chrome で確認する（最も手軽）

### 手順

1. VS Code を開く
2. ターミナルを開く（上メニュー `ターミナル` → `新しいターミナル`）
3. プロジェクトフォルダにいることを確認（`C:\Users\user\Downloads\NIARIM>`）
4. 以下を実行：

```powershell
flutter run -d chrome
```

5. ブラウザが自動で開き `http://localhost:xxxxx/` が表示される

### ターミナルから実行している場合

- ターミナルで **Ctrl + C** を押すと、Chrome プロセスを終了できます

### 注意点

- タップ → マウスクリックで代替
- スワイプ・描画 → マウスドラッグで代替
- 筆圧・ペン入力は確認不可
- Android特有の動作は確認不可

## APK化して実機確認する

### デバッグAPK（開発中の確認用）

```powershell
flutter build apk --debug
```

出力先: `build\app\outputs\flutter-apk\app-debug.apk`

### リリースAPK（本番用）

```powershell
flutter build apk --release
```

出力先: `build\app\outputs\flutter-apk\app-release.apk`

APKファイルをGalaxyに転送してインストールする。

## Galaxy実機でUSBデバッグする（Galaxyが手元にある場合）

### 初回設定（1回だけ）

1. Galaxy の `設定` → `デバイス情報` → `ソフトウェア情報`
2. `ビルド番号` を7回タップ → 開発者モードON
3. `設定` → `開発者向けオプション` → `USBデバッグ` をON
4. USBでPCに接続
5. Galaxy側に「USBデバッグを許可しますか？」が出たら `OK`

### 実行

```powershell
flutter run
```

接続済みのGalaxyが自動で選択される。

## ホットリロード（コード変更を即反映）

`flutter run` 実行中にターミナルで：

## GitHub Actionsでapk化する（PC不要・スマホのみでも可）

PCが手元になくても、GitHub Actions上でAndroid SDKを使ったビルドを実行し、できあがった`.apk`をダウンロードできる。手元の開発環境（PC・Flutter SDK）に依存せず、スマホのブラウザ／GitHubアプリだけで完結する。

ワークフロー定義：`.github/workflows/build-apk.yml`（手動実行のみ・自動トリガーなし）

### 手順

1. GitHubアプリまたはブラウザで `sakurasemaika-creator/NIARIM` を開く
2. 上部タブから **「Actions」** を選択
3. 左側の一覧から **「Build APK」** を選択
4. **「Run workflow」** をタップ
   - ブランチ：ビルドしたいブランチを選択
   - build-type：`debug` または `release`（既定は `debug`）
5. 「Run workflow」を実行 → ビルド完了まで数分待つ（GitHub側のサーバーで実行される）
6. 実行結果ページ下部の **「Artifacts」** に `niarim-<build-type>-apk` が生成されるのでタップしてダウンロード
7. ダウンロードした`.apk`をAndroid端末で開けば直接インストールできる（「提供元不明のアプリ」のインストール許可が必要な場合あり）

### この方法が有効な場面

- PCが手元にない・Flutter SDKをインストールしていない
- ローカル環境のGradle/Android SDKの構成に問題がないか、クリーンな環境で切り分けたい
- `google_mobile_ads`のようなネイティブ依存の更新後、実際にAndroidビルドが通るか確認したい
