オパールを使う
オパールの使い方
オパールは、使いたい特典と期間を自由に選べる仕組み。特典ごとの必要枚数と交換できる内容は、アプリ内で確認できます。
01 / SELECT
必要な機能だけ選ぶ
動画の仕上げや広告の非表示など、使いたい機能をひとつずつ選べます。
02 / DURATION
使う時間を選ぶ
短時間だけでも、じっくり制作したい期間でも。使う予定に合わせて期間を選べます。
03 / KEEP CREATING
オパールで好きな機能を
ログインやミッション、対象広告などで集めたオパールを、作品づくりのために使えます。
引き換えに必要なオパール数
使いたい機能と期間に応じた必要オパール数です。単品とコンプリートパックを一つの表で比較できます。
