# NIARIM 全面監査の修正引継ぎ台帳

App・Web共通。Claudeが要修正の詳細を追記し、ユーザーが別途起動したGPTが同じ項目に修正・確認結果を追記する。Claudeは二巡目の結果も記録する。[実行Policy](../policy/ASTRA_WORK.md#一巡目修正二巡目の担当分離2026-11-16ユーザー指定)に従う。

既存のホーム指摘と証跡は[A003の引継ぎ](../policy/A003_REPAIR_HANDOFF.md)を参照。着手済みの指摘は最新 `dev_branch` の差分、既存の検証結果、保存済みのWIPと照合する。

## 追記する項目

- **Claudeの指摘** — 監査ID、対象repo・確認SHA、画面・操作入口、再現条件と手順、期待と実際、利用者への影響、証跡参照、既知の依存や保留条件
- **GPTの返却** — 対象ID、修正コミットと確認SHA、実施した確認と結果、影響範囲、残る未確認。着手済みのWIPがあれば保管場所と対応HEAD
- **Claudeの二巡目** — 確認SHA、対象IDと判定、再操作の証跡。再現したときは同じ指摘に条件・根拠を追記

- **fixture**：

  - 長い名前（ja・en・ko）、タグ、お気に入り。

- **要修正（DISC126、既存）**：並び順で「名前」を選ぶと前の向き（↓）のままで、Z→Aに並ぶ。期待：名前を選んだらA→Z（または、向きが分かるようにする）。
- **要修正（新、DISC262）**：選ぶ操作を始めると、一覧全体が約64px下へずれる。

  - 手順：1280×800の詳細表示で行を長押しし、同じ高さの別の行を押す。
