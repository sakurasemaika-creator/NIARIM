## 追加した製品仕様

- 「端末の容量」: NIARIM、その他の使用容量、空き容量の3本の横棒のみ。デバイス総容量と空き容量はOSプラグイン取得。表示可能な各行に項目名とバイト量、最長棒基準の相対量を内包。
- 「NIARIMの内訳」: 素材、プロジェクトデータ、書き出し済み、カスタム素材、キャッシュ、ゴミ箱の最大6本の横棒のみ。円グラフ、色丸、ドーナツ代替アイコンを使用しない。
- 両グラフは同じ棒幅・高さ・角丸・縁・未使用部分のテーマ色（`onSurface`）・アクティブなボタンの文字色（`onSecondary`）を使用。色が明るい場合も読めるよう文字にテーマ色の細い縁を付与。
- 内訳6色はアクセントの**色相・彩度だけ**を継承。明度は固定 `[0.615,0.70,0.785,0.85,0.915,0.98]`。旧4、5、6色目から始め、後半は明度100%超過を避けるため段階幅を狭めた**新しい3色**。色の単純な循環・並べ替えではない。
- 端末側の色は同じ彩度・固定明度の先頭3色で、色相のみアクセントから `+18°`。3色は内訳と同系統だが識別可能。
- 表示中の数字・棒の長さは最新集計に追従し、更新失敗時に偽の値を表示しない。集計中/失敗/再試行の既存動作を保持する。
