# 08_設定画面

## 概要

- カテゴリ：基本 / 詳細 / パフォーマンス / ジェスチャー / UI / 品質 / ワークスペース
- 設定内検索バーあり（項目が増えても検索で到達可能）

---

## 基本設定

- FPSデフォルト値
- キャンバス背景色デフォルト
- 言語設定

---

## 詳細設定

- Undo回数（デフォルト50回・変更可）
- 自動保存スロット数（固定5スロット）
- ゴミ箱の自動削除：OFF / 30日 / 60日 / 90日

---

## パフォーマンス設定

- 端末性能を自動判定 → 低品質 / 中品質 / 高品質 / カスタム の4段階
- Copy-on-Write・差分保存・タイルキャッシュ

| 品質 | 混色 | 傾き検知 |
|------|------|---------|
| 低品質 | 簡易混色のみ | OFF |
| 中品質 | 簡易混色 | OFF |
| 高品質 | 将来の本格混色追加時に自動有効 | ブラシ変形に反映 |
| カスタム | 個別設定 | 個別設定 |

---

## ジェスチャー設定

| 操作 | 初期設定 |
|------|---------|
| 2本指タップ | Undo |
| 3本指タップ | Redo |
| 2本指スワイプ左右 | フレーム移動 |
| 長押し | スポイト |

カスタマイズ可能な割り当て候補：Undo / Redo / スポイト / 手のひらツール / 消しゴム切替 / ブラシ切替 / ツール早替え / 何もしない

## 品質設定

- 端末性能の自動判定結果を表示
- 手動で品質を変更可能
- ペンの傾きをブラシに反映（高品質・カスタム時のみ表示）

## ペン入力設定

```
筆圧設定
○ 無効
○ サイズに反映
○ 不透明度に反映
○ サイズ＋不透明度に反映
```

筆圧カーブ：弱 / 普通 / 強 / カスタム（アプリ全体に適用）

- ペンの傾きをブラシに反映（高品質・カスタム時のみ表示）
  - 注釈：対応ペン使用時、ペンを寝かせることでブラシの形状や濃さを変化させます

対応端末のペンボタンに以下を割り当て可能。

- 消しゴム切替
- スポイト
- Undo
- Redo
- ツール早替え
- なし

## ワークスペース設定

「ワークスペース設定」はレイアウトだけでなく操作環境全体を管理する。

### PCモードについて

PCモードとはGalaxy DeX等で利用するデスクトップUIモードを指す。Windows・Mac版を意味しない。

### ツールバー編集

- 表示するツールをチェックボックスで選択
- ドラッグで並び替え

```
☑ Gペン
☑ 消しゴム
☑ バケツ
☑ スポイト
☐ 定規
☐ テキスト
☐ フィルター
```

### パネル配置

- 右利き / 左利きの切替
- スマホレイアウト / DeX（PCモード）レイアウトの切替

### ワークスペース保存・読込

- ワークスペースを名前を付けて保存できる（例：アニメ用 / 線画用 / 背景用）
- 切り替えると表示ツール・早替えツール・パネル配置が一括で変わる
- ワークスペースの読込・削除が可能

---

## ツール早替え機能

早替えツールの編集はキャンバス上で行う。設定画面では管理しない。

### 早替えボタン（↺）

- ツールバーに↺アイコンを1つ配置
- タップするたびに登録順にツールを切替・最後まで行くと先頭へループ
- ジェスチャー・ペンボタンにも「次のツールへ」を割り当て可能

### 早替えツール設定ポップアップ

↺ボタンを長押しするとキャンバス上にポップアップを表示。

```
──────────────────────
早替えツール設定

① Gペン 細
② Gペン 太
③ エアブラシ
④ 消しゴム
⑤ スポイト

＋追加
──────────────────────
```

- ドラッグで順番変更
- 削除可能
- 同じツールを複数登録可能（例：Gペン3px → Gペン8px → Gペン15px）
- 登録数：1〜20個程度
- 「現在のブラシを追加」で使用中のブラシ設定をそのまま登録可能

---

## 入力デバイス仕様

### 対応デバイス・動作条件

- Android 8.0以上（推奨 Android 10以上）
- 低スペック端末（2万円台・64GB・低性能CPU）での動作を前提とする
- Galaxy端末（Sペン・DeXモード）での動作を最終確認環境とする
- 板タブ・液晶タブレット・スタイラスペン：Android OS標準ペン入力API経由で対応（機種ごとの個別実装は行わない）

### 入力の分離と優先順位

```
優先順位
① ペン入力（描画）
② 指ジェスチャー
③ マウス
④ キーボード
```

- 通常端末：指・ペンどちらでも描画可能
- ペン対応端末：ペン入力中はペンを優先し、指入力はジェスチャー操作のみ受け付ける（パームリジェクション）
- ペン入力終了後は通常状態へ戻る

### 初期実装範囲

| 項目 | 状態 |
|------|------|
| 座標（X・Y） | ✅ 対応 |
| 筆圧（pressure） | ✅ 対応 |
| ペン接触判定 | ✅ 対応 |
| 指／ペン入力判別 | ✅ 対応 |
| 傾き（tilt）情報取得 | ✅ 常時取得 |
| 傾きのブラシ変形への反映 | 高品質・カスタム設定時のみ有効 |
| ペンボタン | 対応端末のみ取得・ペンボタン設定で割り当て可能 |

### Galaxy DeXモード・マウス入力

- DeX接続時はマウス・キーボード操作に対応
- 左クリック：描画
- ホイール：ズーム
- 中クリックドラッグ：移動
- 右クリック：コンテキストメニュー
- Shift / Ctrl ショートカット対応
- ウィンドウリサイズ対応
