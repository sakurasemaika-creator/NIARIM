# 08_設定画面

## 概要

- カテゴリ：基本 / 詳細 / パフォーマンス / ジェスチャー / ペン入力 / ワークスペース / UI・テーマ / ウォーターマーク
- 設定内検索バーあり（項目が増えても検索で到達可能）
- 「品質」は独立カテゴリではなく「パフォーマンス」に統合されている
- ウォーターマークカテゴリは無料会員には🔒マーク付きで表示する。タップすると共通Premium紹介バナーを表示する（詳細は 13_広告・課金仕様.md を参照）

---

## 基本設定

- FPSデフォルト値
- キャンバス背景色デフォルト
- 言語設定
- 描画領域初期値（倒率・詳細は 26_描画領域・内部保存仕様.md を参照）

## 詳細設定

- Undo回数（デフォルト50回・変更可）
- 自動保存：クラッシュ復元専用・最大3件固定・古い順削除（スロット数変更不可）
- ゴミ箱の自動削除：OFF / 30日 / 60日 / 90日

---

## パフォーマンス設定

- 端末性能を自動判定 → 低品質 / 中品質 / 高品質 / カスタム の4段階
- 品質設定は保存方式・キャッシュ・オニオンスキン・混色・傾き検知・その他軽量化を含む全体品質設定

| 品質 | 傾き検知 | 保存方式 | オニオンスキン |
|------|---------|---------|----------|
| 低品質 | OFF | スロット5件 | 前後ON・各1枚 |
| 中品質 | OFF | スロット10件 | 前後ON・各3枚 |
| 高品質 | ブラシ変形に反映 | ツリー方式（無制限） | 前後ON・各5枚 |
| カスタム | 個別設定 | 個別設定 | 前後個別にON/OFF・1〜10枚・色・透明度を設定 |

混色モードはブラシ設定に属する機能であり、パフォーマンス設定とは無関係。カスタム品質設定画面に混色モードの設定項目は存在しない。

## ジェスチャー設定

| 操作 | 初期設定 |
|------|---------| 
| 2本指タップ | Undo |
| 3本指タップ | Redo |
| 2本指スワイプ左右 | フレーム移動 |
| 長押し | スポイト |

カスタマイズ可能な割り当て候補：Undo / Redo / スポイト / 手のひらツール / 消しゴム切替 / ブラシ切替 / ツール早替え / 何もしない

## UI設定

- テーマ設定（詳細は 24_テーマ・外観仕様.md を参照）
- ベースカラー / アクセントカラー / 文字色を自由設定可能
- UIテーマはワークスペースとは完全独立
- UIテーマでは配色・アイコン・外観のみ保存（ツール配置は保存しない）
- テーマの保存・複数保存・読み込み・エクスポート・インポート対応
- テーマは .miratheme ファイルとして共有可能（初期実装）
- 引き継ぎデータ（.miratra）にも含められる

## 品質設定

- 初回起動時に端末性能を自動判定し、低品質 / 中品質 / 高品質 のいずれかを自動適用
- 手動で品質を変更可能
- 品質設定は保存方式・キャッシュ・オニオンスキン・傾き検知・その他軽量化を含む全体品質設定
- ペンの傾きをブラシに反映（高品質・カスタム時のみ表示）

### カスタム品質

- 初回起動時のみ、自動判定されたプリセット設定をカスタム品質の初期値としてコピーする
- 一度でもカスタムを適用した後は、最後に適用した内容を端末内へ永続保存する
- プリセット（低/中/高）へ切り替えてもカスタム設定は変更されない
- カスタムへ戻ると最後に使用した内容がそのまま表示される

### カスタム品質のリセット

品質設定画面に「初期値に戻す」ボタンを配置する。

```
カスタム品質設定を初期値に戻しますか？

初期値は、初回起動時に端末性能から自動判定された品質設定になります。

[キャンセル]  [戻す]
```

### 現在のプリセットをコピー

「カスタム品質」設定画面に「現在のプリセットをコピー」ボタンを配置する。ボタンを押すと以下のダイアログを表示する。

```
コピーするプリセットを選択

カスタム設定へコピーするプリセットを選択してください。

  低品質
  前後1枚表示・軽量動作

  中品質
  前後3枚表示・標準

  高品質
  前後5枚表示・高品質

【キャンセル】
```

選択したプリセット内容をカスタム設定へ反映し、以降はユーザーが自由に編集できる。端末買い替え時や「高品質をベースに少しだけ変えたい」場合に有用。

### 永続保存される項目

- 前オニオン ON/OFF・枚数・色・透明度
- 後オニオン ON/OFF・枚数・色・透明度
- 傾き検知 ON/OFF
- 保存方式・スロット数
- その他カスタム品質項目

## ワークスペース設定

「ワークスペース設定」はレイアウトだけでなく操作環境全体を管理する。UIテーマとは独立した設定。

### PCモードについて

PCモードとはGalaxy DeX等で利用するデスクトップUIモードを指す。Windows・Mac版を意味しない。

### ツールバー編集

- 表示するツールをチェックボックスで選択
- ドラッグで並び替え

```
☑ Gペン
☑ 消しゴム
☑ バケツ
☑ スポイト
☐ 定規
☐ テキスト
☐ フィルター
```

### パネル配置

- 右利き / 左利きの切替
- スマホレイアウト / DeX（PCモード）レイアウトの切替

### ワークスペース保存・読込

- ワークスペースを名前を付けて保存できる（例：アニメ用 / 線画用 / 背景用）
- 切り替えると表示ツール・早替えツール・パネル配置が一括で変わる
- ワークスペースの読込・削除が可能

## ツール早替え機能

早替えツールの編集はキャンバス上で行う。設定画面では管理しない。

### 早替えボタン（↺）

- ツールバーに↺アイコンを1つ配置
- タップするたびに登録順にツールを切替・最後まで行くと先頭へループ
- ジェスチャー・ペンボタンにも「次のツールへ」を割り当て可能

### 早替えツール設定ポップアップ

↺ボタンを長押し、または↺ボタン上で上方向へスワイプするとキャンバス上に
ポップアップを表示（どちらのジェスチャーでも同じポップアップが開く。
設定画面まで行かなくても気軽にツール切替の登録・並び替えができる）。

```
──────────────────────
早替えツール設定

① Gペン 細
② Gペン 太
③ エアブラシ
④ 消しゴム
⑤ スポイト

＋追加
──────────────────────
```

- ドラッグで順番変更
- 削除可能
- 同じツールを複数登録可能（例：Gペン3px → Gペン8px → Gペン15px）
- 登録数：1〜20個程度
- 「現在のブラシを追加」で使用中のブラシ設定をそのまま登録可能

## 入力デバイス仕様

### 対応デバイス・動作条件

- Android 8.0以上（推奨 Android 10以上）
- 低スペック端末（2万円台・64GB・低性能CPU）での動作を前提とする
- Galaxy端末（Sペン・DeXモード）での動作を最終確認環境とする
- 板タブ・液晶タブレット・スタイラスペン：Android OS標準ペン入力API経由で対応（機種ごとの個別実装は行わない）

### 入力の分離と優先順位

```
優先順位
① ペン入力（描画）
② 指ジェスチャー
③ マウス
④ キーボード
```

- 通常端末：指・ペンどちらでも描画可能
- ペン対応端末：ペン入力中はペンを優先し、指入力はジェスチャー操作のみ受け付ける（パームリジェクション）
- ペン入力終了後は通常状態へ戻る

### 初期実装範囲

| 項目 | 状態 |
|------|------|
| 座標（X・Y） | ✅ 対応 |
| 筆圧（pressure） | ✅ 対応 |
| ペン接触判定 | ✅ 対応 |
| 指／ペン入力判別 | ✅ 対応 |
| 傾き（tilt）情報取得 | ✅ 常時取得 |
| 傾きのブラシ変形への反映 | 高品質・カスタム設定時のみ有効 |
| ペンボタン | 対応端末のみ取得・ペンボタン設定で割り当て可能 |

### Galaxy DeXモード・マウス入力

- DeX接続時はマウス・キーボード操作に対応
- 左クリック：描画
- ホイール：ズーム
- 中クリックドラッグ：移動
- 右クリック：コンテキストメニュー
- Shift / Ctrl ショートカット対応
- ウィンドウリサイズ対応
