### 公式エンドロゴ動画仕様

動画書き出し時、本編終了後にMIRANIMA公式ロゴ動画を自動追加する。

```
ユーザー作品（本編）
↓
本編終了
↓
MIRANIMAロゴ動画（約５秒）
↓
動画終了
```

- 本編アニメーション部分には一切表示しない
- 内部的にEndCard Trackとして管理

| 版 | EndCard Trackの状態 |
|-----|--------------------|
| 無料版 | タイムライン上に表示されるがロック状態（削除・移動・編集・操作不可） |
| プレミアム | タイムライン上に表示・編集可能（削除・表示非表示・長さ変更・差替え） |

### ユーザーウォーターマーク（プレミアム限定）

ユーザーが任意のロゴ・画像・文字を登録し、動画へ常時表示できる。

設定項目：画像選択 / 文字入力 / 位置 / サイズ / 透明度 / 表示開始時間 / 終了時間 / 常時表示ON/OFF

### 広告アーキテクチャ

広告表示部分と広告プロバイダー部分を分離し、将来的に別広告ネットワーク・自社プロモーション・素材販売広告などへ差し替え可能な構造とする。

```
MIRANIMA
│
├── AdvertisingService
│
├── AdProvider Interface
│
├── AdMobProvider（初期実装）
│
└── FutureProvider
    ├── 他社広告SDK
    ├── 自社プロモーション
    └── 素材販売広告
```

- 各画面はAdvertisingService経由で広告を呼び出す（広告SDKへの直接依存禁止）
- 初期実装：Google AdMob
- AdProvider共通インターフェース：showBanner(position) / showSquareAd() / hideAllAds() / isPremiumUser()

### 無料版広告配置

| 画面 | 広告種別 | 配置場所 | 制約 |
|------|----------|----------|------|
| キャンバスモード | 固定バナー | 画面上部 | キャンバス内部・描画領域への重なり禁止 |
| タイムラインモード | 固定バナー | 画面下部 | 編集領域への重なり禁止 |
| プロジェクト一覧 | 固定バナー | 画面下部 | — |
| 処理中 | 正方形広告 | プログレスバー下部 | 処理完了時に自動消去 |

処理中広告の対象：フィルター適用 / 動画書き出し / GIF生成 / 透過WebM生成 / 大量処理実行時

### プレミアム加入時の広告処理

AdvertisingServiceがプレミアム状態を確認し、全広告を非表示に切り替える。広告領域はUIから完全削除され、作業領域を自動拡張する。

- 保存系ボタンをタイムラインモードのみに配置することでキャンバスモードの描画領域を広く確保

## 6.5 外部ペン入力対応

### 対応方針

- Android OS標準のペン入力APIを使用した汎用対応（特定メーカー依存なし）
- 対応デバイス：板タブ・液晶タブレット・スタイラスペン
- 指操作とペン操作を入力種別で自動判別

```
ペン入力 → 描画
指入力  → ジェスチャー操作（既存仕様通り）
```

### 初期実装範囲

| 項目 | 状態 |
|------|------|
| 座標（X・Y） | ✅ 対応 |
| 筆圧（pressure） | ✅ 対応 |
| ペン接触判定 | ✅ 対応 |
| 指／ペン入力判別 | ✅ 対応 |
| 傾き（tilt）情報取得 | ✅ 取得のみ対応 |
| 傾きのブラシ変形への利用 | 高品質・カスタム設定時のみ有効 |
| ペンボタン | 対応端末のみ取得（消しゴム切替・スポイト等に割り当て可能） |

### 筆圧設定（ブラシ設定に追加）

```
筆圧設定
○ 無効
○ サイズに反映
○ 不透明度に反映
○ サイズ＋不透明度に反映
```

- 弱い筆圧 → 細い／薄い線
- 強い筆圧 → 太い／濃い線

### 傾き対応と品質設定の連携

| 品質 | 筆圧 | 傾き |
|------|------|------|
| 低品質 | ✅ ON | ❌ OFF |
| 中品質 | ✅ ON | ❌ OFF |
| 高品質 | ✅ ON | ✅ ブラシ変形に反映 |
| カスタム | ✅ ON | 個別設定（ペンの傾きをブラシに反映 ON/OFF） |

傾き対応の処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わないため、高品質設定でも負荷は低い。

```
ペン入力
↓
筆圧・傾き取得
↓
ブラシスタンプ倍率変更
↓
キャンバスへ描画
```

傾き反映の表現：ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画する。

設定画面での表記：「ペンの傾きをブラシに反映」（注釈：対応ペン使用時、ペンを寝かせることでブラシの形状や濃さを変化させます）

| 項目 | 内容 |
|------|------|
| サイズ | 可変 |
| 不透明度 | 可変 |
| 間隔 | 可変 |

| 筆圧設定 | 無効 / サイズに反映 / 不透明度に反映 / サイズ＋不透明度に反映 |
| フェード | OFF / 弱 / 中 / 強 / カスタム（開始・終了・距離を個別設定） |
| ストローク減衰 | 描き続けるほど不透明度が下がる（インク切れ表現） |
| 混色 | OFF / 簡易混色 / にじみ |
| 混色率 | OFF / 20% / 40% / 60% / 80% / 100% |
| お気に入り | あり |

ブラシ管理：並び替え・編集・複製・削除

### 混色の仕組み
- **簡易混色**：ブラシ直下の現在色と選択色を一定割合で混ぜる（軽量）
- **にじみ**：描くたびに少しだけ色を引っ張る（比較的軽量）
- 本格的な油絵混色（周囲ピクセル解析）は初期実装に含めない

### 品質設定との連携
| 品質 | 使用可能な混色 |
|------|--------------|
| 低品質 | 簡易混色のみ |
| 中品質 | 簡易混色 ＋ にじみ |
| 高品質 | 将来の本格混色追加時に自動有効 |

## 12. 自動塗り

- プリセット管理（プロジェクト保存と独立）
- パーツ管理
- 更新マーク：レイヤー・タイムライン両方に表示
- 手動更新 → 保存
- 書き出し前に未更新の警告あり

### 自動塗り実行時の方法選択

実行時にラジオボタンで処理方法を選択する。

```
自動塗り方法

○ 塗りなおし
○ 色更新
```

| 選択肢 | 動作 | 用途 |
|--------|------|------|
| 塗りなおし | 現在の自動塗りレイヤーの形状を破棄し、線画から領域を再判定して一から塗りなおす | 誤って自動塗りの形状を変えてしまった場合 |
| 色更新 | 現在の自動塗りレイヤーの形状は維持し、不透明度ロックをかけて最新の色設定のみ反映 | 自動塗りの形状を手動で調整した場合 |

処理の仕組み：
- 塗りなおし：自動塗り用線画レイヤー取得 → パーツID取得 → 色プリセット検索 → 線画形状を個別に解析・領域再判定 → 既存自動塗りレイヤーの形状を破棄 → 最新の色設定で塗りなおす
- 色更新：既存自動塗りレイヤー → 不透明度ロック（形状完全維持）→ 色プリセット検索 → 最新の色で塗りつぶす

色更新は形状を完全に維持したまま不透明度ロックで色のみ置換するため処理が軽く、低スペック端末に適している。

対応する自動塗りレイヤーが存在しない場合は、塗りなおし・色更新どちらを選んでいても必ず新規生成して一から塗る（詳細は 04_自動塗り.md を参照）。

## 13. 複数選択UI

複数選択が可能な全画面で、選択モード開始時に専用UIを表示する。

対象画面：プロジェクト一覧 / タイムライン / フレーム一覧 / 素材一覧 / プリセット一覧 / その他複数項目操作が可能な一覧画面

```
通常表示
  [項目1]
  [項目2]
  [項目3]

↓ 長押しなどで選択モード開始

  全選択　　全解除
  ☑ 項目1
  ☐ 項目2
  ☑ 項目3
```

| ボタン | 動作 |
|--------|------|
| 全選択 | 現在表示中の対象（現在のフォルダ内・シーン内・タイムライン範囲など）をすべて選択 |
| 全解除 | 現在選択されている項目をすべて解除 |

- 全選択・全解除ボタンは選択モード中のみ表示
- スマホではドラッグ範囲選択が難しいため、大量フレーム操作・プロジェクト整理・素材管理を簡単にする目的

---

## 15. 保存・書き出し

| 形式 | 用途 |
|------|------|
| .mirapro | 通常プロジェクト保存 |
| .mirashare | 共有用（編集後に.miraproへ変換、毎回確認あり） |
| .miratra | 引き継ぎ用（旧称 .stutra） |
| MP4 | 動画書き出し |
| GIF | 書き出し時のみGIF制限（GIFモードは存在しない） |
| 透過WebM | 動画書き出し |

- 保存プリセットあり（初心者はプリセットのみ使用可）
- 自動保存：キャンバスの内容を変える操作のたびに実行・最大3件固定・古い順削除・クラッシュ/ファイル破損時の復元専用・Undo履歴とは別管理
- Undo：デフォルト50回・設定変更可・プロジェクト保存時に保存しない・自動保存とは独立

## 16. 内部データ構造

```
Project.mirapro/
├── manifest        ← タイトル・更新日時・サムネ・容量・制作時間・AppVersion
├── Scene/
│   ├── Scene0001/
│   │   ├── Layers/
│   │   │   ├── Layer0001
│   │   │   └── Layer0002
│   │   └── ...
│   └── Scene0002/
├── Audio/
├── Materials/
│   ├── Material0001  ← 素材IDで参照（ファイル名では参照しない）
│   └── Material0002
├── Autosave/         ← 最大3件固定・古い順削除
├── SaveTree/         ← 手動保存履歴（セーブツリー）
└── Cache/            ← 動画保存時はフレーム単位、通常時はレイヤー差分
```


- 不足素材の検出あり
- AppVersionにより将来バージョンでの自動変換対応
