# タイムライン編集操作仕様

この文書は、タイムライン上の素材編集を「長さ調整」「画面トリミング」「分割」「切り取り」に分離し、操作名・対象・保存データ・書き出し時の扱いを統一するための仕様である。

## 1. 機能名と責務

| UI名 | 英語名 | 目的 | 対象 |
|---|---|---|---|
| 長さ調整 | Duration / Speed | タイムライン上の時間範囲と再生速度を変更する | 音声・動画・画像・テキスト・読み上げ・カメラ／キーフレーム |
| 画面トリミング | Crop | 素材の見た目の表示領域を切り抜く | 画像・動画 |
| 分割 | Split | クリップを再生ヘッド位置で前後2つに分ける | 分割対応の全タイムライン素材 |
| 切り取り | Cut to Clipboard | 素材を一時クリップボードへ移し、貼り付け可能にする | 選択したクリップ |

「カット」はUI上の機能名として使用しない。前後の不要区間を詰める操作は「長さ調整」、クリップを二分する操作は「分割」、クリップボードへ移す操作は「切り取り」と呼ぶ。

## 2. 長さ調整

### 2.1 時間範囲
- クリップのタイムライン上の開始位置・終了位置を変更する。
- 左右の端ハンドルと数値入力の両方で指定できる。
- 動画・音声では素材内の使用開始／終了位置を保持し、画像・テキストではタイムライン上の表示期間を変更する。
- 元ファイルや元画像の画素データを破壊しない。
- 既存のドラッグによる開始位置移動・端ハンドルによる範囲変更は維持し、パネル内の名称を「長さ調整」に統一する。

### 2.2 再生速度
- 速度は倍率で保持する。1.0xが通常速度、2.0xが2倍速、0.5xが半分の速度。
- スライダーと数値入力を必ず両方用意する。スライダーは低倍率域を細かく操作できる目盛り設計とし、数値入力では任意の小数を指定できる。
- 通常操作域は0.1x〜16x、拡張入力域は0.01x〜100xを初期案とする。100xは上限値として許可し、端末性能を理由に一律で拒否しない。
- 0より大きい有限値のみ許可する。NaN、Infinity、0、負数は拒否する。小数の丸めは保存時に不用意に行わない。
- 速度変更は非破壊編集とし、元素材のファイルや元のキーフレーム値を上書きしない。
- 速度変更後の表示長は、元の対象時間 ÷ 速度倍率で求める。フレーム単位へ丸める際は、最短1フレームを保証し、隣接クリップとの重なり・意図しない空白を作らない。
- 速度変更後も、音声・映像・読み上げの同期を保つ。音声と映像を連動させるか、片方だけ速度変更するかを明示的に選べるようにする。
- 100x付近では音声の聞き取りやすさは保証しない。音声をミュートする選択肢を用意し、音声処理は映像と独立して扱う。
- プレビュー再生はフレームを飛ばして追従してよいが、タイムライン上の時間・書き出し結果は正確な倍率を保つ。
- 書き出しはリアルタイム処理を要求しない。処理に時間がかかる場合は進捗を表示し、キャンセル可能にする。処理時間の長さを理由に倍率を下げない。

### 2.3 対象ごとの速度の意味
- **動画**：素材内の再生時刻を倍率で進める。音声を含む動画は映像と音声の速度を同期させる設定を持つ。
- **音声**：音声の再生速度を変更する。ピッチ維持のON/OFFを選べる。極端な高速では音質・聞き取りやすさが低下することを許容事項として明示する。
- **読み上げ**：生成済み音声クリップの速度を変更する。読み上げテキスト自体の再生成を必須にしない。
- **画像・テキスト**：静止素材そのものに再生速度はないため、速度欄は表示せず、開始・終了位置による表示期間の変更だけを行う。
- **レイヤーキーフレーム**：対象素材のキーフレーム時刻を非破壊でリタイムする。キーフレームの値・補間カーブは維持し、時間間隔だけを倍率に応じて変える。画像・テキスト素材でもキーフレームがある場合は、そのアニメーションに速度を適用できる。
- **カメラキーフレーム**：選択したカメラアニメーション範囲をリタイムする。カメラの位置・ズーム・回転値と補間結果を維持する。対象範囲外のキーフレームは変更しない。
- **キーフレーム範囲の選択**：単一キーだけでなく、範囲選択した複数キーを一括リタイムできる。範囲外のキーとの衝突時は、適用前にプレビューし、確定できない配置は拒否する。

### 2.4 速度UI
- 「長さ調整」パネル内に「時間範囲」「速度」の項目を分ける。
- 速度欄は倍率表記（例：1.00x）とし、スライダーと直接入力を同期させる。
- 代表値のクイック選択：0.25x / 0.5x / 1x / 2x / 4x / 8x / 16x / 100x。
- 数値入力は小数を許可し、入力途中の不完全値を即時保存しない。確定時に範囲検証する。
- 速度変更によりクリップの終了位置が変わる場合、変更前後の終了位置をプレビューする。既存素材と重なる場合は、勝手に上書き・削除せず、適用を保留してユーザーへ知らせる。

## 3. 画面トリミング
- 画像・動画の見た目の領域を切り抜く機能。時間範囲の変更とは独立させる。
- 元ファイル・元画像の画素は変更せず、クロップ矩形を素材の編集情報として保存する。
- プレビュー上のハンドル操作と数値入力を用意する。
- 位置・拡大・回転・マスクとは別の編集値として保持し、編集順によって結果が変わらない座標系を定義する。
- 動画では全フレームに同じクロップを適用する。時間変化するクロップは別機能として扱い、初期実装には含めない。

## 4. 分割
- 分割モードへ入り、再生ヘッドを合わせて「適用」で確定する。キャンセルで何も変更しない。
- 分割位置をまたぐクリップのみ対象にする。先頭・末尾と同じ位置では分割しない。
- 選択中シーンの分割対象クリップを対象とし、分割後は前後の2クリップが同じ素材内容・トラック行・表示順を維持する。
- 動画・音声は素材内の再生位置、速度、音量、ピッチ設定を引き継ぐ。
- フェードインは前半、フェードアウトは後半へ保持する。分割点に意図しないフェードを追加しない。
- 画像・テキスト・動画はマスク、クロップ、配置、キーフレーム、重なり順などの編集情報を複製する。キーフレーム時刻は前後クリップのローカル時間に合わせて整合させる。
- Undo/Redoで分割全体を1操作として戻せる。

## 5. 切り取り（クリップボード）
- 選択したクリップを一時クリップボードへ保持し、元位置から削除する。
- コピーと切り取りを区別し、貼り付け時は現在の再生ヘッド位置を基準に配置する。
- クリップボードには素材参照だけでなく、速度・時間範囲・クロップ・マスク・配置・キーフレーム・音量・フェード等の編集情報を含める。
- クリップボード内容が失われても元素材ファイル自体を削除しない。
- Undo/Redoは切り取り・貼り付けをそれぞれ1操作として扱う。

## 6. 保存・互換性・検証
- 新しい速度・クロップ情報は既存プロジェクトを壊さない任意フィールドとして保存し、未設定の古いデータは速度1.0x・クロップなしとして読み込む。
- 速度変更、分割、クロップ、切り取りの各操作はUndo/Redo・自動保存・プロジェクト複製・書き出しで一貫させる。
- 動画・音声の書き出しではタイムスタンプを倍率に合わせて変換し、映像と音声の同期をテストする。
- テスト対象：0.1x、0.5x、1x、2x、16x、100x、端数倍率、1フレーム未満の結果、クリップ境界、複数キーの衝突、旧プロジェクト読み込み、Undo/Redo、キャンセル。
- 画質補間を行わない高速化では、元映像に存在しないフレームは生成しない。スロー再生でフレーム数が不足する場合は、フレーム補間を別の品質オプションとして扱う。
