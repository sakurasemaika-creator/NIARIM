# 04_自動塗り

## 概要

- プリセット管理（プロジェクト保存と独立）
- パーツ管理
- 更新マーク（❗）：レイヤー・タイムライン両方に表示
- 手動更新 → 保存
- 書き出し前に未更新の警告あり
- 共通レイヤーは自動塗り対象外

---

## レイヤー種別

自動塗りに関係するレイヤーは以下の2種類。どちらも特殊レイヤーであり、通常レイヤーとは内部データ構造が異なる。どちらも手動追加可能。自動塗り実行時にも自動生成される。

| 種別 | 役割 |
|------|------|
| 自動塗り用線画レイヤー | 線画を描く専用レイヤー。パーツIDを持つ |
| 自動塗りレイヤー | 自動塗り結果を保持する専用レイヤー |

### レイヤー種別の変換

- 通常レイヤー ⇔ 特殊レイヤー（自動塗り用線画・自動塗り）の相互変換は行えない
- 特殊レイヤーは専用の追加メニューからのみ作成できる
- 例外：テキストレイヤー → ラスタライズ → 通常レイヤーへの変換のみ許可

### レイヤー名

- 自動塗り用線画レイヤー・自動塗りレイヤーのレイヤー名はユーザーが変更できない
- 表示名はパーツ名に連動する（例：「髪（線画）」「髪（自動塗り）」）
- パーツ名を変更すると対応するレイヤーの表示名も一括で変わる

### 通常レイヤーとの区別

- 通常レイヤーをパーツ名と同じ名前にしても自動塗りの対象にはならない
- 自動塗りはレイヤー名ではなくレイヤー種別・パーツID・内部IDで判定する

## レイヤー追加

レイヤー追加ボタン押下時のメニュー：

```
通常レイヤー
共通レイヤー
フォルダ
──────────
自動塗り用線画レイヤー
自動塗りレイヤー
```

---

## 自動塗りレイヤーの配置ルール

- 自動塗りレイヤーは対応する自動塗り用線画レイヤーの直下に配置される
- 直下に自動塗りレイヤーが存在する場合 → そのレイヤーを更新する
- 直下に自動塗りレイヤーが存在しない場合 → 直下へ新規生成する
- ユーザーが手動追加・手動移動した自動塗りレイヤーは配置位置を変更しない・自動削除しない・自動移動しない
- ただし手動配置の自動塗りレイヤーも「塗りなおし」「色更新」どちらの処理対象にも含まれる

---

## 自動塗りの実行入口

自動塗りは描画モードとタイムラインモードの両方から実行できる。描画モードでは現在フレームのみ、タイムラインモードでは選択フレーム・シーン・全フレームを対象として実行する。内部処理は共通の自動塗りエンジンを使用し、実行対象フレームが1枚か複数枚かが異なるだけである。

### 入口①：描画モード（現在フレームのみ）

塗りツール一覧から実行する。

```
塗りツール
──────────
バケツ
投げ縄塗り
──────────
自動塗り
```

用途：線画を描き終わった / 色だけ更新したい / 1枚だけ確認したい

### 入口②：タイムラインモード（複数フレーム）

タイムラインモードの三点メニュー（⋮）から実行する。実行対象は選択フレーム・シーン単位・全フレームから選べる。

用途：線画を大量修正した / 一括更新したい

### 更新マーク（❗）との連携

描画モードで❗更新マークをタップすると自動塗りダイアログへ遷移し、実行後に更新マークが消える。

## 自動塗り実行ダイアログ

```
自動塗り方法

※ プロジェクト内で自動塗りを初回実行する場合はどちらを選んでも問題ありません。
※ 自動塗りレイヤーが存在する場合はそのレイヤーを優先して自動塗りを行います。
　線画レイヤーが存在しない場合は領域を自動判定します。

○ 塗りなおし
  （誤って自動塗りの形状を変えてしまった場合におすすめ）
  ※ 一から領域を判定して塗りなおします。
  　 現在の自動塗りレイヤーの形状は破棄されます。

○ 色更新
  （自動塗りの形状を手動で調整した場合におすすめ）
  ※ 不透明度ロックをして最新の色で塗りつぶします。
  　 現在の自動塗りレイヤーの形状は維持されます。

──────────

実行　キャンセル
```

---

## 処理の仕組み

### 塗りなおし

既存の自動塗りレイヤーのレイヤー位置は変更しない。現在の塗り形状を破棄し、自動塗り用線画レイヤーから領域を再判定して一から塗りなおす。

```
自動塗り用線画レイヤー取得
↓
パーツID取得
↓
自動塗りプリセットからパーツ色を検索（パーツIDで判定）
↓
線画形状を個別に解析・領域再判定
↓
既存自動塗りレイヤーの形状を破棄
↓
最新の色設定で塗りなおす
```

### 色更新

既存の自動塗りレイヤーのレイヤー位置・形状は変更しない。不透明度ロックをかけて最新の色設定のみ反映する。

```
既存自動塗りレイヤー
↓
不透明度ロック（形状完全維持）
↓
自動塗りプリセットからパーツ色を検索（パーツIDで判定）
↓
最新の色で塗りつぶす
```

### 自動塗りレイヤーが存在しない場合の例外処理

自動塗り用線画レイヤーは存在するが、対応する自動塗りレイヤーが存在しない場合は、「塗りなおし」「色更新」どちらを選んでいても必ず以下を実行する。

```
線画取得
↓
領域解析
↓
自動塗りレイヤー新規生成（線画レイヤー直下）
↓
一から塗る
```

理由：新規生成されたレイヤーには塗り形状が存在しないため、不透明度ロックでは何も塗れないため。

### 4パターンまとめ

| 線画レイヤー | 塗りレイヤー | 塗りなおし | 色更新 |
|------------|------------|-----------|--------|
| あり | あり | 形状破棄→領域再判定→塗りなおす | 形状維持→色のみ更新 |
| あり | なし | 新規生成→一から塗る | 新規生成→一から塗る（例外処理） |
| なし | あり | 形状破棄→何もしない | 形状維持→色のみ更新 |
| なし | なし | 処理対象なし | 処理対象なし |

---

## 同一パーツ名の複数線画レイヤー

同一フレーム内に同じパーツ名を持つ自動塗り用線画レイヤーが複数存在する場合、それぞれの線画形状を個別に解析し、対応する自動塗りレイヤーへ同じパーツ色で自動塗りを行う。パーツ名が同じでも線画形状は共有せず、それぞれ独立して処理する。

例：

```
前髪（線画）パーツ名：髪
└ 前髪（自動塗り）→ 髪の色で塗る

後ろ髪（線画）パーツ名：髪
└ 後ろ髪（自動塗り）→ 髪の色で塗る

横髪（線画）パーツ名：髪
└ 横髪（自動塗り）→ 髪の色で塗る
```

パーツ色を変更すると3枚すべてに一括反映される。

## 各ツールの参照対象

| ツール | 参照対象 |
|--------|---------|
| バケツ | 表示中のすべてのレイヤーの線を参照 |
| 投げ縄塗り | 選択範囲のみ |
| 自動塗り | 対応する自動塗り用線画レイヤーのみ（パーツIDで判定） |

## プリセット管理

- 保存プリセット・ブラシプリセット・自動塗りプリセットは全部独立
- 自動塗りプリセットはプロジェクト保存とは独立して管理
- 自動塗りはパーツ名ではなくパーツIDで判定する
- 詳細は 20_色管理仕様.md を参照

---

## 共通レイヤーとの関係

- 共通レイヤーは自動塗りの対象外
- 共通レイヤーはオニオンスキンの対象外
- 詳細は 16_レイヤー仕様.md を参照
