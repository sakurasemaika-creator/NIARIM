# 04_自動塗り

## 概要

- プリセット管理（プロジェクト保存と独立）
- パーツ管理
- 更新マーク：レイヤー・タイムライン両方に表示
- 手動更新 → 保存
- 書き出し前に未更新の警告あり

---

## レイヤー種別

| 種別 | 備考 |
|------|------|
| 通常 | あり |
| 自動塗り | あり |
| 参照 | あり |
| フォルダ | あり |

- クリッピング・マスク・ブレンドモード・ロック・不透明度ロック・検索・複数選択
- レイヤー追加ボタン押下時のメニュー：通常レイヤー / フォルダ / ─── / 自動塗りレイヤー追加

---

## 自動塗り実行時の方法選択

実行時にラジオボタンで処理方法を選択する。

```
自動塗り方法

○ 新規自動塗り
○ 既存自動塗りを更新
```

| 選択肢 | 動作 | 用途 |
|--------|------|------|
| 新規自動塗り | 現在の自動塗りレイヤーをリセットし、最新の設定で1から作成 | 自動塗りを削除してしまった場合 / 線画修正後に再生成したい場合 / 色分けを完全にやり直したい場合 |
| 既存自動塗りを更新 | 既存の自動塗り形状を不透明度ロックで維持し、最新の色設定のみ反映 | 手動修正した自動塗りを維持したい場合 / カラー設定だけ変更したい場合 |

---

## 処理の仕組み

### 新規自動塗り

```
線画
↓
領域解析
↓
新規塗りつぶし生成
↓
既存自動塗り置換
```

### 既存自動塗りを更新

```
既存自動塗りレイヤー
↓
透明部分保護（α値維持）
↓
色プリセット反映
↓
形状維持
```

既存更新は透明ピクセルをそのまま保ち、不透明ピクセルの色のみ置換するため処理が軽く、低スペック端末に適している。

---

## プリセット管理

- 保存プリセット・ブラシプリセット・自動塗りプリセットは全部独立
- 自動塗りプリセットはプロジェクト保存とは独立して管理
