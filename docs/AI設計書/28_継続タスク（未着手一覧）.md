## 未着手：実機でないと真偽が確認できない不具合報告

以下はいずれもコードレビューを複数回実施し、配線・計算式ともに問題は見当たらなかった
（詳細は各項目の記述および`12_実装チェックリスト.md`の追記を参照）。実機のない環境での
静的解析には限界があるため、着手する場合はまず実機での再現確認から始めること。

- **フレーム一覧をタップしても現在地（カレントフレーム）が移動しない**（キャンバスモード側の
  `FrameStripWidget`）。各フレームの`GestureDetector.onTap`は`widget.onFrameSelected(index)`を
  呼び、`canvas_screen.dart`側で`onFrameSelected: (idx) => setState(() => _currentFrame = idx)`と
  正しく配線されている。`IgnorePointer`で囲われた中央の現在フレーム枠（2026年8月20日に
  色固定の赤からテーマの更新マーク色連動へ変更済み、`FrameStripWidget`参照）がタップを
  奪っている可能性も確認したが、`IgnorePointer`はヒットテスト対象から正しく除外される
  ため問題なし。再現するなら実機のログ（onTapが実際に呼ばれているか）から調査すること。
- **フレーム一覧を左右にスワイプしたとき、中央の現在フレーム枠に一番近いフレームへ自動吸着し、
  そのフレームを現在地にする**（タイムラインモードと同じ挙動に揃える）。
  そのときキャンバス・レイヤーパレット・タイムラインモードの表示も連動すること。
  `_scrollToCurrent`の`target = currentFrame * itemExtent`と`_handleScrollEnd`の
  `nearest = (offset / itemExtent).round()`は、`sidePadding = (ビューポート幅-itemExtent)/2`
  を用いた中央揃えの計算式として数式上つじつまが合っている（左右パディング分がちょうど
  打ち消し合う）ことを手計算で確認済み。
- **定規ツールをタップしても何も表示されない**という報告があった。`_showRulerPanel`は他の
  正常動作しているパネル（ブラシ・トーン・スタンプ等）と全く同じ`_sidedPanel(...)`パターンで
  画面全体の最前面Stackに配置されており、`_toggleRuler`（トグル）・`_rulerPanel()`（内容）とも
  配線に問題は見当たらない。フローティングパネルを最前面Stackへ移した過去の修正で解消して
  いる可能性が高い。
- **プレビュー下端のドラッグハンドルを動かすと「表示範囲」が変わってしまい「サイズ」が
  連動しない**という報告が一度あった。`onVerticalDragUpdate`が`_previewHeightDragOverride`を
  更新し、`SizedBox(height: previewHeight, child: _buildPreviewContent())`がその値をそのまま
  高さに反映、内側は`Positioned.fill`＋`RawImage(fit: BoxFit.contain)`で外側のサイズに
  アスペクト比を保って収まる作りになっており、理論上は正しくサイズ連動するはず。根本原因は
  特定できていない（ヒット領域拡大のみ対応済み）。
- **チュートリアルの吹き出しがどこをタップしても消えない**という報告があったが、
  `first_use_tooltip.dart`を確認した限り、既に全画面の透明バリアで「どこでも閉じられる」
  実装になっていた。過去に修正した多重表示バグが原因だった可能性がある。
