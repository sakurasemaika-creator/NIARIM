# 32. 作品広場タグ・縦画面モード仕様

最終更新: 2026-09-06

この文書は、作品広場のタグ機能・検索導線・縦画面モードについて、実装済み内容と今後バックエンド/YouTube実プレーヤーへ接続する際の不変要件をまとめる。

## 1. タグ機能

### 1.1 権限

- ログイン済みユーザーは、作者・視聴者を問わず作品へタグを追加できる。
- ロックされていないタグは、作者・視聴者を問わず削除できる。
- タグのロック/ロック解除は、その作品の作者本人だけが行える。
- ロック中のタグは、作者を含め直接削除できない。作者が削除したい場合も、先にロック解除してから削除する。
- 権限制御はUIだけに依存せず、バックエンドでも必ず検証する。

現行バックエンドの `PATCH /works/{id}/tags` は上記を実装済み。タグは1件30文字、**1作品10件まで**とし、第三者による作品アイテム肥大化を防ぐ。

### 1.2 表示と検索導線

- 作品詳細および縦画面モードのタグはタップ可能にする。
- タグをタップした場合、作品広場を「タグ検索」状態で開き、そのタグを初期検索語にする。
- タグ検索は作品の `tags` を対象にする。
- ロック中タグには鍵アイコンを表示する。

## 2. 作品検索

作品検索画面/検索状態には、次の2モードを明示的なタブとして表示する。

1. **キーワード検索**
   - 作品タイトル
   - 作者名
2. **タグ検索**
   - 作品タグ

現在の `CommunityScreen` には検索ロジック自体とタグ検索モードは実装済みだが、UIはアイコンによる切り替えのため、明示的な2タブUIへ置き換える。

タグチップから遷移した場合は、自動的にタグ検索タブを選択する。

## 3. 縦画面モード

### 3.1 基本操作

- 縦長作品を1ページ1作品で表示する。
- 上下スワイプで前後の作品へ移動する。
- 自動再生対象は現在表示中の1作品だけとする。
- ページが切り替わったら前の作品を停止し、新しい現在ページだけを再生する。
- 横画面作品との区別はYouTube側のShorts判定に依存せず、NIARIM投稿元プロジェクトのキャンバス縦横比から `isShort` を決定する。

### 3.2 再生終了時の設定

ユーザーは縦画面モード右上の設定から次のどちらかを選択できる。

- **同じ動画をループ再生**: 再生終了後に0秒へ戻して同じ作品を再生する。
- **次の動画へ自動スクロール**: 再生終了後に次ページへ自動移動し、次の作品を再生する。

選択値は `SharedPreferences` に保存し、次回起動/次回縦画面モードでも維持する。

現在はYouTube実プレーヤーが未接続のため、再生終了イベント自体は発生しない。`community_shorts_viewer.dart` には設定UI・永続化・現在ページ管理・再生終了ハンドラ・次ページ遷移処理まで先行実装し、実プレーヤー接続時に `onEnded` から呼び出す。

有限のダミーデータで「次の動画へ」を選び最終作品まで到達した場合は先頭へ戻す。実バックエンド接続後は、最終作品付近で次ページを先読みし、フィードを継続する方式へ置き換える。

### 3.3 NIARIM固有の制作情報

縦画面モードは単なるShorts/Reelsの複製ではなく、NIARIMで制作された作品を見るための画面とする。動画領域とは別の情報パネルに、少なくとも次を表示する。

- 作者
- 作品タイトル
- タグ
- 動画時間
- 投稿日
- 再生数
- ブックマーク数
- 作品詳細への導線

将来、投稿データが持てるようになったら、キャンバスサイズ、FPS、制作時間、使用ブラシ/素材など「どう作ったか」が分かる情報も追加候補とする。

## 4. YouTube実プレーヤー接続時の注意

- 同時に自動再生するプレーヤーは1つだけにする。
- スクロールで現在ページが変わったら、非表示になったプレーヤーは停止する。
- 独自の作品情報・タグ・アクションUIをYouTubeプレーヤー前面へ重ねず、プレーヤー領域の外に配置する。
- 実際の自動再生条件やプレーヤーUI要件は、接続時点のYouTube API/Developer Policiesを再確認する。

## 5. $0運用との関係

タグ機能そのもののために常時稼働サーバーを追加する必要はない。既存のAWS Lambda Function URL + DynamoDB構成で、タグ追加/削除/ロック/解除を1回のAPI操作として処理する。

現在のバックエンドはDynamoDBをプロビジョンドキャパシティで無料利用枠内に収める設計であり、初期〜小規模利用では月額0円を狙える。ただし無料利用枠を超えるアクセス、ストレージ、データ転送等が発生すれば課金されるため、「利用量に関係なく永久に必ず0円」ではない。
