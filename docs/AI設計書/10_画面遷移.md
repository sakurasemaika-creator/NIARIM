# 10\_画面遷移

## 全画面遷移図

```
起動（スプラッシュ、ロゴを約2秒間表示）
└── ホーム
ホーム
├── ＋ボタン（プロジェクトタブのみ）
│   ├── 新規プロジェクト作成
│   │   └── キャンバス
│   └── 新規フォルダ作成（ダイアログのみ、遷移なし）
├── プロジェクトを開く
│   └── キャンバス
├── お気に入り
├── 共有タブ
│   └── .niashareを開く
│       └── インポート確認
│           └── プロジェクトタブへ追加
├── ゴミ箱
│   ├── 復元 → ホーム
│   └── 完全削除
├── 作品一覧タブ
│   ├── タップ → アプリ内プレビュー（動画/GIF）
│   ├── 共有（写真アプリ等で開く）
│   └── 削除
└── 設定
    └── 各カテゴリ → ホーム

キャンバス
├── ブラシ設定パネル
├── 色選択パネル
│   ├── カラーピッカー
│   ├── 最近使った色
│   └── パレット
├── レイヤーパネル
│   ├── レイヤー追加（通常 / 共通レイヤー / フォルダ / 自動塗り用線画レイヤー / 自動塗りレイヤー）
│   └── 三点メニュー
├── タイムラインモードへ切替
├── キャンバス設定
├── フィルター（描画フィルター）
├── 保存 → キャンバスへ戻る
└── ホームへ戻る

タイムラインモード
├── プレビュー再生
├── フィルター（演出フィルター）
├── 音声追加
├── 動画追加
├── カメラ設定
├── シーン管理（横スクロール）
├── フレーム一覧
├── 三点メニュー（⋮）
│   ├── 保存
│   ├── プロジェクト保存
│   ├── 自動塗り実行
│   └── セーブツリー
└── キャンバスモードへ切替

書き出し
└── 保存完了
    ├── 共有・写真アプリ等で開く
    ├── プロジェクト一覧へ戻る
    └── キャンバスへ戻る
```

---

## 各画面の役割

| 画面               | 役割                                                             |
| ------------------ | ---------------------------------------------------------------- |
| スプラッシュ       | 起動時にロゴを約2秒間表示し、その後ホームへ自動遷移する          |
| ホーム             | プロジェクト管理                                                 |
| キャンバスモード   | 描画専用（描画領域最大化）                                       |
| タイムラインモード | 編集・確認専用（プレビュー・保存・シーン・フレーム・音声・動画） |
| 設定               | アプリ全体の設定                                                 |
| ゴミ箱             | 削除プロジェクトの管理                                           |
| 共有タブ           | 受信した.niashareの管理                                          |
| 作品一覧タブ       | 書き出し済みの動画/GIFファイルの一覧・プレビュー・共有・削除     |
