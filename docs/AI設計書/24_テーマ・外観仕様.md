# 24_テーマ・外観仕様

## 概要

MIRANIMAではUI全体の外観を自由に変更できる。変更はアプリ全体へ即時反映される。キャンバスデータには影響しない。無料版・プレミアム版共通で利用できる。

---

## カスタマイズ項目

| 項目 | 内容 |
|------|------|
| ベーステーマ | ライト / ダーク / システム設定に合わせる |
| アクセントカラー | ボタン・選択枠・スライダーなどの強調色 |
| 文字色 | UI全体の文字色 |
| パネル背景色 | レイヤーパネル・ツールパネルなどの背景色 |
| メニュー背景色 | 三点メニュー・ポップアップの背景色 |
| 選択色 | 選択中項目のハイライト色 |
| 更新マーク色 | ❗アイコンの色 |

すべてカラーピッカー（HSV / RGB / HEX）で自由に設定できる。

---

## ベーステーマ

| テーマ | 内容 |
|--------|------|
| ライト | 白を基調としたUI |
| ダーク | 黒・グレーを基調としたUI |
| システム設定に合わせる | AndroidのOSテーマ設定へ追従 |

初回起動時の初期値：システム設定に合わせる

---

## アクセントカラー

UIの強調表示に使用する。

適用対象例：選択中タブ / 選択枠 / スライダー / ON状態スイッチ / ボタン / 更新マーク / ダイアログの強調色 / タイムラインの現在フレーム
---

## テーマプリセット

### 保存内容

1つのテーマプリセットには以下を保存する。

- ベーステーマ
- アクセントカラー
- 文字色
- パネル背景色
- メニュー背景色
- 選択色
- 更新マーク色
- （将来追加されるUIカラー設定も含められるよう拡張可能）

### 操作

| 操作 | 内容 |
|------|------|
| 新規作成 | 現在の設定を新しいプリセットとして保存 |
| 上書き保存 | 既存プリセットを現在の設定で上書き |
| 名前変更 | プリセット名を変更 |
| 複製 | プリセットをコピーして追加 |
| 削除 | プリセットを削除 |
| 並び替え | ドラッグで順序変更 |
| お気に入り登録 | よく使うプリセットをお気に入りに登録 |
| 読み込み | .mirathemeファイルを読み込んでプリセット一覧へ追加 |
| 共有 | .mirathemeファイルとして書き出して共有 |
| 適用 | タップで即座に反映 |

### 一覧表示

各プリセットに色設定から自動生成したサンプルUIイメージを表示する。名前だけでなく見た目で選べる。

### 初期プリセット

アプリ初期状態で以下を用意する。

- Default Light
- Default Dark
- Blue
- Green
- Purple

---

## テーマの共有（初期実装）

テーマプリセットを `.miratheme` ファイルとして書き出し・読み込みができる。

### 書き出しフロー

```
テーマプリセット選択
↓
「テーマを書き出し」
↓
.miratheme ファイルを生成
↓
共有
```

### 読み込みフロー

```
.miratheme ファイルを受け取る
↓
プレビュー表示
↓
保存
↓
プリセット一覧へ追加
```

---

## 引き継ぎ（.miratra）との連携

.miratra による端末移行時にUIテーマプリセットを含めることができる。

```
☑ UIテーマ
☑ ブラシ
☑ パレット
☑ 自動塗りプリセット
☑ 設定
```

新しい端末でも同じ作業環境をそのまま復元できる。クラウド不要・ローカルファイルのみで完結。

---

## UIテーマとワークスペースの区別

UIテーマとワークスペースは完全に独立した設定である。

| 設定 | 保存内容 |
|------|----------|
| UIテーマ | 配色・アイコン・外観のみ（ツール配置は保存しない） |
| ワークスペース | 表示ツール・早替えツール・パネル配置 |

テーマを変更してもワークスペースは変わらない。ワークスペースを変更してもテーマは変わらない。

---

## プレビュー

テーマ変更画面では変更前にプレビューを表示する。

プレビュー対象：トップ画面 / キャンバス画面 / タイムライン画面

---

## 設定画面での位置づけ

設定画面の「UI設定」カテゴリ内に配置する。ワークスペース設定と同じカテゴリで管理する。

```
設定
├ UI設定
│   ├ テーマ・外観
│   │   ├ ベーステーマ
│   │   ├ カラーカスタマイズ
│   │   └ テーマプリセット管理
│   └ ワークスペース設定
│       ├ ツールバー編集
│       ├ パネル配置
│       └ ワークスペース保存・読込
```
