# 24\_テーマ・外観仕様

## 概要

NIARIMではUI全体の外観を自由に変更できる。変更はアプリ全体へ即時反映される。キャンバスデータには影響しない。無料版・プレミアム版共通で利用できる。

---

## カスタマイズ項目

| 項目             | 内容                                     |
| ---------------- | ---------------------------------------- |
| ベーステーマ     | ライト / ダーク / システム設定に合わせる |
| アクセントカラー | ボタン・選択枠・スライダーなどの強調色   |
| 文字色           | UI全体の文字色                           |
| パネル背景色     | レイヤーパネル・ツールパネルなどの背景色 |
| メニュー背景色   | 三点メニュー・ポップアップの背景色       |
| 選択色           | 選択中項目のハイライト色                 |
| 更新マーク色     | ❗アイコンの色                           |

すべてカラーピッカー（HSV / RGB / HEX）で自由に設定できる。

---

## ベーステーマ

| テーマ                 | 内容                        |
| ---------------------- | --------------------------- |
| ライト                 | 白を基調としたUI            |
| ダーク                 | 黒・グレーを基調としたUI    |
| システム設定に合わせる | AndroidのOSテーマ設定へ追従 |

初回起動時の初期値：システム設定に合わせる

---

## アクセントカラー

UIの強調表示に使用する。

## 適用対象例：選択中タブ / 選択枠 / スライダー / ON状態スイッチ / ボタン / 更新マーク / ダイアログの強調色 / タイムラインの現在フレーム

## テーマプリセット

### 保存内容

1つのテーマプリセットには以下を保存する。

- ベーステーマ
- アクセントカラー
- 文字色
- パネル背景色
- メニュー背景色
- 選択色
- 更新マーク色
- （将来追加されるUIカラー設定も含められるよう拡張可能）

### 操作

| 操作           | 内容                                              |
| -------------- | ------------------------------------------------- |
| 新規作成       | 現在の設定を新しいプリセットとして保存            |
| 上書き保存     | 既存プリセットを現在の設定で上書き                |
| 名前変更       | プリセット名を変更                                |
| 複製           | プリセットをコピーして追加                        |
| 削除           | プリセットを削除                                  |
| 並び替え       | ドラッグで順序変更                                |
| お気に入り登録 | よく使うプリセットをお気に入りに登録              |
| 読み込み       | .niathemeファイルを読み込んでプリセット一覧へ追加 |
| 共有           | .niathemeファイルとして書き出して共有             |
| 適用           | タップで即座に反映                                |

### 一覧表示

各プリセットに色設定から自動生成したサンプルUIイメージを表示する。名前だけでなく見た目で選べる。

### 初期プリセット

アプリ初期状態で、虹7色（赤・橙・黄・緑・青・藍・紫）× ライト/ダークの
14種類を用意する。「赤」はアプリの既定色である珊瑚ピンクが該当する。

- ポップ（ライト）＝赤・ライト（既定選択。baseThemeはシステム設定に合わせる）
- ポップ（ダーク）＝赤・ダーク
- オレンジ（ライト／ダーク）
- イエロー（ライト／ダーク）
- グリーン（ライト／ダーク）
- ブルー（ライト／ダーク）
- インディゴ（ライト／ダーク）
- パープル（ライト／ダーク）

## テーマの共有（初期実装）

テーマプリセットを `.niatheme` ファイルとして書き出し・読み込みができる。

### 書き出しフロー

```
テーマプリセット選択
↓
「テーマを書き出し」
↓
.niatheme ファイルを生成
↓
共有
```

### 読み込みフロー

```
.niatheme ファイルを受け取る
↓
プレビュー表示
↓
保存
↓
プリセット一覧へ追加
```

## 引き継ぎ（.niatra）との連携

.niatra による端末移行時にUIテーマプリセットを含めることができる。

```
☑ UIテーマ
☑ ブラシ
☑ パレット
☑ 自動塗りプリセット
☑ 設定
```

新しい端末でも同じ作業環境をそのまま復元できる。クラウド不要・ローカルファイルのみで完結。

## UIテーマとワークスペースの区別

UIテーマとワークスペースは完全に独立した設定である。

| 設定           | 保存内容                                           |
| -------------- | -------------------------------------------------- |
| UIテーマ       | 配色・アイコン・外観のみ（ツール配置は保存しない） |
| ワークスペース | 表示ツール・早替えツール・パネル配置               |

テーマを変更してもワークスペースは変わらない。ワークスペースを変更してもテーマは変わらない。

## 色設定の自由度と、操作不能からの復旧

テーマ・外観は、ユーザーが自由に色を組み合わせられるようにする機能である。一般的に読みにくい組み合わせ、低コントラスト、色相差が小さい組み合わせもユーザーの選択として許容し、コントラスト比・配色美・アクセシビリティ基準だけを理由にテーマ色の保存を拒否しない。設定時にエラーを出したり、変更前の色へ巻き戻したりするのではなく、操作不能になりかねない現在のテーマから自力で復旧できる手段を提供する。

### 起動画面右上のリセットボタン

- 現在のテーマが、設定画面や起動画面の主要導線などを事実上操作不能にしかねない組み合わせと判定された場合、起動画面の右上にリセットボタンを表示する。
- 表示条件は、テーマがどの経路から入ったかに依存しない。テーマ・外観での手動変更、プリセット適用、テーマファイルのimport、.niatraによる端末引き継ぎ、その他の設定反映でも、現在のテーマが同じリスク判定に該当すれば表示する。
- ボタンを押すと既定のライトテーマへ戻し、復旧後はリセットボタンを非表示にする。リスク判定に該当しない通常テーマでは表示しない。
- ボタンの文字は黒文字＋白縁取り、アイコンも黒を白で縁取った固定色とする。ボタン外周は黒/白の二重線などで、明るい背景・暗い背景のどちらでも識別できるようにする。これは復旧専用の唯一の固定色例外であり、通常UIのテーマ色を固定してはならない。

### リスク判定の位置づけ

- 現行実装では、相対輝度のコントラスト比と実UI上の重要な色ペアを、リセットボタンを表示するための保守的な目安として使う。ユーザーがその色を見分けられるか、人間の知覚を完全に予測するものではない。
- この判定はボタンの表示にのみ使い、保存の可否・エラー・色の巻き戻しには使わない。判定に該当してボタンが表示されても、色を自動補正したり別の値に差し替えたりしない。
- 検証対象のペアは、実UIで操作や復帰に関係する文字色×パネル背景色、文字色×メニュー背景色、主要導線の文字色×背景色などから確認する。全項目の色差を総当たりで強制しない。
- 色相対比・明度対比・彩度対比・補色対比・縁辺対比などは見え方を理解する観点とし、個別の最低色差や保存拒否条件を設けない。彩度0%では色相値を変えても無彩色であること、HSLの明度L=0%/100%は黒/白、HSVのV=0%は黒であることなど、設定値と描画色が一致しないケースも判定の確認時に留意する。
- テーマ色を変更したら保存されること、アプリを再起動しても保持されること、危険判定時に起動画面右上の固定色ボタンが出ること、押すと既定テーマへ戻ることを実操作で確認する。
