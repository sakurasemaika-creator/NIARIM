## 自動塗り

- [x] プリセット管理（プロジェクト保存と独立、AutofillPresetService）
- [x] 更新マーク（レイヤーパネル。タイムライン側の❗表示は未実装）
- [x] 更新マーク：タップで自動塗りダイアログへ遷移
- [x] 書き出し前の未更新警告
- [x] 自動塗り実行ダイアログ：塗りなおし / 色更新 の2択
- [x] 塗りなおし：形状破棄→領域再判定→一から塗りなおす
- [x] 色更新：形状維持→不透明度ロック→最新色で塗りつぶす
- [x] 線画直下に自動塗りレイヤーが存在する → そのレイヤーを更新
- [x] 線画直下に自動塗りレイヤーが存在しない → 直下へ新規生成
- [x] 手動配置した自動塗りレイヤーも塗りなおし・色更新の対象（位置は変更しない）
- [x] 新規追加された線画レイヤーは色更新選択時でも必ず新規生成→一から塗る
- [ ] 自動塗り対象：ベタ塗り・トーン（ブラシ・スタンプは対象外）（対象種別の判定は未実装）
- [ ] 自動塗りプリセット：パーツごとに塗り色・線画色・ブレンドモード・レイヤー不透明度・トーン設定を保存
- [ ] 自動塗りプリセット：不透明度はレイヤー不透明度として反映（塗り色は100%固定）
- [ ] 自動塗りプリセット：ブレンドモードは自動塗りレイヤー・自動塗り用線画レイヤー両方へ反映
- [ ] 自動塗りプリセット：設定完了マーク・未設定時は保存不可
- [ ] 自動塗りプリセット：グラデーション（直線・放射）対応
- [ ] 自動塗りプリセット：リアルタイムプレビュー
