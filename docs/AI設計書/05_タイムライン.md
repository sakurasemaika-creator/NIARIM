# 05\_タイムライン

## 基本操作

- フレーム追加・コピー・削除・範囲選択・演出フィルター適用・自動塗り実行
- 複数選択時：全選択・全解除ボタンを表示
- タイムラインモードから複数フレームに対して自動塗りを一括実行できる（選択フレーム・シーン単位・全フレーム）

### 複数選択の同種ルール

**最初に選択したオブジェクトと同じ種別のオブジェクトのみ追加選択できる。**

このルールはタイムラインモード・キャンバスモードのレイヤーパレットで共通であり、ユーザーが「今は何をまとめて操作しているのか」を常に明確に保つための設計である。

| 最初に選択したオブジェクト | 追加選択できるオブジェクト |
| -------------------------- | -------------------------- |
| フレーム                   | フレームのみ               |
| シーン                     | シーンのみ                 |
| 動画素材                   | 動画素材のみ               |
| 画像素材                   | 画像素材のみ               |
| 音源                       | 音源のみ                   |
| ウォーターマーク           | ウォーターマークのみ       |

異なる種別のオブジェクトは追加選択できない（グレーアウト表示）。

## シーン管理

- 内部フォルダ名：Scene0001形式（4桁連番）
- 内部indexは0始まり、ユーザー表示は1始まり（`Scene${index + 1}`で生成）
- シーン切替：タイムライン上部のシーン一覧（横スクロール）から選択
- シーン追加：シーン一覧の「＋」ボタン

### シーン一覧の操作

| ジェスチャー                               | 動作                                                     |
| ------------------------------------------ | -------------------------------------------------------- |
| シングルタップ（通常時）                   | シーン名変更ダイアログを表示                             |
| シングルタップ（複数選択モード・選択済み） | そのシーンのみ選択解除                                   |
| シングルタップ（複数選択モード・未選択）   | 何もしない                                               |
| ダブルタップ                               | 当該シーンへ移動（選択）                                 |
| 長押し                                     | シーン内フレームを全選択（フレーム複数選択モードへ移行） |

フレーム一覧と操作体系を統一する（長押し＝フレーム全選択、ダブルタップ＝シーン移動）。

### シーンチップの三点メニュー

| 項目         | 内容                                                                |
| ------------ | ------------------------------------------------------------------- |
| シーン名変更 | シーン名変更ダイアログを表示                                        |
| シーン削除   | 確認ダイアログを表示してから削除（シーンが1件のみの場合は削除不可） |

移動は複数選択機能で対応するため、三点メニューには追加しない。

### シーン削除の確認ダイアログ

シーン削除時（三点メニューまたは複数選択モードの削除ボタン）は確認ダイアログを表示する。

```
「シーン名」を削除しますか？

シーン内の全フレーム・共通レイヤー・動画素材・画像素材・ウォーターマークを含むすべてのデータが削除されます。

[キャンセル]  [削除]
```

複数選択時は「選択中のN件のシーンを削除しますか？」と表示する。

### シーンチップ長押し

長押しすると「シーン内フレームを全選択」を実行し、そのシーン内に存在するすべてのフレームをフレーム複数選択状態にする。その後は通常のフレーム複数選択と同じ操作（削除・移動・複製）を行える。

### シーン複数選択モード

シーン一覧の「選択」ボタンを押すと複数選択モードを開始する。複数選択モード中に行える操作：

| 操作 | 内容                                                                     |
| ---- | ------------------------------------------------------------------------ |
| 削除 | 選択中シーンをすべて削除（確認ダイアログあり。全シーン選択時は削除不可） |
| 移動 | カーソル固定方式で選択シーンを移動                                       |

複数選択されたシーンは選択順ではなく現在の並び順を維持した連続ブロックとして扱う。

#### 複数選択モードの終了条件

- 「全解除」ボタンをタップ（選択がすべて解除され通常モードへ戻る）
- 選択済みシーンをシングルタップ → そのシーンのみ解除。最後の1件を解除した時点で通常モードへ戻る
- 操作（移動・削除）が正常に完了した場合

未選択シーンをシングルタップしても何も起こらない。

#### 移動キャンセル時の挙動

移動中にキャンセルした場合は複数選択モードへ戻る。選択状態は維持する。通常モードへは戻らない。

これによりユーザーは、移動をやめて削除へ切り替える・挿入位置だけ変更して再度移動する・選択内容を一部変更するといった操作を選択し直すことなく続けて行える。

フレーム複数選択・シーン複数選択の両方で同じ挙動とし、一貫した操作体系を維持する。

#### 複数選択モード中のUI

- シーンチップにチェックアイコンを表示（選択済み：`check_circle`、未選択：`radio_button_unchecked`）
- 三点メニューは非表示
- 全選択・全解除ボタンを表示
- 削除・移動ボタンを表示

### シーン並び替え手順（カーソル固定方式）

1. 複数選択モードで対象シーンを選択
2. 「移動」ボタンを押す
3. 画面中央に固定カーソルを表示。カーソル直下に吹き出しプレビューを表示
4. シーン一覧をスクロールしてカーソル位置（挿入位置）を決定
5. 「決定」で確定

移動後も選択中シーン（`_selectedSceneId`）は解除せず、IDで追従させる。

シーン移動は複数選択機能（1件選択を含む）からのみ実行できる。1件選択・複数選択の両方を同じ操作体系で扱う。

**例1：1件選択で移動**

```
移動前：Scene1 / Scene2 / Scene3 / Scene4
↓ Scene2を1件選択 → 【移動】→ Scene3とScene4の間に挿入
移動後：Scene1 / Scene3 / Scene2 / Scene4
```

**例2：複数選択で移動**

```
移動前：Scene1 / Scene2 / Scene3 / Scene4
↓ Scene2・Scene3を選択 → 【移動】→ Scene4の後に挿入
移動後：Scene1 / Scene4 / Scene2 / Scene3
```

## フレーム・シーン複製／移動時のカーソル吹き出し表示

複製・移動時は、画面中央に表示されるカーソルの直下へ、吹き出し形式で「現在移動・複製する対象」を表示する。

### 選択数による表示

| 選択数  | 表示内容                               |
| ------- | -------------------------------------- |
| 1件     | サムネイル1枚のみ                      |
| 2件     | 先頭サムネイル＋白カード1枚            |
| 3件以上 | 先頭サムネイル＋白カード2枚（最大3枚） |

- 先頭のサムネイルのみ実画像を表示。2枚目以降は白塗り＋枠線の白カードのみ
- カードは少しだけ左右・上下にずらし、1〜2°わずかに回転させ「紙が重なっている」見た目にする
- 吹き出し右上に選択数バッジを表示（例：×2、×12）
- 吹き出し・カード・バッジはFlutterウィジェットのみで描画（画像素材不使用）
- 4件以上選択されている場合でも表示は最大3枚まで

### 表示内容の切り替え

| 対象               | サムネイル内容                 |
| ------------------ | ------------------------------ |
| フレーム複製・移動 | フレームのサムネイル           |
| シーン複製・移動   | シーン先頭フレームのサムネイル |

この吹き出し表示はフレーム複製・フレーム移動・シーン複製・シーン移動すべてで共通仕様とする。

## 再生コントロール

タイムラインモードに表示。アイコン表示（文字なし）。

| ボタン       | 動作                                                               |
| ------------ | ------------------------------------------------------------------ |
| ⏮           | 最初のフレームへ移動                                               |
| ⏪           | 前のフレームへ                                                     |
| ▶ / ⏸        | 再生 / 一時停止（同位置で切替）                                    |
| ⏩           | 次のフレームへ                                                     |
| ⏭           | 最後のフレームへ移動                                               |
| 🔁（ループ） | ループ再生ON/OFF切替。ONの間はアクセントカラーで強調表示。既定はON |

ループOFFの状態で再生すると、最終フレームに到達した時点で自動的に一時停止する
（先頭へは戻らない）。ループONの場合は従来どおり最終フレームから先頭へ戻り、
再生を継続する。

## タイムライン素材

画像素材・動画素材・ウォーターマークはすべて**タイムライン素材**として統一的に扱う。

### 共通仕様

- 開始フレーム・終了フレームを持つ
- タイムラインモードで追加する
- タイムライン上でドラッグハンドルにより表示範囲を変更できる
- 表示中のフレームではキャンバスモードのレイヤーパレットへ自動表示される
- 表示範囲外のフレームではレイヤーパレットに表示されない

### タイムライン上でのドラッグ操作（タスク#99）

- クリップ本体を長押ししてドラッグ：表示開始位置を移動（クリップの長さは
  変わらない）
- クリップ左端のハンドルをドラッグ：右端（終了フレーム）を固定したまま
  開始位置と長さを変更
- クリップ右端のハンドルをドラッグ：開始位置を固定したまま長さ（終了
  フレーム）を変更
- いずれもフレーム単位でスナップし、タイムライン全体の範囲外へは
  移動・拡張できない
- ドラッグ確定時（指を離した時点）に永続化される。音声クリップは元々
  対応済みだったが、画像・動画クリップ（`LayerType.timelineImage`/
  `timelineVideo`）は表示開始位置・使用範囲の変更が実際には保存され
  ない不具合があったため、あわせて修正した

### 役割分担

| 機能                                 | 担当                                                       |
| ------------------------------------ | ---------------------------------------------------------- |
| 表示時間の編集（開始・終了フレーム） | タイムラインモード                                         |
| 重なり順（素材とイラストの前後）     | タイムラインモードの「重なり順」（シーン・フレーム範囲）   |
| イラスト内のレイヤー順               | キャンバスモードのレイヤーパレット                         |
| 位置・拡大・X/Y/Z軸回転・マスク      | タイムラインモードの素材の編集パネル・プレビューのドラッグ |
| 複製                                 | タイムラインモード                                         |
| 削除                                 | 素材の編集パネル・レイヤーパレット（素材全体を削除）       |

### 重なり順（2026-10-16 ユーザー指定で追加）

ユーザー指定：「レイヤー順を細かくフレームごと、シーンごとに変えられるように」「素材の表示順はテキスト1とテキスト2の間にフレームのイラストを表示させるとかもできるように」。以前の「タイムラインモードにレイヤー並び替え機能は作らない」は撤回した。

- 重なり順の単位は「フレーム（イラスト）」と各素材トラックの列（テキスト1・テキスト2…・画像1…・動画1…）。フレーム（イラスト）はそのフレームの描画レイヤー（通常・共通・自動塗り・テキストレイヤー等）をまとめたもので、その中の順番は従来どおりキャンバスモードのレイヤーパレットで決める。
- シーンごとに`Scene.stack`（`SceneStack`）を持つ：シーン全体の重なり順`order`（先頭が最前面）と、フレーム範囲ごとの重なり順`ranges`（`StackRange`：開始・終了フレームと順番。範囲どうしは重ならない。範囲内のフレームでは範囲の順番がシーン全体の順番より優先される）。.niaproのシーンの`stack`。2026-10-16版の「このフレームから」の変更`changes`（次の変更まで続く）は読み込み時に範囲へ直す（各変更から次の変更の前のフレームまで、最後の変更はシーンの終わりまで＝`kStackRangeOpenEnd`）。
- 未指定のときの順番は前から：テキストの列（テキスト1が最前面）→フレーム（イラスト）→画像の列→動画の列。ウォーターマークは常に最前面。保存された順番に無い列（後から足した列）は、既定の順番での位置へ差し込む。
- タイムラインのプレビュー・書き出し・キャンバスの表示はすべてこの順番で重ねる（`lib/engine/timeline_stack.dart`の`stackFrameLayers`）。以前は素材がホームのフレームでは最前面、他のフレームでは最背面と、フレームによって前後が入れ替わっていた。素材は表示範囲のフレームにだけ出る（ホームのフレームでも範囲外なら出さない）。
- 編集はツールバーの「重なり順」（素材の編集パネルの見出しからも開ける）。プレビューの下に出るパネルで、各項目のつまみのドラッグか↑↓で並べ替える。「この重なり順を使う所」を4択のラジオボタンで選ぶ（2026-10-17 ユーザー指定：「「F1から」というタブを作るよりも「フレーム指定」というタブにして〇フレーム目〜〇フレーム目のように」「手打ちでフレーム数を打てるようにするのに加えて全てのフレーム、とシーン複数選択の3種類でラジオボタンに」「現在のシーン全体というものを追加して四択に」）：
  - **現在のシーン全体**：今のシーンの`order`。
  - **フレーム範囲**：範囲の一覧（「F1〜F6」のチップ。タップでその範囲を選んで先頭フレームへ移動）、「F○から範囲を追加」（今のフレームが範囲に入っていないときだけ）、開始・終了フレームの入力欄（数字を打って確定かフォーカスを外すと反映）とRangeSlider。範囲は隣の範囲と重ならないように抑え、動かした側の端のフレームへプレビューを移す。範囲の削除ボタン付き。
  - **シーン複数選択**：シーンのチップを選び（最低1つ）、並べ替えると選んだシーンすべての`order`がその順番になる。
  - **全てのフレーム**：全シーンの`order`を同じ順番にする。
  - シーン単位の3つは、対象のシーンにフレーム範囲があると「フレーム範囲を指定したフレームは、その範囲の順番が優先されます」と出す。表示する順番は今のシーン（複数選択では選んだ中の最初のシーン）の順番で、対象のシーンの列すべてを並べる。
  - パネルを開いたときは、今のフレームが範囲に入っていれば「フレーム範囲」、そうでなければ「現在のシーン全体」を選んでおく。
- 項目を長押しすると複数選択になる（2026-10-17 ユーザー指定：「重なり順も複数選択できるようにして複数の素材を一気に表示階層移動できるように」「複数選択は他と同じく素材長押しで開始、全解除ボタンも必要」。レイヤーパレットと同じ操作）。各項目にチェックが付き、タップで選択を切り替える。パネルの下に「N件選択中・全選択・全解除」と「最前面へ・手前へ・奥へ・最背面へ」のバーが出る。選んだ項目の矢印とつまみのドラッグも、選んだ項目をまとめて動かす（間に挟まった項目を1つずつ飛び越え、選んだ項目どうしの順番は保つ。`lib/engine/timeline_stack.dart`の`stepStackSelection`・`stackSelectionToEnd`・`dragStackSelection`）。4択のどれでも使える。全解除か、最後の1つの選択を外すと終わる。
- 列を削除すると後ろの列の番号が詰まるので、重なり順に保存した列の番号も同時に詰める（`ProjectService.removeTrackRow`）。
- レイヤーパレットの素材の行は並び替えできない（順番はタイムラインの重なり順で決まるため）。

### マスク

- テキスト・画像・動画の各素材（`Layer.mask`）と、フレーム（イラスト）（`SceneStack.frameMask`）にマスクを付けられる。形は「なし・四角・楕円」で、中心X・Y・幅・高さ（キャンバスに対する%）・回転・ぼかし（境目のなめらかさ、短い辺に対する%）・反転（形の内側を隠す）を指定する（`LayerMask`、編集UIは`lib/widgets/layer_mask_editor.dart`）。
- 素材のマスクは素材と一緒に動く（素材の位置・回転・拡大の前の向きで指定）。フレーム（イラスト）のマスクはシーンごとで、描画レイヤーをまとめて切り抜く。テキスト・画像・動画には効かず、キャンバスモードの描画中にも効かせない（タイムラインのプレビューと書き出しだけ）。

### テキスト素材・素材の編集パネル

ユーザー指定：「タイムラインモードではテキストの追加もできるように」「画像素材と同じくテキストも複数タイムラインの列を追加できるように」「テキストもX軸Y軸Z軸回転などをスライダーやドラックで手軽に調整できるように」「UIは任せますが、もっともユーザー目線で操作しやすくわかりやすいように」。

- ツールバーの「素材を追加」（テキスト・画像・動画・音声の追加を1つのメニューにまとめた。種類ごとにボタンを並べると10個になり、420px幅でも書き出しボタンが画面外へ出た）→「＋テキスト」で文字と表示範囲（開始・長さ）を入れて追加する（`LayerType.timelineText`、画像・動画と同じ表示範囲レイヤー）。文字はキャンバスの中心に置き、白い文字に黒い縁取り・キャンバスの短い辺の約1/8の大きさで始まる。同じ時間に重なる素材があれば、空いている列（無ければ新しい列）へ自動で置く（画像・動画・音声も同じ）。追加するとそのまま編集パネルが開く。画像素材の追加（「＋画像」）とトラックも復活させた。
- テキスト・画像・動画のクリップをタップすると、**プレビューの下（トラックの代わり）に編集パネル**が開く。モーダルのシートだとプレビューが隠れて調整しにくいため。パネルは「文字（テキストのみ）・配置・マスク・動画（動画のみ）」に分かれ、見出しに重なり順・複製・削除・閉じるのボタンがある。
- 文字：内容・フォント・大きさ・太字・斜体・縦書き・色（よく使う8色＋カラーピッカー）・揃え・行間・字間・縁取り（色・太さ）。キャンバスのテキストツールと同じ`TextObject`・`rasterizeTextObject`で、文字の塊の中心をキャンバスの中心に置いて描く（`rasterizeTimelineText`）。入力が止まってから120msで描き直す。
- 配置：置く列（列の移動・新しい列）・X・Y・拡大縮小・X軸回転・Y軸回転・Z軸回転・不透明度・リセット。X軸・Y軸回転は奥行きのある回転（`lib/engine/perspective_transform.dart`、視点はキャンバスの長い辺の1.5倍の距離）。
- プレビュー上のつまみ（`material_gizmo.dart`）：ドラッグで移動、角の丸で拡大縮小、上の丸でZ軸回転、2本指で移動・拡大・回転をまとめて行う。枠は素材の描かれている範囲を、X/Y軸回転とカメラを通して表示どおりの位置に描く。今のフレームに素材が出ていないときは「F○〜F○に表示」と出す。
- キーフレーム：キーフレームが1つ以下のうちは、配置の変更は素材全体に効く（動かない）。「F○にキーフレームを追加」で今の値を記録すると（無ければ表示開始フレームにも1つ作る）2つ以上になり、以後の変更は今のフレームの値として記録され、間は自動でつながる（After Effects等と同じ）。素材を丸ごと動かすとキーフレームも一緒にずれる（端のハンドルで長さを変えたときはずらさない）。
- 動画：音量・使用開始F・使用終了F（以前の詳細シートから移した）。音声クリップは従来どおり詳細シート。

### 削除の仕様

レイヤーパレットで削除した場合はその素材全体（全表示範囲）を削除する。特定フレームのみ削除という動作にはしない。

### 通常レイヤーの最低枚数

各フレームには `LayerType.normal` を最低1枚保持する。`LayerType.normal` はユーザーが直接描画するための基本レイヤーであり、`folder`・`autoFillLineart`・`autoFill` はその代替にならない。

| 判定対象                                         | 内容                                               |
| ------------------------------------------------ | -------------------------------------------------- |
| `LayerType.normal` の枚数 == 1                   | 削除ボタンをグレーアウト（タップ不可・長押し不可） |
| `LayerType.normal` の枚数 >= 2                   | `normal` レイヤーは削除可能                        |
| `folder`・`autoFillLineart`・`autoFill` の枚数   | 判定に含めない                                     |
| タイムライン素材（画像・動画・ウォーターマーク） | `normal` 枚数に関係なく常に削除可能                |

エラーダイアログ・トーストは表示しない。

## 演出フィルター

タイムラインへ適用する非破壊編集フィルター。映像（フレーム）にのみ適用され、動画トラック・音声トラックには影響しない。

### 適用範囲

演出フィルターは以下の単位で適用できる。

- 選択フレーム
- シーン全体
- 全フレーム

### 初期実装フィルター

- フェード（色指定）
- ガウスぼかし
- レンズぼかし
- モザイク
- 色収差
- ノイズ
- アニメ風加工
- お気に入り・お気に入りのみ表示

詳細は 18\_フィルター仕様.md を参照。

## EndCard Track（エンドロゴ管理）

EndCard Trackは素材トラック群の最下段（音源トラックの下）に常時表示する。

### タイムライン表示順

```
フレーム
シーン
共通レイヤー
画像
動画
音源
エンドカード  ← 素材トラック群の最下段
```

ウォーターマークは専用トラックを作らない。画像素材と同じ画像トラックに追加される。

エンドカードは動画素材の一種だが、通常の動画編集作業の邪魔にならないよう最下段へ配置する。

| 版         | 状態                                                                                    |
| ---------- | --------------------------------------------------------------------------------------- |
| 無料版     | 南京錠付きで表示。タップするとPremium誘導ポップアップを表示。削除・移動・編集・操作不可 |
| プレミアム | タップすると削除ボタンを表示。表示／非表示・長さ変更・差し替えが可能                    |
