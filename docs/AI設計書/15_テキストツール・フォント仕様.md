# 15_テキストツール・フォント仕様

## 基本方針

- テキストは編集可能なテキストオブジェクトとして保持する
- ラスター専用アプリのため、編集時のみ文字情報を保持し、表示時はキャッシュ画像を使用する
- ラスタライズも可能

---

## 作成方法

テキストツール選択中に、指・ペン・マウスいずれの入力でキャンバスをタップするとテキスト入力ダイアログを表示する。

```
テキストツールを選択
↓
キャンバスをタップ（指・ペン・マウスすべて対応）
↓
テキスト入力ダイアログ
↓
OK
↓
テキストレイヤーが自動生成される
```

---

## テキストツールの操作仕様

### ① テキストツール選択中

- キャンバスをタップすると新規テキストボックスを作成
- 既存テキストをタップすると編集開始
- 入力方式は指・ペン・マウスすべて対応
- キャンバス移動（パン）・拡大縮小・回転・他ツールへの切替・モード切替は可能
- 描画ツールは使用不可

### ② テキストボックス編集中

- キーボードを表示し文字入力が可能
- フォント・サイズ・色・太字・斜体・行間・文字間隔など各種テキスト設定が可能

### ③ 編集終了

- テキストボックス外をタップすると編集終了
- テキストツール選択状態へ戻る

### ④ テキストボックス変形（テキストツール選択中のみ）

- 一本指ドラッグ：移動
- 二本指ジェスチャー：拡大縮小・回転

画像レイヤーと同じ操作感で統一する。

---

## レイヤー

- テキストレイヤーとして作成される（テキスト1 / テキスト2 / テキスト3 …）
- 通常レイヤーとは別アイコンで表示

---

## 編集可能項目

| 項目 | 内容 |
|------|------|
| 文字内容 | 自由編集 |
| フォント | 一覧から選択 |
| サイズ | スライダー |
| 色 | 通常カラーパレット・スポイト対応 |
| 太字 | ON/OFF |
| 斜体 | ON/OFF（フォント対応時のみ） |
| 行間 | スライダー |
| 文字間隔 | スライダー |
| 横書き・縦書き | 切替 |
| 揃え | 左・中央・右 |

---

## アウトライン（初期実装）

| 項目 | 内容 |
|------|------|
| アウトライン ON/OFF | チェックボックスで切替 |
| アウトライン色 | 自由選択 |
| 太さ | スライダー（0〜20px） |

標準プリセット例：白文字＋黒縁 3px

主な用途：アニメ字幕 / セリフ / タイトル / MV歌詞

---

## フォント

### 初期フォント

- Android標準フォントを使用（フォント選択の「標準フォント」）

### 同梱フリーフォント

「標準フォント」に加え、以下のフリーフォント（Google Fonts配布・
SIL Open Font License、日本語対応）をアプリにあらかじめ同梱し、追加操作
なしでフォント選択から選べる。白光明朝のフォールバック（未対応文字の
補完）を兼ねるため常時同梱が必要な1書体のみとする。

| 表示名 | フォントファミリー |
|--------|---------------------|
| 源ノ明朝 | Noto Serif JP |

### 追加フリーフォント（オンデマンドダウンロード）

初期インストール容量を抑えるため、Google Fonts配布の全ファミリー
（ofl/apache/ufl＝SIL Open Font License・Apache License 2.0・
Ubuntu Font License、いずれも個人・商用問わず無償利用可。約2000書体）
はアプリに同梱せず、カタログ情報（フォント名・ダウンロードURL等の
テキストデータのみ、`assets/font_catalog/font_catalog.json`）のみを
同梱する。ユーザーは`設定 → フォント管理 → 追加フリーフォントを探す`
（`FontCatalogScreen`）から検索・カテゴリ絞り込み（ゴシック／明朝・
セリフ／装飾／手書き風／等幅）で目的のフォントを探し、ダウンロード
ボタンで個別に取得する。取得元はGoogle Fontsの配布元そのもの
（GitHub: google/fonts）。ダウンロード後はユーザー追加フォントと同じ
仕組み（`FontService.importBundledFont()`）で端末内に保存・登録される
ため、以降はオフラインでも利用できる（再ダウンロード不要）。初回
ダウンロード時のみネット接続が必要。

カタログは`scripts/build_font_catalog.py`（google/fontsリポジトリの
METADATA.pbを解析して生成）で作成する。フォントの追加・更新は
google/fonts側の更新を取り込んで同スクリプトを再実行することで行う。

ダウンロード失敗時のエラー表示は下記「エラー表示」の規定に準じる
（ネットワーク未接続時は「ネットワークに接続できません。」）。

ライセンス表記は設定画面「利用規約・ライセンス」に掲載する。

### ユーザーフォント追加

```
設定 → フォント管理 → ＋追加
```

対応形式：TTF / OTF

保存場所：アプリ内 Fonts フォルダ

---

## フォント管理

| 機能 | 内容 |
|------|------|
| 一覧表示 | インストール済みフォントを一覧表示 |
| 検索 | フォント名で検索 |
| 追加 | TTF / OTF を追加 |
| 削除 | フォントを削除 |
| 名前変更 | 表示名を変更 |
| 詳細表示 | フォント名・種類・容量を表示 |

---

## エラー表示

| 状況 | メッセージ |
|------|-----------|
| 未対応フォント | 「このフォントは読み込めません。」 |
| 破損フォント | 「フォントが破損しています。」 |
| 追加フリーフォントのダウンロード時にネット未接続 | 「ネットワークに接続できません。」 |

---

## プロジェクト共有

- 「フォントを含める」を選択した場合のみフォントを同梱
- 不足フォントがある場合：「不足フォントがあります。○○.ttf」と表示し再検索を促す

---

## ラスタライズ

```
三点メニュー → ラスタライズ
```

- 通常レイヤーに変換される
- ラスタライズ後は文字情報の編集不可

---

## アニメーション

通常レイヤーと同様に以下に対応：

- 位置
- 回転
- 拡大縮小
- 不透明度

---

## 描画フィルター・演出フィルター

| フィルター種別 | 対応 |
|--------------|------|
| 描画フィルター（現在レイヤー / 現在フォルダ / 参照レイヤー / 選択範囲） | ○ |
| 演出フィルター（フレーム全体） | ○ |

---

## Undo

通常対応。

---

## パフォーマンス

- 編集時のみ文字情報を保持
- 描画時はキャッシュ画像を使用
- アウトラインもキャッシュ化するため毎フレーム再計算しない
- 低スペック端末でも軽量動作

## 初期実装しない機能（将来追加候補）

- ワープ文字
- グラデーション文字
- OpenType高度機能
- 文字ごとのアニメーション

縦中横・ルビは初期実装しない機能として記載していたが、開発途中で実装済み
（縦書き時の半角英数字の自動回転・縦中横・ルビ入力、いずれもテキスト編集
UIから設定可能。詳細は engine/text_render.dart を参照）。
