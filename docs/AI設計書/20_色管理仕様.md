# 20\_色管理仕様

## 色選択パネル構成

キャンバス画面でツールバーから開くポップアップ。

```
カラーピッカー
────────────
最近使った色（色履歴）
────────────
パレット
```

---

## カラーピッカー

- HSV / RGB / HEX の3形式に対応
- HSV形式：正方形（横軸＝彩度・縦軸＝明度）＋外側カラーサークル（色相）の
  タップ・ドラッグ選択方式。RGB形式：スライダー操作
- HEXは入力・コピー・貼り付けすべて対応（例：#FFAA22）
- スポイトボタンからキャンバス上の色を取得可能

---

## スポイト

- カラーピッカー内のスポイトボタンからキャンバス上の色を取得
- ブラシ使用中に長押しで一時的にスポイトへ切替・離すとブラシへ戻る
- 長押しスポイトの割り当ては設定画面のジェスチャー設定から変更可能
- 取得対象：表示中のすべてのレイヤーを合成した色

---

## 最近使った色（色履歴）

- 直近10色を一覧表示
- タップで即座に選択

---

## パレット

- ユーザーが任意の色を登録できる
- パレットの作成・名前変更・削除が可能
- 複数パレットを切替えて使用できる
- 色の追加・削除・ドラッグで並び替えが可能
- パレットのお気に入り登録に対応

---

## 自動塗り用色プリセット

自動塗り用の色プリセットは「キャラクター・背景などの配色セット」として管理する。色プリセット ≠ 単純な色保存。

### プリセット一覧画面

各パーツは以下のみ表示する。

```
[サムネイル]  パーツ名  [色チップ]  ✓設定完了マーク
```

- 検索・並び替え・お気に入り登録に対応
- 色チップをタップ → 詳細設定ポップアップへ遷移
- パーツ名をタップ → 直接編集（表示名のみ変更・内部パーツIDは変更されない）

### 保存チェック

未設定項目が1つでもある場合は保存不可。赤文字で不足しているパーツ名と設定内容を表示。すべて設定完了になると保存可能。

---

## 塗り色設定

### 設定方法

- 単色
- グラデーション

### 単色

- カラーピッカー
- スポイト
- レイヤー不透明度スライダー（0〜100%）

### グラデーション

**種類**

- 直線（方向：360°）
- 放射状（中央→外側）
- 放射状（外側→中央）

**放射状の基準**

- 円形
- 塗りつぶし形状に合わせる

**共通設定**

- 色数：最大10色
- 各色：カラーピッカー / スポイト / 不透明度
- 色比率：スワイプで各色の境界を変更（直線・放射状ともに対応）
- ぼかし範囲：色が混ざる距離・幅を調整
- ぼかし強度：色の境界をどれだけ滑らかにするかを調整
- 放射状のみ：中心位置をドラッグで変更可能
- リアルタイムプレビュー付き

**ぼかし範囲とぼかし強度の違い**

| 設定       | 内容                                         |
| ---------- | -------------------------------------------- |
| ぼかし範囲 | 色が混ざる範囲（グラデーションの広さ）を調整 |
| ぼかし強度 | 色の境界をどれだけ滑らかにするかを調整       |

---

## レイヤー不透明度

自動塗りプリセットで設定する不透明度は**レイヤー不透明度**として反映する。塗り色の不透明度は100%固定。

理由：塗り色の透明度で管理すると、手動加筆時に重ね描きで濃さが変化してしまうため。レイヤー不透明度で管理することで、自動塗り部分・手描き部分どちらも同じ濃さになる。

```
自動塗りプリセット設定
  色：#000000
  不透明度：40%
  ブレンドモード：乗算

↓ 自動塗り実行後

影レイヤー
  塗り色：黒100%
  レイヤー不透明度：40%
  ブレンドモード：乗算
```

## ブレンドモード

パーツごとに設定可能。設定したブレンドモードは以下の両方へ反映する。

- 自動塗りレイヤー
- 対応する自動塗り用線画レイヤー

---

## 線画色設定

ラジオボタンで選択方法を切り替える。

```
○ 指定色
○ 塗り色と同じ
○ 色トレス・線画馴染ませ
```

**指定色**

- カラーピッカー
- スポイト
- レイヤー不透明度スライダー

**塗り色と同じ**

対応するパーツの塗り色をそのまま線画色へ使用する。

**色トレス・線画馴染ませ**

スライダーで調整。

| スライダー | デフォルト値 |
| ---------- | ------------ |
| 色相       | -10          |
| 彩度       | 60           |
| 明度       | -70          |

リアルタイムプレビュー付き。

**線画と塗りの隙間を埋める**（0〜100、既定50）

線の薄いふち（アンチエイリアス）のどこまでを「線」として塗りを止めるかのしきい値。不透明度が`1 + 値/100×253`を超える線画の画素で塗りが止まる（既定50＝従来の128）。大きいほど線の薄いふちの下まで塗り、縁取りや塗り色と同じ線画色のときに見える線画と塗りの間の隙間が小さくなる（100で完全に不透明な線の手前まで塗る）。保存・復元あり（旧データは50）。

---

## 線画色トレス（公式の自動操作）

線画レイヤーで実行する。下にある塗りの色を、線画にクリッピングした新規レイヤー（線画の直上）へ取り込み、ぼかし30px→複製2回と結合（濃さを足す）→色トレス補正（色相−10°、彩度は残りの60%だけ上げ、明度は半分）を行う。線は隣の塗りより深い色になり、線の外は一切変わらない。線画自身の色は取り込まない。色トレス補正の彩度・明度は「残り幅に対する割合」で、固定量を引くとほとんどの色が黒になる。

端末に保存済みの公式プリセットは、編集していない（配布時の日付のままの）ものは起動時に最新の手順へ置き換え、配布をやめたもの（オーロラホログラム）は消す。新しく配布した公式プリセットは1回だけ追加し、ユーザーが消したものは戻さない。編集したもの・自作の自動操作はそのまま。

公式プリセットの名前と手順名は保存データでは日本語のままで、表示するときにアプリの言語へ訳す（`lib/utils/custom_automation_labels.dart`。名前は配布時の日本語名と一致する間だけ訳し、ユーザーが名前を変えたらその名前を出す）。手順名は保存されたラベルではなく、手順の種類と設定（フレーム番号・ブラシの太さ・フィルターの種類など）から作るので、記録した自動操作の手順も言語に従う。自動操作・記録したフィルターの再実行で作られる新規レイヤー（縁取り・墨溜まり・自動線画）の名前も、フィルターパネルと同じ訳になる。

## レイヤー設定（パーツごと）

各パーツに以下を保存する。

**塗りレイヤー**

- 色（単色 / グラデーション）
- レイヤー不透明度
- ブレンドモード
- トーン使用・使用トーン

**線画レイヤー**

- 色（指定色 / 塗り色と同じ / 色トレス）
- レイヤー不透明度
- ブレンドモード（塗りレイヤーと同じ値が自動反映）

---

## 詳細設定ポップアップ（色チップタップ時）

```
塗り色
線画色
グラデーション
トーン
ブレンドモード
不透明度
```

すべてリアルタイムプレビュー付き。

## 混色

- ブラシ設定の混色モード（OFF / 簡易混色 / にじみ）と連携
- 混色率：0〜100%・スライダー
- 詳細は 17\_ブラシ仕様.md を参照

---

## トーンカーブ（プレミアム限定）

- 色調をカーブで調整
- 処理はLUT参照による色変換のため低負荷
- 🔒マーク付きで表示・タップで課金誘導ポップアップ

---

## レベル補正（プレミアム限定）

- 入力・出力レベルを調整
- 処理は色値の単純計算のため低負荷
- 🔒マーク付きで表示・タップで課金誘導ポップアップ
