# 19\_プロジェクト管理仕様

## ホーム画面構成

ホーム画面は3タブ構成。

| タブ         | 内容                       |
| ------------ | -------------------------- |
| プロジェクト | 編集用 .niapro の一覧      |
| 共有         | 受信した .niashare の一覧  |
| ゴミ箱       | 削除したプロジェクトの一覧 |

共通UI：

- 設定へのアクセス
- 自動塗りプリセット管理へのアクセス
- 初回起動時：「手書きアニメーションを制作できます」のポップアップのみ表示
- 無料版：画面下部に固定バナー広告

---

## プロジェクト一覧表示

- 表示切替：大 / 中 / 小 / 詳細
- 低スペック端末では小表示を自動推奨
- 各プロジェクトカードにサムネイルを表示
- 並び替え：名前（昇順・降順）/ 最終更新日時（昇順・降順）
- フォルダとプロジェクトを同一一覧内で並び替え

---

## 新規作成（＋ボタン）

- ＋ボタン（右下floating action button）はプロジェクトタブでのみ表示する
  （共有・ゴミ箱タブでは新規作成の導線自体が不要なため非表示）
- タップすると「新規プロジェクト」「新規フォルダ」の2択を表示する
  （新規プロジェクト作成画面へ即座に遷移するのではなく、まず選ばせる）
- 「新規プロジェクト」を選ぶと新規プロジェクト作成画面（サイズ・fps等の
  設定）へ遷移する
- 「新規フォルダ」を選ぶとフォルダ名入力ダイアログを表示し、現在開いて
  いるフォルダの直下（ルート表示中はルート直下）に作成する

---

## タップ操作

| 対象           | シングルタップ     | ダブルタップ | 長押し                             |
| -------------- | ------------------ | ------------ | ---------------------------------- |
| プロジェクト   | 詳細情報画面を開く | 編集開始     | 複数選択モード開始                 |
| フォルダ       | フォルダを開く     | —            | 複数選択モード開始                 |
| 共有タブの項目 | 詳細情報画面を開く | —            | 共有タブ専用フォルダへの移動シート |

.niashareのインポート確認自体は、OSから共有ファイルを開いた時点（タブ内の
操作ではない）で1回だけ表示される。インポート後のプロジェクトは詳細情報
画面内の「編集を開始」ボタンから通常のプロジェクトと同様に編集を開始
できる（一覧でのダブルタップショートカットは無し）。

## 三点メニュー（⋮）項目

- 複製

## 新規作成

新規作成時に以下を設定する。

- プロジェクト名
- FPS
- キャンバスサイズ
- 背景色
- 長さ（秒またはフレーム数）
- 描画領域倒率（詳細は 26\_描画領域・内部保存仕様.md を参照）

---

## フォルダ管理

- プロジェクトをフォルダでグループ化できる
- フォルダは複数階層に対応
- フォルダ内移動時はパンくずリストで現在位置を表示
- フォルダもお気に入り登録可能
- フォルダの作成・名前変更・削除・並び替え・色変更が可能
- フォルダ削除時は中のプロジェクトをルートへ戻すか確認ダイアログを表示
- フォルダはプロジェクト一覧画面右下の＋ボタンから、新規プロジェクトと
  並ぶ選択肢として作成できる（下記「新規作成（＋ボタン）」を参照）。
  作成場所は現在開いているフォルダの直下（ルート表示中はルート直下）

### 用途の補足（プロジェクト・シーン・フォルダの使い分け）

「1プロジェクト＝1本の書き出し単位」が基本単位のため、以下のように使い分ける。

| やりたいこと                                     | 使う機能                                                                   |
| ------------------------------------------------ | -------------------------------------------------------------------------- |
| 1本の動画の中で場面（カット）を分けて作る        | プロジェクト内の「シーン」機能（仕様書05）                                 |
| 同じ作品の複数話数・シリーズ物をまとめて管理する | フォルダ（複数階層対応。「作品名」フォルダの中に各話プロジェクトを並べる） |

フォルダ作成ダイアログ・ヘルプページにこの使い分けのヒントを表示する。

## 検索

- 🔍タップで検索バーが展開される
- 検索対象：プロジェクト名 / フォルダ名

---

## お気に入り

- プロジェクト・フォルダをお気に入り登録できる
- お気に入りタブでお気に入りのみ表示（ゴミ箱タブを除く）

---

## 複数選択

- 長押しで複数選択モード開始
- 全選択・全解除ボタンを表示
- 対象：プロジェクト・フォルダ両方
- 複数選択時の操作：移動・複製・ゴミ箱へ移動
- 名前変更は単体選択時のみ可能

---

## ゴミ箱

- 削除したプロジェクトはゴミ箱タブへ移動
- 容量制限なし・古い順自動削除なし・ユーザー管理
- ゴミ箱から復元可能
- 完全削除可能
- 自動削除設定：OFF / 30日 / 60日 / 90日（設定画面で変更可能）

---

## 自動保存

- 描画などで変更が発生したタイミングで自動保存
- クラッシュ・ファイル破損時の復元専用
- 最大3件固定・古い順に自動削除
- Undo履歴とは別管理
- 手動保存（セーブスロット・セーブツリー）とは完全に独立

---

## 制作時間カウント

- 描画モード・タイムラインモードのみカウント
- 一定時間無操作でカウント停止・操作再開でカウント再開
- ホーム画面・設定画面・ヘルプ閲覧中はカウントしない

---

## .niashare（共有タブ）

- .niashareは通常のファイルとして端末に保存される
- ユーザーがダウンロード → タップ → NIARIMで開く流れ
- OSから共有ファイルを開いた時点（コールドスタート・ウォームスタート
  いずれも）でインポート確認ダイアログを表示する
- 「この共有ファイルを複製して通常プロジェクトとして保存しますか？」と表示
- 確認後、プロジェクトを複製して追加する（.niashare自体は変更されない）。
  追加先は「共有」タブであり、通常のプロジェクトタブとは別枠の一覧として
  並び替え・お気に入り絞込・専用フォルダ分類（共有タブ専用フォルダ）が
  可能。プロジェクト詳細画面を開く・編集を始める等の操作は通常プロジェクト
  と同様に行える（データ上は同じ`.niapro`として保存され、共有インポート
  由来かどうかのフラグのみで一覧の表示先を分けている）

---

## .niatra（引き継ぎ）

引き継ぐ項目をチェックボックスで選択できる。

```
☑ 設定
☑ 素材
☑ ブラシ
☑ プリセット
☑ UIテーマ

[全選択]  [全解除]
```

---

## 無料版のプロジェクト尺制限

- 1プロジェクトあたりの最大尺：1.5分（90秒）
- 超過しようとすると警告ダイアログを表示しプレミアムへの移行を促す

---

## ファイル形式

| 形式      | 用途                             |
| --------- | -------------------------------- |
| .niapro   | 通常プロジェクト保存（編集用）   |
| .niashare | 共有用（複製して共有タブへ追加） |
| .niatra   | 引き継ぎ用（項目選択式）         |

詳細は 06\_保存・共有.md を参照。
