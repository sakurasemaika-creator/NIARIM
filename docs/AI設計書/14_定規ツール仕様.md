# 14_定規ツール仕様

## 基本方針

- 定規は描画補助専用オブジェクトとして実装する
- 定規自体は画像には描画されない
- ブラシ・消しゴム・自動塗り等の描画補助のみ行う
- ラスター専用
- 初心者向け設計
- Galaxy スマホ・タブレット・DeX 対応
- 低スペック端末でも快適動作

---

## 初期実装する定規

| 定規 | 用途 |
|------|------|
| 直線定規 | 直線・建物・漫画 |
| 円定規 | 円・円弧 |
| 楕円定規 | 楕円・パース付き円 |
| 矩形定規 | 長方形・正方形 |
| 放射定規 | 対称イラスト・花・歯車・マンダラ・円形デザイン |
| 一点透視定規 | 消失点1つ |
| 二点透視定規 | 左右2つの消失点・背景制作向け |
| 三点透視定規 | 上下含めた3消失点・高層ビルなど |

---

## 図形ツール

実装しない。定規だけで円・四角・楕円・直線すべて描けるため、UIも簡潔になる。

---

## 作成方法

```
ツールバー → 定規 → ポップアップ（種類選択）
```

ポップアップ選択肢：直線 / 円 / 楕円 / 矩形 / 放射 / 一点透視 / 二点透視 / 三点透視

---

## 定規一覧

定規ツール選択時のみ表示。通常時は非表示。

---

## 同時表示数

- 同時表示は1つまで
- 新しい定規を配置すると現在の定規は自動で収納される

---

## 表示

- 青色半透明で表示
- 画像には保存されない

---

## スナップ

ブラシが定規に自動吸着する。

対応ツール：ブラシ / 消しゴム / 自動塗り境界確認

---

## 各定規の設定項目

### 放射定規

| 項目 | 内容 |
|------|------|
| 分割数 | 2〜360分割を自由指定 |
| 中心位置 | 変更可能 |
| 回転角度 | 変更可能 |

- 左右対称定規は放射定規2分割で代用可能

### 一点透視定規

| 項目 | 内容 |
|------|------|
| 消失点位置 | 変更可能 |

### 二点透視定規

| 項目 | 内容 |
|------|------|
| 左消失点 | 変更可能 |
| 右消失点 | 変更可能 |

### 三点透視定規

| 項目 | 内容 |
|------|------|
| 左消失点 | 変更可能 |
| 右消失点 | 変更可能 |
| 上（または下）消失点 | 変更可能 |

---

## 編集・操作

| 操作 | 内容 |
|------|------|
| 移動 | 配置後にハンドル表示・移動可能 |
| ロック | ロックONで移動不可 |
| 表示ON/OFF | 表示・非表示の切替 |
| 削除 | ゴミ箱から削除 |
| Undo | 通常対応 |

---

## レイヤー

- 定規はレイヤー非依存
- プロジェクト共通で適用される

---

## 保存・共有

- 保存対象：`.mirapro` / `.mirashare` 両対応
- プロジェクト共有時も定規情報を保持

---

## パフォーマンス

- 定規は座標情報のみ保持
- 画像生成なし
- RAM使用量極小
- 低スペック端末対応

---
