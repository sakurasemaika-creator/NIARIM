# 14\_定規ツール仕様

## 基本方針

- 定規は描画補助専用オブジェクトとして実装する
- 定規自体は画像には描画されない
- ブラシ・消しゴム等の描画補助のみ行う
- ラスター専用
- 初心者向け設計
- Galaxy スマホ・タブレット・DeX 対応
- 低スペック端末でも快適動作

---

## 初期実装する定規

| 定規        | 備考                                                                  |
| ----------- | --------------------------------------------------------------------- |
| 直線定規    | 始点・終点を配置。定規上で何本でも線が引ける。移動・回転可能          |
| 楕円定規    | 楕円形状を自由に変更。回転・移動可能。正円スナップあり                |
| 集中線定規  | 放射定規の2分割で対称定規としても利用可能。中心位置・回転角度変更可能 |
| 1点透視定規 | 消失点1つ                                                             |
| 2点透視定規 | 消失点2つ                                                             |
| 3点透視定規 | 消失点3つ                                                             |
| 魚眼パース  | 5点の曲線透視（レンズの縁の円・中心）。中心・半径・傾きを変更可能     |

### 実装しない定規

- 円定規：楕円定規の正円スナップで代用できるため不要
- 平行定規：直線定規を移動しながら使えば平行線を描けるため不要
- 矩形定規：直線定規を使って描けるため不要

---

## 図形ツール

| 選択肢 | 動作                                                           |
| ------ | -------------------------------------------------------------- |
| OFF    | 通常ブラシへ戻る                                               |
| 線     | 開始点→終了点で直線描画                                        |
| 四角形 | 開始点→終了点で四角形描画。縦横比1:1付近で正方形へ自動スナップ |
| 円     | 開始点→終了点で楕円描画。縦横比1:1付近で真円へ自動スナップ     |

- 長押し不要・ワンタップでポップアップ表示
- ドラッグ中はゴムバンド表示（リアルタイムプレビュー）・指を離すまで確定しない
- 現在のブラシサイズ・不透明度・ブレンドモード・クリッピングを反映
- ブラシ・トーンどちらでも描画可能
- スナップ判定：縦横比が1:1付近になると自動的に吸い付くようにスナップ（Shiftキー不要）
- 四角形と長方形・円と楕円は別ツールにしない（ドラッグ量で自然に切り替わる）

---

## 定規一覧（ポップアップ）

定規ツールを押した時のみポップアップを表示。通常時は非表示。

```
────────────────
直線定規
楕円定規
集中線定規
────────────────
1点透視
2点透視
3点透視
魚眼パース
────────────────
```

項目が画面に収まらないとき（小さい画面・大きい文字）は一覧がスクロールする。

---

## 同時表示数

- 同時表示は1つまで
- 新しい定規を選択すると現在の定規は自動で閉じる

---

## 表示

- 半透明表示
- ハンドル表示
- 削除ボタン表示
- 画像には保存されない

---

## スナップ

- スナップ対象：現在表示中の定規のみ
- 複数定規へのスナップは行わない
- 対応ツール：ブラシ / 消しゴム

## 各定規の設定項目

### 直線定規

| 項目       | 内容           |
| ---------- | -------------- |
| 始点・終点 | 配置・移動可能 |
| 回転       | 可能           |
| 移動       | 可能           |

### 楕円定規

| 項目         | 内容                                  |
| ------------ | ------------------------------------- |
| 形状変更     | 横幅・縦幅を自由に変更                |
| 正円スナップ | 横幅≒縦幅になると自動で正円に吸い付く |
| 回転         | 可能                                  |
| 移動         | 可能                                  |

### 集中線定規

| 項目     | 内容                 |
| -------- | -------------------- |
| 分割数   | 2〜360分割を自由指定 |
| 中心位置 | 変更可能             |
| 回転角度 | 変更可能             |

- 2分割で左右対称定規として利用可能

### 1点透視定規

| 項目       | 内容     |
| ---------- | -------- |
| 消失点位置 | 変更可能 |

### 2点透視定規

| 項目     | 内容     |
| -------- | -------- |
| 左消失点 | 変更可能 |
| 右消失点 | 変更可能 |

### 3点透視定規

| 項目                 | 内容     |
| -------------------- | -------- |
| 左消失点             | 変更可能 |
| 右消失点             | 変更可能 |
| 上（または下）消失点 | 変更可能 |

### 魚眼パース定規

5点の曲線透視（カーヴィリニア・パースペクティブ）。魚眼レンズで撮ったように、
レンズの縁の円の中で直線が弧を描く。

| 項目               | 内容                                                             |
| ------------------ | ---------------------------------------------------------------- |
| 中心（第5消失点）  | 中心の丸をドラッグで移動                                         |
| 半径（レンズの縁） | 円の右の丸をドラッグ。既定はキャンバスの短い辺の45%              |
| 傾き               | 円の上の丸（上の消失点）をドラッグすると全体が中心のまわりに回る |

- 横の線：左右の消失点（円の左右の端）を通る円弧。中心を通る1本（水平線）だけは直線
- 縦の線：上下の消失点（円の上下の端）を通る円弧。中心を通る1本だけは直線
- 奥行きの線：中心へ集まる直線
- ガイドは縁の円・横と縦の円弧（中心から縁まで4段ずつ）・奥行きの線（45°おき）を表示する
- スナップ：どの点を通る線も、横・縦・奥行きにちょうど1本ずつある。描き始めてから画面上で
  10px動いた時点で、その向きに最も近い1本を選び、ストロークの終わりまでその線へ投影し続ける
  （向きが決まるまでは描き始めの点に留まる）。円の外側でも同じ円弧の続きに沿う
- 計算は`lib/engine/fisheye_perspective.dart`（ローカル座標＝中心が原点・傾きを戻した向き）

## 編集・操作

| 操作       | 内容               |
| ---------- | ------------------ |
| 移動       | ハンドルをドラッグ |
| 回転       | ハンドルをドラッグ |
| サイズ変更 | ハンドルをドラッグ |
| 削除       | 削除ボタンをタップ |
| Undo       | 通常対応           |

---

## レイヤー

- 定規はレイヤー非依存
- プロジェクト共通で適用される

---

## 保存・共有

- 保存対象：`.niapro` / `.niashare` 両対応
- プロジェクト共有時も定規情報を保持

---

## パフォーマンス

- 定規は座標情報のみ保持
- 画像生成なし
- RAM使用量極小
- 低スペック端末対応
