# 21_素材管理仕様

## 概要

- 素材とはプロジェクト内で使用する画像・音声・動画ファイルを指す
- 素材はファイル名ではなく素材ID（MaterialID）で参照する
- 同一素材はプロジェクト内に1つだけ保存する。同じ画像・動画・音声を複数回使用する場合でも、キャンバス・タイムラインからはMaterialIDを参照することで重複保存を防ぎプロジェクト容量を削減する

---

## 素材の保存場所

| 素材種別 | 保存場所 | 管理単位 |
|---------|---------|---------|
| 画像・音声・動画 | プロジェクト内 `Materials/` | プロジェクトごと |
| フォント（TTF/OTF） | アプリ全体 `Fonts/` | アプリ全体で共有 |
| ブラシ設定・ブラシ画像 | アプリ全体 `Brushes/` | アプリ全体で共有 |

フォント・ブラシはプロジェクトと独立してアプリ全体で管理する。

---

## 素材ID

- Material0001形式（4桁連番）・拡張子を保持（例：Material0001.png / Material0002.mp4）
- ファイル名ではなくIDで参照

---

## 素材の種類

| 種類 | 用途 | 対応形式 |
|------|------|---------|
| 画像 | キャンバスへの貼り付け・ブラシ形状として登録・素材一覧から選択可能 | PNG / JPG など |
| 音声 | タイムラインの音声トラックへ配置 | MP3 / WAV など |
| 動画 | タイムラインの動画トラックへ配置 | 通常動画 / 透明動画（WebM）両対応 |

---

## 素材フォルダ構成

```
Project.mirapro/
└── Materials/
    ├── Material0001.png
    ├── Material0002.mp4
    ├── Material0003.mp3
    └── ...
```

---

## 素材一覧UI

- サムネイル・種類アイコン・ファイル名を一覧表示

```
🖼  Material0001  背景_教室.png
🎬  Material0002  OP.mp4
🎵  Material0003  BGM01.mp3
```

---

## 素材操作

| 操作 | 内容 |
|------|------|
| 追加（画像） | ギャラリー または ファイルアプリから読み込み |
| 追加（音声・動画） | ファイルアプリから読み込み |
| 削除 | 使用中でない素材のみ削除可能。使用中の場合は「現在使用中のため削除できません」と表示 |
| 未使用素材を一括削除 | 使用されていない素材をまとめて削除 |
| 詳細表示 | ファイル名・種類・容量・解像度（画像）・再生時間（動画・音声）・最終更新日時を表示 |

---

## 不足素材の検出

- プロジェクトを開いた際に参照先の素材が見つからない場合は「不足素材があります」と表示
- 「再検索」ボタンで参照先を再確認
- 再検索後も見つからない場合は再度「不足素材があります」と表示

---

## 共有時の素材同梱

.mirashare / .stutra 作成時に種類ごとに同梱を選択できる。

```
☑ 画像
☑ 動画
☑ 音声
```

同梱しない場合、受信側で不足素材の警告が表示される。

---

## フォント素材

- ユーザーが追加したフォント（TTF / OTF）はアプリ全体の `Fonts/` フォルダで管理
- フォント名を表示
- 詳細は 15_テキストツール・フォント仕様.md を参照

---

## ブラシ素材

- ブラシはブラシ画像だけでなくブラシ設定全体をアプリ全体の `Brushes/` フォルダで管理
- ブラシ画像は素材一覧からも選択可能
- 詳細は 17_ブラシ仕様.md を参照
