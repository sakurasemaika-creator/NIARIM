# 02_UI仕様

## ホーム画面

- プロジェクト一覧（大・中・小アイコン / 詳細表示の切替）
- 並び替え：名前 / 更新日時（昇順・降順）
- フォルダ管理
- お気に入り
- 共有一覧
- ゴミ箱
- 設定へのアクセス
- 自動塗りプリセット管理へのアクセス
- 初回起動時：「手書きアニメーションを制作できます」のポップアップのみ表示
- 無料版：画面下部に固定バナー広告

## キャンバスモード（描画優先）

目的：描画に集中できるよう、キャンバス表示領域を最大化する。

```
┌──────────────────────────────┐
│        バナー広告（無料版）   │
├──────────────────────────────┤
│←　　　　　　　　　　　　↩　↪ │
│                              │
│         キャンバス           │
│                              │
├──────────────────────────────┤
│ブラシサイズ                  │
│不透明度                      │
├──────────────────────────────┤
│ツールバー                    │
├──────────────────────────────┤
│□□□□ □□□□ □□□□ □□□□ ▶      │
│（フレーム一覧 横スクロール） │
└──────────────────────────────┘
```

表示：戻る / Undo（↩）/ Redo（↪）/ キャンバス / ブラシサイズ / 不透明度 / ツールバー / フレーム一覧（横スクロール）

非表示：プロジェクト名 / 保存 / プロジェクト保存 / シーン一覧 / 動画タイムライン / 音声タイムライン / プレビュー

## タイムラインモード（編集・確認専用）

目的：アニメーション編集・確認専用画面。描画は行わないためキャンバスは表示せずプレビューを表示する。

```
┌──────────────────────────────────────┐
│← プロジェクト名　　　↩　↪　⋮        │
├──────────────────────────────────────┤
│             プレビュー               │
├──────────────────────────────────────┤
│      ⏮   ⏪   ▶/⏸   ⏩   ⏭           │
├──────────────────────────────────────┤
│ツールバー                            │
├──────────────────────────────────────┤
│Scene1  Scene2  Scene3   ＋           │
├──────────────────────────────────────┤
│フレーム一覧                          │
├──────────────────────────────────────┤
│動画タイムライン                      │
├──────────────────────────────────────┤
│音声タイムライン                      │
├──────────────────────────────────────┤
│        バナー広告（無料版）           │
└──────────────────────────────────────┘
```

再生コントロール（左から）：⏮ 最初のフレームへ / ⏪ 前のフレームへ / ▶ 再生・⏸ 一時停止（同位置で切替） / ⏩ 次のフレームへ / ⏭ 最後のフレームへ（アイコン表示）

右上三点メニュー（⋮）：Redoの右側に配置。タップすると以下が開く。

```
┌─────────────────┐
│ 保存            │
│ プロジェクト保存 │
│ 自動塗り実行    │
│ セーブツリー    │
└─────────────────┘
```

表示：戻る / プロジェクト名 / Undo（↩）/ Redo（↪）/ 三点メニュー / プレビュー / 再生コントロール / ツールバー / シーン一覧（横スクロール） / フレーム一覧 / 動画タイムライン / 音声タイムライン

非表示：キャンバス / ブラシサイズ / 不透明度

## 複数選択UI

複数選択が可能な全画面で、選択モード開始時に専用UIを表示する。

対象画面：プロジェクト一覧 / タイムライン / フレーム一覧 / 素材一覧 / プリセット一覧 / その他複数項目操作が可能な一覧画面

```
通常表示
  [項目1]
  [項目2]
  [項目3]

↓ 長押しで選択モード開始

  全選択　　全解除
  ☑ 項目1
  ☐ 項目2
  ☑ 項目3
```

| ボタン | 動作 |
|--------|------|
| 全選択 | 現在表示中の対象（フォルダ内・シーン内・タイムライン範囲など）をすべて選択 |
| 全解除 | 現在選択されている項目をすべて解除 |

- 全選択・全解除ボタンは選択モード中のみ表示

## 無料版のプレミアム機能表示

無料版でもプレミアム限定機能を南京錠マーク（🔒）とともに表示する。タップすると課金誘導ポップアップを表示する。

- 🔒 EndCard Track（タイムライン上に表示・ロック状態）
- 🔒 ユーザーウォーターマーク（設定項目に🔒マーク付きで表示）
- 🔒 トーンカーブ（メニューに🔒マーク付きで表示）
- 🔒 レベル補正（メニューに🔒マーク付きで表示）

課金誘導ポップアップの内容：機能名 / 「Premiumで解放」の説明 / 月額・年額プラン選択ボタン

## UIコンポーネント仕様

### ダイアログ

- 確認が必要な操作（フォルダ削除・共有保存など）はダイアログを表示
- 説明文は短く端的に表示する（例：「同名データがあります。」のみ表示し「どうしますか？」は表示しない）
- ボタン構成は「キャンセル」を左・「実行」を右に配置する2択を基本とする（Android標準に準拠）
- 破壊的操作（削除・完全削除）は実行ボタンを赤系色で表示

### 三点メニュー（⋮）

- 画面右上または項目右端に配置
- タップでメニューリストをポップアップ表示
- 項目数が多い場合は縦スクロール対応

### ラジオボタン

- 単一選択の選択肢に使用
- 例：自動塗り方法の選択・筆圧設定

### チェックボックス

- ON/OFFの切替に使用
- 例：ドットペンモード・アウトラインON/OFF
- ロックはチェックボックスではなくアイコンボタンで操作する

### スライダー

- 数値の連続的な調整に使用
- 例：ブラシサイズ・不透明度・混色率・ぼかし半径・筆圧反映度
- スライダー横に現在値を数値表示
- ブラシサイズ・不透明度はキャンバス画面のUndo/Redoと同じ列に配置

### プログレスバー

- 時間のかかる処理中に表示
- 例：フィルター適用・動画書き出し・GIF生成
- 処理内容と進捗（例：25/120フレーム）を表示（予想残り時間は表示しない）
- 無料版は下部に正方形広告を表示・処理完了時に自動消去

### 南京錠マーク（🔒）

- プレミアム限定機能に表示
- タップで課金誘導ポップアップを表示
- ポップアップ内容：機能名 / 「Premiumで解放」の説明 / 無料版との比較表 / 月額・年額プラン選択ボタン

### 吹き出し説明

- 初回使用時に該当UIの近くに吹き出しで簡易説明を表示
- 表示は一度のみ・再表示なし
- 再確認はヘルプページから行う

### ヘルプ（？ボタン）

- 複雑な機能（ブレンドモード・クリッピングなど）の近くに「？」ボタンを配置
- タップのみ対応（長押し不要）
- タップで簡易説明を表示
- 詳しく知りたい場合はヘルプページへ誘導

## アイコン仕様

### 再生コントロール

| アイコン | 意味 |
|----------|------|
| ⏮ | 最初のフレームへ移動 |
| ⏪ | 前のフレームへ |
| ▶ | 再生 |
| ⏸ | 一時停止（▶と同位置で切替） |
| ⏩ | 次のフレームへ |
| ⏭ | 最後のフレームへ移動 |

### 共通アイコン

| アイコン | 意味 |
|----------|------|
| ← | 戻る |
| ↩ | Undo |
| ↪ | Redo |
| ⋮ | 三点メニュー |
| 🔍 | 検索（タップで検索バー展開） |
| ★ | お気に入り |
| 🔒 | ロック / プレミアム限定 |
| ❗ | 更新マーク（自動塗りレイヤーが最新でない場合）。タップ→自動塗り実行画面。長押し→説明表示 |
| 👁 | 表示ON/OFF |
| ＋ | 追加 |
| ゴミ箱 | 削除 |
| 📁 | フォルダ |
| ？ | ヘルプ・簡易説明 |
| ↺ | ツール早替えボタン |

### ジェスチャー操作

| ジェスチャー | 初期設定 | 変更 |
|-------------|---------|------|
| 2本指タップ | Undo | ○ |
| 3本指タップ | Redo | ○ |
| 2本指左右スワイプ | フレーム移動 | ○ |
| 長押し | スポイト | ○ |

- ジェスチャーは設定画面から自由に変更可能
- キーボードショートカットとは独立して設定できる
