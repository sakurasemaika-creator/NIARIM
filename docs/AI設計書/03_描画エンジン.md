# 03\_描画エンジン

## 描画方式

- ラスターベース描画のみ（ベクターなし）
- 描画エンジンはタッチ入力・ペン入力双方を入力ソースとして抽象化し、ブラシエンジンへ渡す

図形ツール（タップでポップアップ表示）

| 選択肢 | 動作                                                           |
| ------ | -------------------------------------------------------------- |

| 線     | 開始点→終了点で直線描画                                        |
| 四角形 | 開始点→終了点で四角形描画。縦横比1:1付近で正方形へ自動スナップ |

- ドラッグ中はゴムバンド表示（リアルタイムプレビュー）・指を離すまで確定しない

- スナップ判定：縦横比が1:1付近になると自動的に吸い付くようにスナップ（Shiftキー不要）
- 四角形と長方形・円と楕円は別ツールにしない（ドラッグ量で自然に切り替わる）

## フェード仕様

ストロークが進むにつれて不透明度・サイズが減少する。

カスタム設定項目：開始値（%）/ 終了値（%）/ 距離（px）

---

## ストローク減衰仕様

筆圧ではなく、描き続けるほどインクが減るような表現。ストローク後半で自然に薄くなる。

## 混色仕様

- モード（ブラシカスタムのラジオボタン）：デジタル / 油彩風混色 / 水彩風混色（ユーザー指定の名称。「油彩」「水彩」と言い切ると本物の画材の再現と誤認されるため「〜風」）。旧「にじみ」は廃止し、保存済みの「にじみ」は水彩風混色、「アナログ風」（旧「簡易混色」を含む）は油彩風混色として読み込む。
- デジタル：混ぜずにそのまま塗る。
- 油彩風混色：下の色と絵の具のように混ざる。色相は画家の色相環（赤・橙・黄・緑・青・紫のRYB）の短い方を回り、赤＋青＝紫、青＋黄＝緑、赤＋黄＝橙になる（どの赤・青・黄でも。暖色寄りの赤＋青が茶色になる物理的な顔料計算ではなく、常識的な混色。ユーザー指定）。補色どうし（赤と緑、青と橙、黄と紫）は絵の具と同じく落ち着いた中間色になる。彩度は2色の直線補間を保ち、明度はKubelka–Munk分光混色（spectral.js 3.0.0の分光データ、MIT License）と直線補間の中間で、明るい方の色より明るくならない（デジタルの色相環補間のように途中で急に明るくならない）。混色度合いは2色を結ぶ経路のOKLabでの長さの割合で測る。スタンプごとに筆の下の絵の具を拾って筆の色に混ぜ、色延びの距離だけ引きずる（新しい絵の具が戻って選択色へ近づく）。
- 水彩風混色：透明な絵の具を重ねる。描いている間は同じストロークの中で重ならない1回のウォッシュで、紙の目と顔料のむら（どちらもキャンバスに固定された模様）が出る。ペンを離すと乾き、にじみ（と少しだけ水分量）に応じて筆より外へ不規則ににじむ。乾いた縁に色が溜まる表現はブラシではなく描画フィルター「水彩境界」で付ける（ユーザー指定。描いた後に調整できるように）。下の絵の具の上では色相環どおりに混ざって（黄の上に青＝緑）透明な一層ぶん深くなる。同じ色を重ねたとき、不透明度100%なら濃くならずに同じ色の範囲が広がり（複数のストロークでベタ塗りしても塗りムラにならない。ユーザー指定）、不透明度を下げているときは重ねた分だけ深くなる。違う色は100%どうしでも混ざる。混色度合いが高いほど濡れた色どうしが溶け合い、深くならない。乾かす処理はペンを離した時点（Undoの記録が閉じる前）に行い、1回のUndoで戻る。
- 半透明の既存色（筆跡の縁など）は、不透明度に応じて混ざる量が減る。
- 混色度合い：0〜100（筆圧ON時は弱・強）。
- 油彩風混色のみ：色延び 0〜100（初期値30。拾った色を最大でブラシ幅の6倍まで運ぶ。0なら拾わない）、輝度補正 1〜5（初期値3。3は補正なし、1〜2は暗め、4〜5は明るめ。混色の中間ほど強く、端点の色は変えない）。
- 水彩風混色のみ：水分量（初期値50。多いほど薄く、むらが出て、少し広がる）、絵具量（初期値60。多いほど濃い）、にじみ（初期値50。乾くときに筆の外へどこまで、どれだけ不揃いに広がるか）、いずれも0〜100。
- 描画先ピクセルの局所領域のみを処理し、キャンバス全域の走査をしない。アルファ、筆圧、不透明度、Undo/Redoとの整合性を保つ。

混色ブラシは品質設定とは独立したブラシ機能であり、すべての品質設定で利用可能とする。品質設定は描画処理・キャッシュ・プレビューなどのパフォーマンス制御のみを行う。

## 外部ペン入力対応

Android OS標準のペン入力APIを使用した汎用対応（特定メーカー依存なし）。

対応デバイス：板タブ・液晶タブレット・スタイラスペン

```
ペン入力 → 描画
指入力  → ジェスチャー操作（既存仕様通り）
```

### 初期実装範囲

| 項目                     | 状態                                                       |
| ------------------------ | ---------------------------------------------------------- |
| 座標（X・Y）             | ✅ 対応                                                    |
| 筆圧（pressure）         | ✅ 対応                                                    |
| ペン接触判定             | ✅ 対応                                                    |
| 指／ペン入力判別         | ✅ 対応                                                    |
| 傾き（tilt）情報取得     | ✅ 取得のみ対応                                            |
| 傾きのブラシ変形への利用 | 高品質・カスタム設定時のみ有効                             |
| ペンボタン               | 対応端末のみ取得（消しゴム切替・スポイト等に割り当て可能） |

### 傾き対応と品質設定の連携

| 品質     | 筆圧  | 傾き                |
| -------- | ----- | ------------------- |
| 低品質   | ✅ ON | ❌ OFF              |
| 中品質   | ✅ ON | ❌ OFF              |
| 高品質   | ✅ ON | ✅ ブラシ変形に反映 |
| カスタム | ✅ ON | 個別設定（ON/OFF）  |

傾き対応の処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わない。

```
ペン入力
↓
筆圧・傾き取得
↓
ブラシスタンプ倍率変更
↓
キャンバスへ描画
```

傾き反映の表現：ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画する。

設定画面での表記：「ペンの傾きをブラシに反映」
