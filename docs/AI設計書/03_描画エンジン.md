# 03_描画エンジン

## 描画方式

- ラスターベース描画のみ（ベクターなし）
- 描画エンジンはタッチ入力・ペン入力双方を入力ソースとして抽象化し、ブラシエンジンへ渡す

---

## 描画ツール一覧

| ツール | 備考 |
|--------|------|
| ペン | あり |
| 消しゴム | あり |
| バケツ | あり |
| スポイト | あり |
| 指 | あり |
| 選択 | 矩形選択・投げ縄選択・自動選択（マジックワンド）を初期実装 |
| 移動 | あり |
| 変形 | あり |
| 図形 | 四角・楕円・直線 |
| 定規 | あり |

## ブラシ設定

| 項目 | 内容 |
|------|------|
| サイズ | 可変 |
| 不透明度 | 可変 |
| 間隔 | 可変 |
| 手ブレ補正 | あり |
| ドットペンモード | あり |
| 筆圧設定 | 無効 / サイズに反映 / 不透明度に反映 / サイズ＋不透明度に反映 |
| フェード | OFF / 弱 / 中 / 強 / カスタム（開始・終了・距離を個別設定） |
| ストローク減衰 | 描き続けるほど不透明度が下がる（インク切れ表現） |
| 混色 | OFF / 簡易混色 / にじみ |
| 混色率 | OFF / 20% / 40% / 60% / 80% / 100% |
| お気に入り | あり |

ブラシ管理：並び替え・編集・複製・削除

---

## フェード仕様

ストロークが進むにつれて不透明度・サイズが減少する。

カスタム設定項目：開始値（%）/ 終了値（%）/ 距離（px）

---

## ストローク減衰仕様

筆圧ではなく、描き続けるほどインクが減るような表現。ストローク後半で自然に薄くなる。

---

## 混色仕様

- 簡易混色：ブラシ直下の現在色と選択色を一定割合で混ぜる（軽量・ブラシ直下のみ解析）
- にじみ：描くたびに少しだけ色を引っ張る（比較的軽量）
- 本格的な油絵混色（周囲ピクセル解析）は初期実装に含めない

### 品質設定との連携

| 品質 | 使用可能な混色 |
|------|--------------|
| 低品質 | 簡易混色のみ |
| 中品質 | 簡易混色 ＋ にじみ |
| 高品質 | 将来の本格混色追加時に自動有効 |

---

## 外部ペン入力対応

Android OS標準のペン入力APIを使用した汎用対応（特定メーカー依存なし）。

対応デバイス：板タブ・液晶タブレット・スタイラスペン

```
ペン入力 → 描画
指入力  → ジェスチャー操作（既存仕様通り）
```

### 初期実装範囲

| 項目 | 状態 |
|------|------|
| 座標（X・Y） | ✅ 対応 |
| 筆圧（pressure） | ✅ 対応 |
| ペン接触判定 | ✅ 対応 |
| 指／ペン入力判別 | ✅ 対応 |
| 傾き（tilt）情報取得 | ✅ 取得のみ対応 |
| 傾きのブラシ変形への利用 | 高品質・カスタム設定時のみ有効 |
| ペンボタン | 対応端末のみ取得（消しゴム切替・スポイト等に割り当て可能） |

### 傾き対応と品質設定の連携

| 品質 | 筆圧 | 傾き |
|------|------|------|
| 低品質 | ✅ ON | ❌ OFF |
| 中品質 | ✅ ON | ❌ OFF |
| 高品質 | ✅ ON | ✅ ブラシ変形に反映 |
| カスタム | ✅ ON | 個別設定（ON/OFF） |

傾き対応の処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わない。

```
ペン入力
↓
筆圧・傾き取得
↓
ブラシスタンプ倍率変更
↓
キャンバスへ描画
```

傾き反映の表現：ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画する。

設定画面での表記：「ペンの傾きをブラシに反映」

## フィルター

### 描画フィルター（レイヤーへ直接適用）

- アニメ調背景（描画フィルターのみ。演出フィルターには含めない）
- お気に入り・お気に入りのみ表示

### 演出フィルター（タイムラインへ適用）

- フェード（色指定）
- ガウスぼかし
- レンズぼかし
- モザイク
- 色収差
- ノイズ
- お気に入り・お気に入りのみ表示

### フィルター適用範囲

- 選択範囲がある場合：選択範囲のみに適用
- 選択範囲がない場合：現在選択中のレイヤー・フォルダ・参照レイヤーへ適用
