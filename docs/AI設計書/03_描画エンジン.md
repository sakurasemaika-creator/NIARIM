# 03_描画エンジン

## 描画方式

- ラスターベース描画のみ（ベクターなし）
- 描画エンジンはタッチ入力・ペン入力双方を入力ソースとして抽象化し、ブラシエンジンへ渡す

|--------|------|

図形ツール（タップでポップアップ表示）

| 選択肢 | 動作 |
|--------|------|
| OFF | 通常ブラシへ戻る |
| 線 | 開始点→終了点で直線描画 |
| 四角形 | 開始点→終了点で四角形描画。縦横比1:1付近で正方形へ自動スナップ |
| 円 | 開始点→終了点で楕円描画。縦横比1:1付近で真円へ自動スナップ |

- 長押し不要・ワンタップでポップアップ表示
- ドラッグ中はゴムバンド表示（リアルタイムプレビュー）・指を離すまで確定しない
- 現在のブラシサイズ・不透明度・ブレンドモード・クリッピングを反映
- ブラシ・トーンどちらでも描画可能
- スナップ判定：縦横比が1:1付近になると自動的に吸い付くようにスナップ（Shiftキー不要）
- 四角形と長方形・円と楕円は別ツールにしない（ドラッグ量で自然に切り替わる）

### スタンプとの役割分担

| 図形ツール | スタンプ |
|-----------|----------|
| 線・四角形（長方形含む）・円（楕円含む） | 三角形・五角形・六角形・星・ハート・吹き出し・矢印・記号・その他装飾図形 |

## フェード仕様

ストロークが進むにつれて不透明度・サイズが減少する。

カスタム設定項目：開始値（%）/ 終了値（%）/ 距離（px）

---

## ストローク減衰仕様

筆圧ではなく、描き続けるほどインクが減るような表現。ストローク後半で自然に薄くなる。

---

## 混色仕様

- 簡易混色：ブラシ直下の現在色と選択色を一定割合で混ぜる（軽量・ブラシ直下のみ解析）
- にじみ：描くたびに少しだけ色を引っ張る（比較的軽量）
- 本格的な油絵混色（周囲ピクセル解析）は初期実装に含めない

混色ブラシは品質設定とは独立したブラシ機能であり、すべての品質設定で利用可能とする。品質設定は描画処理・キャッシュ・プレビューなどのパフォーマンス制御のみを行う。

---

## 外部ペン入力対応

Android OS標準のペン入力APIを使用した汎用対応（特定メーカー依存なし）。

対応デバイス：板タブ・液晶タブレット・スタイラスペン

```
ペン入力 → 描画
指入力  → ジェスチャー操作（既存仕様通り）
```

### 初期実装範囲

| 項目 | 状態 |
|------|------|
| 座標（X・Y） | ✅ 対応 |
| 筆圧（pressure） | ✅ 対応 |
| ペン接触判定 | ✅ 対応 |
| 指／ペン入力判別 | ✅ 対応 |
| 傾き（tilt）情報取得 | ✅ 取得のみ対応 |
| 傾きのブラシ変形への利用 | 高品質・カスタム設定時のみ有効 |
| ペンボタン | 対応端末のみ取得（消しゴム切替・スポイト等に割り当て可能） |

### 傾き対応と品質設定の連携

| 品質 | 筆圧 | 傾き |
|------|------|------|
| 低品質 | ✅ ON | ❌ OFF |
| 中品質 | ✅ ON | ❌ OFF |
| 高品質 | ✅ ON | ✅ ブラシ変形に反映 |
| カスタム | ✅ ON | 個別設定（ON/OFF） |

傾き対応の処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わない。

```
ペン入力
↓
筆圧・傾き取得
↓
ブラシスタンプ倍率変更
↓
キャンバスへ描画
```

傾き反映の表現：ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画する。

設定画面での表記：「ペンの傾きをブラシに反映」

## フィルター

### 描画フィルター（レイヤーへ直接適用）

- アニメ調背景（描画フィルターのみ。演出フィルターには含めない）
- お気に入り・お気に入りのみ表示

### 演出フィルター（タイムラインへ適用）

- フェード（色指定）
- ガウスぼかし
- レンズぼかし
- モザイク
- 色収差
- ノイズ
- お気に入り・お気に入りのみ表示

### フィルター適用範囲

- 選択範囲がある場合：選択範囲のみに適用
- 選択範囲がない場合：現在選択中のレイヤーまたはフォルダへ適用
