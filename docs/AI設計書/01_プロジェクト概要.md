# 01_プロジェクト概要

## アプリ概要

- アプリ名：NIARIM
- ジャンル：手書きアニメ制作アプリ
- プラットフォーム：Android
- コンセプト：低価格帯Androidでもサクサク動く、本格的な手書きアニメ制作アプリ

---

## 対応端末

- Android端末全般
- 低スペック端末（2万円台・64GB・低性能CPU）でも動作すること
- Galaxy端末（DeXモード・Sペン）での動作を最終確認環境とする
- 板タブ・液晶タブレット接続にも対応

---

## 課金仕様

NIARIMは月額・年額のサブスクリプション方式を採用する。

| プラン | 価格 | 備考 |
|--------|------|------|
| 無料版 | 0円 | — |
| プレミアム月額 | 550円（税込） | サブスクリプション |
| プレミアム年額 | 5,500円（税込） | 実質2か月分無料 |

### 無料版

- 全基本制作機能利用可能
- 動画書き出し可能
- 動画書き出し時、本編終了後にNIARIM公式エンドロゴ動画（約5秒）を自動追加
- 広告表示あり

### プレミアム版（月額550円税込）

以下を解放する。

- 全広告削除
- NIARIM公式エンドロゴ動画の削除
- エンドロゴ動画のタイムライン編集（削除・表示非表示・長さ変更・差替え）
- ユーザーウォーターマーク機能
- トーンカーブ
- レベル補正

### エンドロゴ動画の仕様

- 本編アニメーション部分には一切表示しない
- 内部的にEndCard Trackとして管理
- 無料版：タイムライン上に南京錠付きで表示・自動追加。タップするとPremium誘導バナーを表示。削除・移動・編集・操作不可
- プレミアム版：タイムライン上に表示・編集可能（削除・表示非表示・長さ変更・差替え）

### ユーザーウォーターマーク（プレミアム限定）

設定項目：画像選択 / 文字入力 / 位置 / サイズ / 透明度 / 表示開始時間 / 終了時間 / 常時表示ON/OFF

---

### 無料版のプレミアム機能表示

無料版でもプレミアム限定機能を南京錠マーク（🔒）とともに表示する。タップすると課金誘導ポップアップを表示する。

- 🔒 EndCard Track（タイムライン上に表示・ロック状態）
- 🔒 ユーザーウォーターマーク
- 🔒 トーンカーブ
- 🔒 レベル補正

課金誘導ポップアップの内容：機能名 / 「Premiumで解放」の説明 / 月額・年額プラン選択ボタン

---

### 非対応機能

以下は実装しない。

- AI生成機能
- クラウド同期
- ベクター描画
- 3D機能
- 特定メーカー依存のペン入力

---

## 開発ポリシー

- ラスターベース描画のみ
- 低スペック端末での動作速度を最優先
- PC専用環境に依存しない開発構成
- Flutter / Dart で実装
- GitHub でコード管理
