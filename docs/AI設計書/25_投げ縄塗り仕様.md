# 25\_投げ縄塗り仕様

## 概要

投げ縄塗りはペンツール内のサブツール。投げ縄選択とは完全に別ツールであり、「塗る」ことが目的。

---

## ツール配置

ペンツール内のサブツールとして配置する。ペンボタン長押し（または上スワイプ）で表示されるタブUIに含まれる。

```
ペン（長押し・上スワイプ）
├ ブラシ
├ トーン
├ スタンプ
└ 投げ縄塗り
```

---

## 塗り方式

ベタ塗り・トーン塗りを切り替え可能。

```
──────────────────────
ベタ塗り
──────────────────────
トーン一覧
□□□□□□
□□□□□□
```

- ベタ塗り：一番上のボタンを押すだけ
- トーン：その下のトーン一覧から選択

### トーン保持

バケツ塗りと投げ縄塗りはそれぞれ独立して最後に使用したトーンを保持する。互いに変更されない。

---

## 囲って塗るモード

画面上部（Undo付近）に表示するON/OFFスイッチ。

**OFF（通常投げ縄塗り）**

指で囲った軌跡そのものをベタ/トーンで直接描画する。

**ON（囲って塗る）**

囲った範囲内に存在する閉領域のみをバケツ塗りエンジンで一括塗り。

```
内部処理：
投げ縄生成
↓
囲った範囲を走査
↓
閉領域検出
↓
各閉領域へバケツ塗り
```

---

## 透明色対応

透明色を選択して投げ縄塗りすると投げ縄消しゴムとして動作する。専用の投げ縄消しゴムツールは実装しない。

---

## 描画先

現在レイヤーへ直接描画する。選択レイヤーは使用しない。

---

## レイヤー設定反映

| 項目                   | 反映                             |
| ---------------------- | -------------------------------- |
| 現在色                 | ○                                |
| レイヤーブレンドモード | ○                                |
| レイヤー不透明度       | ○                                |
| クリッピング           | ○                                |
| アルファロック         | 実装しない（クリッピングで代用） |

---

## トーン仕様

- サイズ一定
- 回転なし
- 密度変更なし
- 散布なし
- テクスチャループ
- 透明部分は透過維持

---

## 対応ツール

| ツール   | 対応 |
| -------- | ---- |
| ベタ塗り | ○    |
| トーン   | ○    |
| ブラシ   | ✕    |
| スタンプ | ✕    |

---

## アンチエイリアス

- ベタ塗り：ブラシAA設定に準拠
- トーン：テクスチャAA設定に準拠

---

## Undo

投げ縄一回の描画全体を1履歴としてUndo。

---

## 選択範囲との連携

選択範囲が存在する場合、投げ縄塗りは選択範囲内のみ描画される。

---

## 投げ縄選択との違い

| 項目         | 投げ縄塗り        | 投げ縄選択           |
| ------------ | ----------------- | -------------------- |
| 目的         | 囲んだ範囲を塗る  | 囲んだ範囲を選択する |
| 描画先       | 現在レイヤー      | 選択レイヤー         |
| 選択範囲作成 | しない            | する                 |
| ベタ         | ○                 | ✕                    |
| トーン       | ○                 | ✕                    |
| 透明色       | ○（消しゴム動作） | ✕                    |

---

## 既存仕様との連携

- ラスター描画のみ（ベクターなし）
- ベタ描画エンジン・トーン描画エンジンを使用
- レイヤー仕様（クリッピング・ブレンドモード）をそのまま利用
- Undoは通常のUndo履歴に含まれる
