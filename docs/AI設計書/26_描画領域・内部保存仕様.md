# 26\_描画領域・内部保存仕様

## 描画領域と書き出し領域の分離

本アプリでは描画領域と書き出し領域を分離して管理する。

### 書き出し領域

プロジェクト作成時に設定したサイズで固定。この領域が最終的に動画として書き出される範囲となる。

| 例        |
| --------- |
| 1920×1080 |
| 1280×720  |
| 3840×2160 |

### 描画領域

書き出し領域とは別に設定できる拡張描画範囲。デフォルトはOFF。設定からONにすることができる。

- 描画領域倍率を設定することで書き出し領域より広い範囲に描画できる
- 書き出し時は書き出し領域（赤枠内）のみレンダリングする。赤枠外の描画内容は動画に含まれない

---

## 描画領域倍率

| 項目   | 値                             |
| ------ | ------------------------------ |
| 最小   | 1倍（描画領域 = 書き出し領域） |
| 最大   | 10倍                           |
| 初期値 | 2倍                            |

### 倍率と描画可能範囲の例（書き出しサイズ 1920×1080 の場合）

| 倍率 | 描画可能範囲 |
| ---- | ------------ |
| 1倍  | 1920×1080    |
| 2倍  | 3840×2160    |
| 5倍  | 9600×5400    |
| 10倍 | 19200×10800  |

---

## 描画領域の表示

描画領域を広げている場合、書き出し範囲を赤枠で表示する。赤枠の外側も自由に描画できる。

### 赤枠内のみ表示する箇所

- フレーム一覧
- タイムライン
- プレビュー
- 完成プレビュー

---

## 内部保存方式（Sparse Tile）

描画領域全体を画像として保持しない。内部保存はタイル方式（Sparse Tile）を採用する。

### タイル分割

キャンバスを一定サイズの小さなタイルへ分割して管理する。

- タイルサイズ：256×256px または 512×512px（実装側で最適値を決定）

### 保存ルール

- 描画されたタイルのみ保存する
- 何も描かれていないタイルはメモリへ保持しない・保存データにも含めない

```
描画領域イメージ（□=未描画タイル、■=描画済みタイル）

□ □ □ □ □
□ ■ □ □ □
□ ■ ■ □ □
□ □ □ □ □
□ □ □ □ □

保存されるのは ■ が含まれるタイルのみ
```

### メモリ使用量

メモリ使用量は以下によって決定される。

- 描画されたタイル数
- レイヤー数
- フレーム数

描画領域倍率だけではメモリ使用量は増加しない。描画領域を10倍に設定していても、実際に描画していない領域はメモリを消費しない。

---

## 書き出し時の動作

動画書き出し時は描画領域全体ではなく赤枠内（書き出し領域）のみレンダリングする。赤枠外の描画内容は動画に含まれない。

---

## 設定の優先順位

```
ホーム画面設定（デフォルト値）
        ↓
新規プロジェクト作成時の初期値（ホーム画面設定を引き継ぎ・変更可）
        ↓
プロジェクト設定（最優先・作成後でも変更可）
```

---

## ホーム画面設定

描画領域の初期値を設定する。この値が新規プロジェクト作成時の初期値となる。

```
描画領域

初期値

2.0倍
```

---

## 新規プロジェクト作成

ホーム画面設定を初期値として表示する。作成時に変更可能。

```
プロジェクト名

サイズ

FPS

────────────────────────

☑ 描画領域を広くする

倍率

2.0倍
────────────●────────────
```

---

## プロジェクト設定

作成後でも変更可能。プロジェクト設定はホーム画面設定より優先される。

```
描画領域

ON

倍率

3.5倍
```

---

## パフォーマンスに関する注意

描画領域倍率を大きく設定しても、描画していない領域は保存されないため倍率だけを理由に動作が重くなることはない。

ただし以下が多い場合は端末性能によって動作が重くなる場合がある。

- 描画済みタイル数
- レイヤー数
- フレーム数
