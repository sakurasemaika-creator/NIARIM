# 22\_オニオンスキン仕様

## 概要

オニオンスキンは現在編集中フレームの前後のフレームを半透明表示し、滑らかなアニメーション制作を補助する機能。表示専用であり、実データは変更しない。

---

## 表示対象レイヤー

以下の2種類のみを対象とする。ラスタライズ済みキャッシュを利用する。

| 対象                   |
| ---------------------- |
| 通常レイヤー           |
| 自動塗り用線画レイヤー |

共通レイヤー・テキストレイヤー・自動塗りレイヤー（塗りレイヤー）・演出フィルター結果は対象外。

タイムライン素材レイヤー（画像・動画・ウォーターマーク）はオニオンスキン対象外。タイムライン素材は時間軸の管理をタイムラインモードで行うため、フレーム間差分表示の意味がない。

共通レイヤーが対象外の理由：複数フレーム共通表示のため、前後フレームとの差分がなく表示する意味がない。

---

## 設定UI

前フレームと後フレームをそれぞれ独立して設定する。トグルスイッチでON/OFFを切り替え、OFFにすると表示枚数・色・透明度の詳細設定は折りたたまれる。

```

────────────────────

表示　　　　　◉────
────────────────────
（ON時のみ表示）
表示枚数
───────●──────

色

```

### 内部データ構造

```dart
bool showPrevOnion;
int  prevFrames;    // 1〜10
Color prevColor;
double prevOpacity; // 0.0〜1.0

bool showNextOnion;
int  nextFrames;    // 1〜10
Color nextColor;
double nextOpacity; // 0.0〜1.0
```

### 品質設定との連携

| 品質     | 前フレーム                            | 後フレーム                            |
| -------- | ------------------------------------- | ------------------------------------- |
| 低品質   | ON・1枚                               | ON・1枚                               |
| 中品質   | ON・3枚                               | ON・3枚                               |
| 高品質   | ON・5枚                               | ON・5枚                               |
| カスタム | ON/OFF・1〜10枚・色・透明度を個別設定 | ON/OFF・1〜10枚・色・透明度を個別設定 |

品質プリセットを変更しても、オニオンスキンの色・透明度設定は変更しない。ユーザーが設定した色・透明度は常に維持される。

### 色の初期値

| 方向               | 初期色 |
| ------------------ | ------ |
| 前フレーム（過去） | 赤     |
| 後フレーム（未来） | 青     |

### 透明度

- スライダー：0〜100%
- 初期値：35%

### 濃さの変化（ON/OFF）

ONの場合、現在フレームに近いほど濃く表示する。

例（前3枚・濃さの変化ON）：

- -1フレーム：40%
- -2フレーム：25%
- -3フレーム：15%

---

## フレーム間隔

表示するフレームの間隔を設定可能。

選択肢：1フレーム毎 / 2フレーム毎 / 3フレーム毎 / 5フレーム毎

例：前2枚・間隔2 → -2フレーム・-4フレームを表示

---

## 表示方式

- キャンバスへ直接描画せず、表示専用レイヤーとして合成する
- 実データは変更しない
- ペン描画中もリアルタイム表示（描画終了まで待たない）

---

## タイムラインモードでの表示

- タイムラインモードのプレビューにオニオンスキンを表示するかどうかを設定できる
- デフォルト：OFF（プレビュー確認を優先するため）

---

## 書き出し時

動画・GIF・WebM・PNG連番すべてにオニオンスキンは含まれない。表示専用機能。

---

## ショートカット

- オニオンスキンON/OFFをジェスチャー・ペンボタンに割り当て可能
- 設定画面のジェスチャー設定から変更可能

---

## カメラとの連携

オニオンスキンはカメラ変換後の座標で表示する。カメラ移動・拡大・回転が適用された状態で前後フレームを表示するため、カメラワークがある場合でも正確な位置関係を確認できる。
