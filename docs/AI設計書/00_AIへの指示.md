# 00_AIへの指示

## このドキュメントについて

このファイルはNIARIMの開発をAIに依頼する際の前提条件・ルールを定義する。
必ず最初に読み込ませること。

---

## アプリ概要

- アプリ名：NIARIM
- プラットフォーム：Android
- 開発言語：Dart
- フレームワーク：Flutter
- コンセプト：低価格帯Androidでもサクサク動く手書きアニメ制作アプリ

---

## 開発方針

- PC専用環境に依存しない構成とする
- Flutter Webでブラウザ確認を可能とする
- APKビルド後、Android実機（Galaxy端末）で最終確認する
- 低スペック端末（2万円台・64GB・低性能スマホ）でも動作することを最優先とする
- ラスターベース描画のみ。ベクター描画は実装しない

---

## 禁止事項

以下は実装しない。

- AI生成機能
- クラウド同期
- ベクター描画
- 3D機能
- 特定メーカー依存のペン入力SDK

---

## 命名規則

| 対象                 | 規則             | 例               |
| -------------------- | ---------------- | ---------------- |
| 内部シーンフォルダ   | 4桁連番          | Scene0001        |
| レイヤーID           | 4桁連番          | Layer0001        |
| 素材ID               | 4桁連番          | Material0001     |
| プロジェクトファイル | .niapro          | Project.niapro   |
| 共有ファイル         | .niashare        | Project.niashare |
| 機能ID               | カテゴリ-3桁番号 | DRAW-001         |

| UI             | UI             |
| タイムライン   | TL             |

---

## 優先順位

1. 動作の安定性（クラッシュしない）
2. 低スペック端末での動作速度
3. 描画レスポンス
4. UI操作性
5. 機能の充実度

---

## コーディングルール

- 広告SDKへの直接依存禁止。必ずAdvertisingService経由で呼び出す
- 各画面は役割を明確に分離する（キャンバスモード＝描画専用、タイムラインモード＝編集専用）
- 素材はファイル名ではなく素材IDで参照する
- Undoはプロジェクト保存時に保存しない
- 自動保存はキャンバスの内容を変える操作のたびに実行する（最大3件固定・古い順削除・ファイル破損時の復元専用）
