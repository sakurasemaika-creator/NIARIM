# 16_レイヤー仕様

## レイヤー種別

### ユーザー作成可能なレイヤー

| 種別 | アイコン | 備考 |
|------|----------|------|
| 通常レイヤー | 通常アイコン | 描画・編集の基本単位 |
| 共通レイヤー | 🔗アイコン | 複数フレームで共有されるレイヤー |
| 自動塗り用線画レイヤー | 専用アイコン | 自動塗り用の線画を描く専用レイヤー。パーツIDを持つ |
| 自動塗りレイヤー | 専用アイコン | 自動塗り結果を保持する専用レイヤー |
| フォルダ | フォルダアイコン | 複数レイヤーをグループ化 |
| テキストレイヤー | 専用アイコン | 編集可能なテキストオブジェクトを保持 |
| タイムライン画像素材レイヤー | 専用アイコン | タイムラインから追加した画像素材。表示範囲内のフレームのみレイヤーパレットに表示 |
| タイムライン動画素材レイヤー | 専用アイコン | タイムラインから追加した動画素材。表示範囲内のフレームのみレイヤーパレットに表示 |
| ウォーターマークレイヤー | 専用アイコン | タイムラインから追加したウォーターマーク。表示範囲内のフレームのみレイヤーパレットに表示（プレミアム限定） |

「参照レイヤー」という種別は存在しない。バケツ・自動塗りの参照動作は各ツールの仕様で定義する。

### 内部レイヤー（アプリ内部専用）

ユーザーが作成・操作するレイヤーではなく、アプリが内部処理のために使用する一時レイヤー。

| 種別 | 用途 |
|------|------|
| 選択レイヤー（LayerType.selection） | 選択範囲情報を保持するための内部専用レイヤー |

- レイヤーパネルには表示しない
- ユーザーが追加・削除・並び替えすることはできない
- ブラシ・スタンプ・フィルターなどの通常描画対象ではない
- 選択範囲作成後に対象レイヤーへ移動すると選択編集UIへ切り替える
- `LayerType.selection` はコード上で必要であり削除しない

## レイヤー追加

レイヤー追加ボタン押下時にメニューを表示。

```
通常レイヤー
共通レイヤー
フォルダ
───────────
自動塗り用線画レイヤー
自動塗りレイヤー
```

- 自動塗り用線画レイヤー・自動塗りレイヤーはどちらも手動追加可能
- 自動塗り実行時にも自動生成される
- 通常レイヤー ⇔ 特殊レイヤー（自動塗り用線画・自動塗り）の相互変換は行えない
- 例外：テキストレイヤー → ラスタライズ → 通常レイヤーへの変換のみ許可

## レイヤーパネル上部

```
＋　新規レイヤー
📁　新規フォルダ
📷　画像読み込み
```

### 📷 画像読み込み

- タップするとAndroidのファイルピッカーを開く
- 対応形式：PNG / JPG / JPEG / WEBP / BMP / TIFF / GIF（静止画として）/ PSD（対応後）
- 読み込み後：通常レイヤーとして追加・直後に移動/拡大縮小/回転/自由変形モードへ自動移行
- デフォルト配置位置：キャンバス中央
- PSD読み込み時：「統合画像として読み込む」「レイヤーごとに読み込む」を選択可能

※ この画像読み込みは通常レイヤーとして追加する機能。タイムライン素材として追加する場合はタイムラインモードから行う。

---

## タイムライン素材レイヤーのレイヤーパレット操作

タイムライン素材レイヤー（画像・動画・ウォーターマーク）は表示範囲内のフレームでレイヤーパレットに表示される。

| 操作 | 内容 |
|------|------|
| 表示範囲変更 | 三点メニューから開始・終了フレームを変更 |
| 差し替え | 三点メニューから素材を差し替え |
| 削除 | 三点メニューから削除（素材全体を削除） |

- 複製はレイヤーパレットからは行わない。タイムラインモードから行う。
- レイヤー順の変更はレイヤーパレットのドラッグで行う（フレーム単位）。

---

## レイヤーパネル

レイヤー一覧を縦スクロールで表示。各レイヤーの表示構成：

```
□表示  ★お気に入り  [サムネイル]  レイヤー名  ❗更新マーク  [種別アイコン]  🔒ロックアイコン
```

- サムネイルはペンを離した瞬間に現在レイヤーのみ更新する（全レイヤー一括更新はしない）
- ❗更新マークは自動塗りレイヤーが最新でない場合に表示（詳細は自動塗りレイヤーの項を参照）
- 🔒はロック中のみ表示
- 長押しで複数選択モード開始

---

## レイヤー複数選択

### 開始・終了

- レイヤーを長押しで複数選択モード開始
- 最後の1件を解除した時点で複数選択モード終了

### 同種レイヤーのみ追加選択可能

**最初に選択したレイヤーと同じ種別のレイヤーのみ追加選択できる。**

これはタイムラインモードの複数選択（フレーム・シーン・動画素材など）と操作体系を統一するためのルールである。

| 最初に選択したレイヤー | 追加選択できるレイヤー |
|----------------------|----------------------|
| 通常レイヤー | 通常レイヤーのみ |
| フォルダ | フォルダのみ |
| 自動塗り用線画レイヤー | 自動塗り用線画レイヤーのみ |
| 自動塗りレイヤー | 自動塗りレイヤーのみ |
| テキストレイヤー | テキストレイヤーのみ |
| タイムライン画像素材レイヤー | タイムライン画像素材レイヤーのみ |
| タイムライン動画素材レイヤー | タイムライン動画素材レイヤーのみ |
| ウォーターマークレイヤー | ウォーターマークレイヤーのみ |

異なる種別のレイヤーはチェックボックスをタップしても選択されない（グレーアウト表示）。

### 選択操作

- 複数選択モード中はレイヤー左側にチェックボックスを表示
- チェックボックスまたはレイヤー本体タップで選択・解除
- 選択済みレイヤーをシングルタップするとそのレイヤーのみ選択解除
- 最初に選択したレイヤーと異なる種別のレイヤーはチェックボックスがグレーアウトされタップ不可

### 全選択・全解除

複数選択モード中は以下のボタンを表示する。

- 全選択（最初に選択したレイヤーと同種のレイヤーのみ全選択）
- 全解除

### 複数選択中に実行できる操作

| 操作 | 条件 |
|------|------|
| 削除 | 通常レイヤーが最後の1枚になる場合はグレーアウト・タップ不可（メッセージ表示なし） |
| 移動 | 常に実行可能 |
| フォルダへ移動 | 常に実行可能 |
| フォルダ化 | 常に実行可能 |
| 結合 | 結合可能なレイヤーのみ選択されている場合のみ有効（それ以外はグレーアウト） |

レイヤー種別により実行できない操作は自動でグレーアウトする。

### タイムライン素材レイヤーの複数選択

タイムライン画像・動画・ウォーターマークも通常レイヤーと同様に複数選択できる。
同種ルールにより、例えばタイムライン画像素材レイヤーを最初に選択した場合はタイムライン画像素材レイヤーのみ追加選択できる。

- 複数選択での対応操作：**削除のみ**
- 表示範囲変更・差し替えは三点メニューから個別に行う（複数選択では非対応）

## レイヤー検索

- レイヤーパネル上部に🔍アイコンのみ表示
- 🔍タップで検索バーが展開される
- レイヤー名で検索

## レイヤー操作

| 操作 | 内容 |
|------|------|
| 名前変更 | レイヤー名タップ、または三点メニューから変更可能 |
| 複製 | コピーオンライト方式で追加（複製直後は実データをコピーしない・編集時に初めて実体化） |
| 結合 | 選択レイヤーを1枚に統合（制約は下記参照） |
| 削除 | 確認ポップアップなしで即削除・Undoで復元可能（ゴミ箱はない） |
| 並び替え | ドラッグで順序変更 |
| 複数選択 | 長押しで選択モード開始・全選択・全解除（詳細は「レイヤー複数選択」セクション参照） |

---

## レイヤーID

- 内部管理用に4桁連番のIDを付与（形式は未確定・例：L0001）
- UUIDは使用しない（デバッグしやすい連番方式）
- レイヤー名はユニーク不要（同名レイヤーを複数作成可能）

---

## 表示・ロック

| 項目 | 内容 |
|------|------|
| 表示ON/OFF | 目のアイコンで切替 |
| ロック | 移動・描画・編集を禁止。ロック中は🔒アイコンを表示 |
| 不透明度ロック | 透明ピクセルへの描画を禁止 |

アルファロックは実装しない。クリッピングで代用する。

## ブレンドモード

各レイヤーに設定可能。

- 通常
- 乗算
- スクリーン
- オーバーレイ
- 加算
- 減算
- 比較（暗）
- 比較（明）
- 焼き込みカラー
- 覆い焼きカラー
- ハードライト
- ソフトライト
- 差の絶対値
- 色相
- 彩度
- カラー
- 輝度

## 不透明度

- 各レイヤーに個別の不透明度を設定可能（0〜100%）

---

## クリッピング

- レイヤーパネルにクリッピングボタンを配置
- ONにすると現在選択中レイヤーが一つ下のレイヤーへクリッピングされる
- クリッピング先がさらにクリッピングされている場合は、一番下のクリッピング元レイヤーの不透明形状を使用する
- クリッピング中のレイヤーはレイヤー左側に └ マークを表示し、どのレイヤーがクリッピングされているか一目で分かる
- フォルダを跨ぐクリッピングは禁止
- 自動塗りレイヤーへのクリッピング対応
- 自動塗りレイヤー・自動塗り用線画レイヤーもフォルダ跨ぎクリッピング禁止

---

## マスク（廃止・クリッピングで代用）

専用のレイヤーマスク機能は実装しない。描画範囲を制御したい場合は上記の
「クリッピング」で代用する（下のレイヤーの不透明範囲内のみ描画される
仕組みは、実質的にマスクと同じ目的を果たせるため）。

---

## フォルダ

- 複数レイヤーをグループ化
- 開閉（展開・折りたたみ）が可能
- フォルダ自体にもブレンドモード・不透明度・ロックを設定可能
- フォルダへのクリッピング対応
- フォルダ選択中に描画フィルターを適用すると、フォルダ内の全レイヤーへ反映される

---

## レイヤー結合

| 組み合わせ | 結合可否 | 備考 |
|-----------|---------|------|
| 通常レイヤー同士 | ○ | |
| フォルダ内レイヤー同士 | ○ | |
| フォルダ同士 | ○ | |
| 自動塗り用線画レイヤー | ○ | 結合後は通常レイヤーへ変換（パーツID削除） |
| 自動塗りレイヤー | ○ | 結合後は通常レイヤーへ変換（自動塗り属性削除） |
| 共通レイヤー | ✕ | 他フレームへ影響するため結合不可 |
| フォルダ＋レイヤー（異なる階層） | ✕ | |
| フォルダ＋フォルダ内レイヤー（異なる階層） | ✕ | |
| タイムライン素材（画像・動画・ウォーターマーク） | ✕ | 通常レイヤーとの結合不可。結合メニューは表示しない |

結合時のブレンドモード：一番下のレイヤーのブレンドモードに合わせる。

### 共通レイヤーと通常レイヤーの内容共有

共通レイヤーと通常レイヤーの直接変換は行わない。内容を共有したい場合は以下の手順で行う。

```
範囲選択
↓
コピー
↓
貼り付け（対象レイヤーへ）
```

これにより見た目のみ複製できる（リンクは作成しない）。

## 共通レイヤー

- 複数フレームで同一の描画内容を共有するレイヤー
- 通常レイヤーとは内部構造が異なるため相互変換不可
- レイヤー一覧では🔗アイコンと適用範囲で通常レイヤーと区別する（例：🔗 影（1〜120））

### 共通レイヤー化ダイアログ

通常レイヤーを共通レイヤーへ変更しようとした場合、以下のダイアログを表示する。

```
共通レイヤーへ変更

○ 現在レイヤーを共通化
  （このレイヤーのみを共通レイヤーとして設定します）

○ 表示中レイヤーを複製して全統合して共通化
  （表示中のすべてのレイヤーを統合した結果を共通レイヤーとして作成します）

キャンセル　　OK
```

### 追加時の設定

共通レイヤーを選択すると以下を設定するダイアログを表示する。

```
共通レイヤー範囲

開始フレーム
[   1   ]

終了フレーム
[ 120 ]

「現在範囲を使用」ボタン

────────────────

○ 全フレーム
○ 現在シーン
○ シーン指定
○ フレーム範囲指定

        キャンセル　作成
```

- 「現在範囲を使用」ボタンでタイムラインの現在表示範囲を開始・終了に自動セットできる

### 三点メニュー（共通レイヤー専用）

共通レイヤーの三点メニューには以下を表示する。

- 表示フレーム範囲変更
- 複製
- 名前変更
- 削除

「表示フレーム範囲変更」を押すと以下のダイアログを表示する。

```
表示範囲

開始フレーム
[      ]

終了フレーム
[      ]

────────────

○ 全フレーム
○ 現在シーン
○ シーン固定

────────────

キャンセル　　　OK
```

範囲変更により表示されなくなるフレームが発生する場合は確認ダイアログを表示する。

### タイムラインでの表示範囲変更

タイムライン上では左右のドラッグハンドルでも表示範囲を変更できる。シングルタップで表示範囲設定ダイアログを開く。

### 共通レイヤーの一部フレームだけ変更したい場合

範囲選択で内容をコピーして通常レイヤーとして貼り付けて上書きする。共通レイヤーはそのまま維持される。共通レイヤーから通常レイヤーへの変換機能は実装しない。

### 共通レイヤーと自動塗りの関係

- 共通レイヤーは自動塗りの対象外
- 共通レイヤーはオニオンスキンの対象外

---

## 自動塗りレイヤー

- 自動塗り用線画レイヤーと自動塗りレイヤーはどちらも手動追加可能
- 自動塗り実行時にも自動生成される
- 同一パーツIDの線画レイヤーのみを参照して塗り分ける
- 自動塗り用線画レイヤーのレイヤー名・自動塗りレイヤーのレイヤー名はユーザーが変更できない
- 表示名はパーツ名に連動する（例：「髪（線画）」「髪（自動塗り）」）
- パーツ名を変更すると対応するレイヤーの表示名も一括で変わる
- 内部パーツIDはパーツ名変更時も変更されない

### 自動塗り実行時の挙動

| 状況 | 動作 |
|------|------|
| 線画直下に自動塗りレイヤーが存在する | そのレイヤーを更新（塗りなおし or 色更新） |
| 線画直下に自動塗りレイヤーが存在しない | 直下へ新規生成→一から塗る |
| 手動配置した自動塗りレイヤー | 位置は変更しない・塗りなおし/色更新の対象に含まれる |
| 新規追加された線画レイヤー（塗りレイヤーなし） | 色更新選択時でも必ず新規生成→一から塗る |
| 対応する線画レイヤーが存在しない自動塗りレイヤー | 塗りなおし：形状破棄→何もしない / 色更新：形状維持→色のみ更新 |

### 塗りなおし

既存の自動塗りレイヤーのレイヤー位置は変更しない。現在の塗り形状を破棄し、自動塗り用線画レイヤーから領域を再判定して一から塗りなおす。

### 色更新

既存の自動塗りレイヤーのレイヤー位置・形状は変更しない。不透明度ロックをかけて最新の色設定のみ反映する。

### 更新マーク（❗）

表示条件：線画変更 / 色プリセット変更 / 自動塗り設定変更のいずれかが発生した場合

- ❗タップ → 自動塗り実行ダイアログへ遷移
- ❗長押し → 「現在の自動塗りは最新ではありません。タップすると更新できます。」を表示

---

## テキストレイヤー

- 編集可能なテキストオブジェクトを保持
- ラスタライズで通常レイヤーに変換可能（通常レイヤー ⇔ 特殊レイヤー変換の唯一の例外）
- 詳細は 15_テキストツール・フォント仕様.md を参照

### テキストレイヤーの追加方法

テキストレイヤーはレイヤーパレットの＋ボタンからは追加しない。キャンバスツールのテキストツールから生成する。

```
テキストツールを選択
↓
キャンバスをタップ
↓
テキスト入力ダイアログ
↓
OK
↓
テキストレイヤーが自動生成される
```

レイヤーパネルの＋ボタンメニューにテキストレイヤーは表示しない。

---

## バケツ・投げ縄塗り・自動塗りの参照動作

| ツール | 参照対象 |
|--------|---------|
| バケツ | 表示中のすべてのレイヤーの線を参照 |
| 投げ縄塗り | 選択範囲のみ |
| 自動塗り | 同一パーツIDの自動塗り用線画レイヤーのみ |

「参照レイヤー」という種別は存在しない。

---

## フィルター適用範囲

| 状態 | 適用先 |
|------|--------|
| 選択範囲あり | 選択範囲のみ |
| 選択範囲なし・通常レイヤー選択中 | 現在レイヤー |
| 選択範囲なし・フォルダ選択中 | 現在フォルダ全体 |
| 選択範囲なし・共通レイヤー選択中 | 設定された適用範囲（全体・シーン・範囲）へ反映 |

---

## Undo / Redo

- レイヤー操作（追加・削除・移動・結合・複製）はすべてUndo対応
- デフォルト50回・設定画面で変更可能
