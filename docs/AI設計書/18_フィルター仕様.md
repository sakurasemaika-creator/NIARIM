# 18\_フィルター仕様

## フィルターの種別

NIARIMのフィルターは「描画フィルター」と「演出フィルター」の2種類に分かれる。

| 種別           | 適用対象                                   | タイミング                           |
| -------------- | ------------------------------------------ | ------------------------------------ |
| 描画フィルター | レイヤー・フォルダ・共通レイヤー・選択範囲 | 静止画として直接適用（破壊編集）     |
| 演出フィルター | タイムライン（映像のみ）                   | 再生・書き出し時に適用（非破壊編集） |

描画フィルター版と演出フィルター版は別管理であり、設定は共有しない。

---

## 描画フィルター

レイヤーへ直接適用する静止画フィルター。適用後はUndo対応。

### 適用範囲

| 状態                             | 適用先                                         |
| -------------------------------- | ---------------------------------------------- |
| 選択範囲あり                     | 選択範囲のみ                                   |
| 選択範囲なし・通常レイヤー選択中 | 現在レイヤー                                   |
| 選択範囲なし・フォルダ選択中     | 現在フォルダ全体                               |
| 選択範囲なし・共通レイヤー選択中 | 設定された適用範囲（全体・シーン・範囲）へ反映 |

「参照レイヤー」という種別は存在しないため、参照レイヤー選択中という状態はない。

選択範囲（矩形・投げ縄・自動選択・全選択で作ったキャンバス上の範囲）があるときは、プレビューも適用も**その内側だけ**を変え、外側の画素はそのまま残す（範囲の縁がプレビューの縮小で半端になる所は混ぜる）。縁取り・墨溜まり・自動線画のように新しいレイヤーへ描くものは、新しいレイヤーの範囲外を透明にする。調整パネルには「選択範囲の中だけに適用されます」と出す。**フィルターの調整UIと選択範囲の編集UIは同時に出さない**：フィルターの調整中（スマホはフィルターパネルを開いている間、PC/DeXはドッキングしたパネルでフィルターを選んで調整している間）は、選択範囲の編集UI（選択ツールの操作バー・変形スライダー・キャンバス上の変形ハンドル・上部バーの「選択範囲を反転」）を一時的に隠し、キャンバスへのタッチはフィルターのつまみだけが受ける。適用・閉じる（キャンセル）・一覧へ戻る等で調整を離れると、選択範囲はそのままで編集UIが再び出る。球体陰影は選択レイヤーが無ければ選択範囲を自分の範囲として使う。眼鏡断層は自分の「レンズの範囲」を使う（下記）。

### 初期実装フィルター

| フィルター     | 設定項目                                                                 | 備考                                                               |
| -------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| ガウスぼかし   | 強さ                                                                     | 大量フレームへの適用時はプログレスバーを表示（例：25/120フレーム） |
| レンズぼかし   | 強さ                                                                     | 同上                                                               |
| アニメ風加工   | 強さ・色数・エッジ強調                                                   | 選択中のレイヤー・フォルダ・共通レイヤー・選択範囲に適用           |
| トーンカーブ🔒 | プリセット（リニア・明るく・暗く・高コントラスト・低コントラスト・反転） | プレミアム限定。詳細は20\_色管理仕様.md参照                        |
| レベル補正🔒   | 入力ブラック・入力ホワイト・出力ブラック・出力ホワイト                   | プレミアム限定。詳細は20\_色管理仕様.md参照                        |

### お気に入り（描画フィルター）

- お気に入り登録・お気に入りのみ表示に対応
- フィルター検索対応
- リアルタイムプレビュー対応

## 演出フィルター

タイムラインに適用する非破壊編集フィルター。映像（フレーム）にのみ適用され、動画トラック・音声トラックには影響しない。

### 非破壊編集・キャッシュ方式

演出フィルターは元の描画データを書き換えない。初回適用時または設定変更時のみキャッシュを生成し、通常再生時はキャッシュを利用することで低スペック端末でも高速再生を実現する。

### 適用範囲指定

各演出フィルターに開始フレーム・終了フレームを指定できる。

### 複数フィルターの適用順

タイムライン上の並び順に従って適用される。

例：ぼかし → ノイズ → フェード の順に並んでいればその順で処理。

### フィルター操作

| 操作     | 内容                             |
| -------- | -------------------------------- |
| 追加     | フィルターをタイムラインへ追加   |
| 複製     | フィルターを複製                 |
| 並び替え | ドラッグで順序変更               |
| ON/OFF   | 目アイコンで一時無効・有効を切替 |
| 削除     | フィルターを削除                 |

### 初期実装フィルター

| フィルター   | 設定項目                                           |
| ------------ | -------------------------------------------------- |
| フェード     | 色指定・開始・終了タイミング                       |
| ガウスぼかし | 強さ・開始フレーム・終了フレーム                   |
| レンズぼかし | 強さ・開始フレーム・終了フレーム                   |
| モザイク     | サイズ・開始フレーム・終了フレーム                 |
| 色収差       | 強さ・方向・開始フレーム・終了フレーム             |
| ノイズ       | 強さ・種類・開始フレーム・終了フレーム             |
| アニメ風加工 | 強さ・色数・エッジ強調・開始フレーム・終了フレーム |

### お気に入り（演出フィルター）

- お気に入り登録・お気に入りのみ表示に対応
- フィルター検索対応
- リアルタイムプレビュー対応

## アニメ風加工フィルター

- 描画フィルター・演出フィルターの両方に実装
- 設定項目：強さ / 色数 / エッジ強調
- 描画フィルター版と演出フィルター版は別管理であり、設定は共有しない
- 演出フィルター版はキャッシュ方式で処理するため低スペック端末でも動作可能

## 球体陰影フィルター

- 描画フィルター。楕円の光の内側を光色、外側を影色で、**描いてあるところにだけ**重ねる（クリッピングレイヤーと同じ扱い。レイヤー自身の不透明度は変えない）
- 影色・光色：カラーチップ→カラーピッカーで選ぶ（透明も可。色のアルファがかかり具合で、透明にした側は何もしない）
- 合成のしかた：
  - 「影と光を別々に」：影色・光色それぞれにブレンドモード（レイヤーと同じ25種、既定は乗算・スクリーン）
  - 「まとめて1つで」：影色→光色のグラデーションを1つのブレンドモード（既定ハードライト）で重ねる。中間の灰色より暗い色は暗く、明るい色は明るくなる
- 光の楕円：位置X・Y（キャンバス幅・高さに対する%、0〜100）、大きさX・Y（キャンバスの短い辺に対する%、1〜200。同じ値なら真円）。いずれも「−・スライダー・＋」で1ずつ増減でき、数値をタップすると直接入力できる
- 境目のぼかしは2本：**光側のぼかし**（楕円の縁から内側へ、光色がどこから弱まり始めるか）と**影側のぼかし**（縁から外側へ、影色がどこで満ちきるか）。どちらも半径に対する%（0〜100、既定はどちらも30）で、片方を変えてももう片方の側は動かない。0でも縁は1px程度のアンチエイリアスで滑らかにする
- 割合で持つので、縮小プレビューと本適用で光が同じ場所に来る
- 選択レイヤーを塗ってあれば、その範囲だけに付ける。選択レイヤーが無くキャンバスに選択範囲があれば、その範囲だけに付ける（どちらも無ければレイヤー全体）
- ブレンドの式は`lib/engine/blend_math.dart`（レイヤー合成と同じ式。25種すべてを実際の合成結果と照合するテストあり）

## 背景馴染ませフィルター

- 対象（作業レイヤー）の周りの背景（他の表示レイヤー）から主光源・副光源・環境光・影色・反射色を推定し、**描いた内容全体**へ色を乗せる（縁だけではない）
  - 環境光：内容全体へ（縁ほど少し強く）
  - 光と影：対象全体にわたり、光源側から反対側へ明暗の勾配（中央は光と影の両方が少しずつ）。縁では輪郭の向きと光源方向の一致度で強める
  - 反射光：下側全体へ弱く、下向きの縁で強く。色移り：縁の近くだけ近傍の背景色
- 色は乗算済みの画素を元の色に戻して扱い、不透明度を掛け直して書き戻す（半透明の絵も不透明の絵と同じ色になる）。アルファは変えない
- 結果は画素へ直接焼き込むので、合成モードを重ねて統合したときに見え方が変わることはない

## 魚眼レンズフィルター

- 設定項目：**歪み**（−100〜100、既定50）・**半径**（効く範囲。キャンバスの対角線の半分に対する%、1〜100）・中心X・Y
- 歪みが正なら中央が膨らむ（実際の魚眼レンズのように中央が拡大され、縁へ向かって圧縮される）、負なら中央がすぼまる、0なら何もしない
- 半径の外側は動かない

## 新規レイヤーを作るフィルター（縁取り・墨溜まり・自動線画）

- 縁取り・墨溜まりは元のレイヤーの直下、自動線画は直上へ新規レイヤーを作る
- 新規レイヤーは元のレイヤーと同じフォルダに入り、直上のレイヤーがクリッピングしているときは自分もクリッピングにする（クリッピングしている元レイヤーの下へ縁取りを入れても、元レイヤーのクリッピング先が縁取りに変わらない。元レイヤーへクリッピングしたレイヤーとの間へ自動線画を入れても同様）

## 眼鏡断層フィルター（レンズの範囲）

- 選んだ範囲（レンズ）ごとに、その重心を中心とした局所的な放射状の歪みをかける。範囲は連結した塊ごとに別のレンズになる（両目を一度に塗れる）
- 範囲は**調整中にキャンバスへ直接塗る**。パネルの「レンズの範囲」に**ペン**（塗る）・**消しゴム**（消す）・**バケツ**（タップした所を自動選択と同じ判定で加える。参照は自動選択の「作業レイヤーのみ／表示レイヤーすべて」に従う）と、範囲を消すボタン、ペンの太さ（画面上の半径2〜80px。ズームしても指の下で同じ大きさ）がある
- 塗った範囲はキャンバス上にピンクの半透明で重ねて表示する（選択範囲の青と区別）。書き出し・レイヤーには写らない
- 1本のストローク・1回のバケツ・範囲を消す操作は、それぞれフィルター編集のUndo/Redo1手
- フィルターを選んだとき、選択レイヤーが塗ってあればその範囲から、無ければキャンバスの選択範囲から始まる（どちらも無ければ空で、ペンを選んだ状態）。範囲が空のときは塗り方の案内を出す
- 範囲は調整パネルを閉じるか別のフィルターを選ぶと忘れる
- 強さ（−100〜100、負で凹レンズ風に縮小、正で凸レンズ風に拡大）、中心位置の微調整（左右・上下）

## 調整画面（描画フィルター）

- スマホでは、フィルターを選んで調整している間、キャンバスモード専用の上部バー（独自のUndo/Redoを含む）・太さ/不透明度スライダー・ツールバー・フレーム一覧を一時的に隠す。調整パネルは**画面下部に横幅いっぱい**で出し、キャンバスはその上の残り全部を使う（役割の重なるボタンを2か所に出さず、作業領域を広く取るため）。一覧へ戻る・閉じる・適用でキャンバスモードの表示に戻る
- プレビューは**キャンバスそのもの**に出す（別枠のプレビューは出さない）。編集中のレイヤーの絵だけをフィルター後の縮小画像（長辺640px）に差し替えて描くので、光の位置・魚眼の中心などをキャンバス上で動かしながら結果をそのまま見られる。プレビューの計算は別Isolate（`compute`）で行い、操作中に追い越された分は捨てて最新の設定だけを描く。自動線画だけは制御点の編集枠がパネル内に残る
- 下部パネルの中身：名前の行（一覧へ戻る・名前・たたむ・閉じる）／調整項目（高さは画面の3割まで、右端にスクロールバーを常時表示）／Undo・Redo・適用の行。スライダーは「項目名と数値・−・スライダー・＋」の1行で、色とブレンドモードも1行に並べる
- 「たたむ」でコントロールを畳むと、名前とUndo/Redo/適用だけになる
- 適用前はレイヤーの画素を一切変えない。調整中のキャンバスへのタッチは、つまみ以外では描画しない
- PC/DeX（横に広い画面）では従来どおり横のパネルに出し、キャンバスモードの表示も隠さない

## キャンバス上のつまみ（球体陰影・魚眼）

- フィルター編集中、球体陰影は光の楕円（中心の「＋」、右端＝幅・下端＝高さの丸いつまみ）、魚眼は中心の「＋」と効く範囲の円（円上の丸いつまみ＝半径）をキャンバスに表示し、ドラッグで動かせる（スライダーと連動、1回のドラッグがフィルターのUndo1手）
- 魚眼の半径のつまみは、円が画面外へはみ出すとき（100%だと円はキャンバスの四隅を通る）は**画面内の円周上**へ回り込んで描く。円周上ならどこを掴んでも同じ半径になる。いったん置いた向きは、画面内にある限りそのまま保つ
- つまみの大きさ・線の太さは画面基準（ズームしても同じ大きさ）。当たり判定は定規のつまみと同じ指28px相当
- つまみ以外へのタッチでは何もしない（フィルター編集中に誤ってレイヤーへ描かない）。2本指の拡大・移動は使える
- 魚眼の中心X・Yはキャンバス幅・高さに対する%（中央から±50で端まで）

## フィルター適用時の広告（無料版）

- フィルター処理中（進行中）に正方形広告を表示
- 処理完了時に自動消去
- 対象：フィルター適用 / 動画書き出し / GIF生成 / 透過WebM生成 / 大量処理実行時
