# 18_フィルター仕様

## フィルターの種別

MIRANIMAのフィルターは「描画フィルター」と「演出フィルター」の2種類に分かれる。

| 種別 | 適用対象 | タイミング |
|------|----------|-----------|
| 描画フィルター | レイヤー・フォルダ・共通レイヤー・選択範囲 | 静止画として直接適用（破壊編集） |
| 演出フィルター | タイムライン（映像のみ） | 再生・書き出し時に適用（非破壊編集） |

描画フィルター版と演出フィルター版は別管理であり、設定は共有しない。

---

## 描画フィルター

レイヤーへ直接適用する静止画フィルター。適用後はUndo対応。

### 適用範囲

| 状態 | 適用先 |
|------|--------|
| 選択範囲あり | 選択範囲のみ |
| 選択範囲なし・通常レイヤー選択中 | 現在レイヤー |
| 選択範囲なし・フォルダ選択中 | 現在フォルダ全体 |
| 選択範囲なし・共通レイヤー選択中 | 現在共通レイヤー |

「参照レイヤー」という種別は存在しないため、参照レイヤー選択中という状態はない。

### 初期実装フィルター

| フィルター | 設定項目 | 備考 |
|-----------|----------|------|
| ガウスぼかし | 強さ | 大量フレームへの適用時はプログレスバーを表示（例：25/120フレーム） |
| レンズぼかし | 強さ | 同上 |
| アニメ風加工 | 強さ・色数・エッジ強調 | 選択中のレイヤー・フォルダ・共通レイヤー・選択範囲に適用 |

### お気に入り

- お気に入り登録・お気に入りのみ表示に対応

---

## 演出フィルター

タイムラインに適用する非破壊編集フィルター。映像（フレーム）にのみ適用され、動画トラック・音声トラックには影響しない。

### 非破壊編集・キャッシュ方式

演出フィルターは元の描画データを書き換えない。初回適用時または設定変更時のみキャッシュを生成し、通常再生時はキャッシュを利用することで低スペック端末でも高速再生を実現する。

### 適用範囲指定

各演出フィルターに開始フレーム・終了フレームを指定できる。

### 複数フィルターの適用順

タイムライン上の並び順に従って適用される。

例：ぼかし → ノイズ → フェード の順に並んでいればその順で処理。

### フィルター操作

| 操作 | 内容 |
|------|------|
| 追加 | フィルターをタイムラインへ追加 |
| 複製 | フィルターを複製 |
| 並び替え | ドラッグで順序変更 |
| ON/OFF | 目アイコンで一時無効・有効を切替 |
| 削除 | フィルターを削除 |

### 初期実装フィルター

| フィルター | 設定項目 |
|-----------|----------|
| フェード | 色指定・開始・終了タイミング |
| ガウスぼかし | 強さ・開始フレーム・終了フレーム |
| レンズぼかし | 強さ・開始フレーム・終了フレーム |
| モザイク | サイズ・開始フレーム・終了フレーム |
| 色収差 | 強さ・方向・開始フレーム・終了フレーム |
| ノイズ | 強さ・種類・開始フレーム・終了フレーム |
| アニメ風加工 | 強さ・色数・エッジ強調・開始フレーム・終了フレーム |

### お気に入り

- お気に入り登録・お気に入りのみ表示に対応

---

## アニメ風加工フィルター

- 描画フィルター・演出フィルターの両方に実装
- 設定項目：強さ / 色数 / エッジ強調
- 描画フィルター版と演出フィルター版は別管理であり、設定は共有しない
- 演出フィルター版はキャッシュ方式で処理するため低スペック端末でも動作可能

---

## フィルター適用時の広告（無料版）

- フィルター処理中（進行中）に正方形広告を表示
- 処理完了時に自動消去
- 対象：フィルター適用 / 動画書き出し / GIF生成 / 透過WebM生成 / 大量処理実行時
