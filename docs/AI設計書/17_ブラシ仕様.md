# 17_ブラシ仕様

## 基本方針

- ラスターベース描画のみ（ベクターなし）
- タッチ入力・ペン入力双方を入力ソースとして抽象化しブラシエンジンへ渡す
- 低スペック端末でも快適動作
- アプリ終了後も最後に使用したブラシを記憶・復元する

---

## ブラシ・トーン・スタンプの役割

| 機能 | 色情報 | サイズ変化 | 主用途 |
|------|--------|-----------|--------|
| ブラシ | 現在色 | ブラシサイズに連動 | 自由描画 |
| トーン | 現在色 | 常に一定サイズでループ | 規則パターン・漫画トーン |
| スタンプ | スタンプ画像が保持 | ブラシサイズに連動 | 色付き素材・装飾 |

---

## ペンツールの構成

ペンボタンを長押し（または上スワイプ）するとタブUIを表示。

```
ブラシタブ  |  トーンタブ  |  スタンプタブ
```

通常タップ：現在選択中のブラシ・トーン・スタンプで描画。

### 管理項目

- ブラシ一覧
- お気に入り

- ブラシ検索
- 自作ブラシ
- 読み込み
- 書き出し

### ブラシ設定項目

| 項目 | 内容 |
|------|------|
| サイズ | 1〜500px・スライダー |
| 不透明度 | 1〜100%・スライダー |
| 間隔 | スタンプ間隔を調整・スライダー |
| ぼかし半径 | 0〜100・スライダー・デフォルト0 |
| 手ぶれ補正 | ON/OFF・強度調整 |
| ドットペンモード | チェックボックスでON/OFF（ON時：アンチエイリアス完全OFF・ピクセル単位描画） |
| 筆圧反映 | OFF / サイズ / 不透明度 / サイズ＋不透明度（ブラシ個別設定） |
| 筆圧反映度 | 0〜100%・スライダー（ブラシ個別設定） |
| フェード | OFF / 弱 / 中 / 強 / カスタム |
| ストローク減衰 | ON/OFF |
| 混色 | OFF / 知覚的混色 / にじみ |
| 混色率 | 0〜100%・スライダー（混ざり方の強さ） |
| 明るさ補正 | 5段階・知覚的混色時のみ表示・デフォルト中 |
| 回転 | ON/OFF |
| 密度 | スライダー |
| 散布 | スライダー |

筆圧カーブ（弱 / 普通 / 強 / カスタム）はアプリ全体の設定画面で管理する。

## トーンタブ

### 管理項目

- トーン一覧
- お気に入り
- お気に入りのみ表示（チェックボックス）
- トーン検索
- 自作トーン
- 読み込み
- 書き出し

### トーン仕様

- 現在色で描画（色情報を保持しない）
- ブラシサイズを変更してもトーンパターン自体のサイズは変化しない
- テクスチャは一定サイズでループ表示
- 回転なし・密度なし・散布なし
- 不透明度変更可能
- ドットモード対応
- テクスチャ内の透明部分は透過
- 編集可能なのは名前・テクスチャ画像のみ

---

## スタンプタブ

### 管理項目

- スタンプ一覧
- お気に入り
- お気に入りのみ表示（チェックボックス）
- スタンプ検索
- 自作スタンプ
- 読み込み
- 書き出し

### スタンプ仕様

- スタンプ画像自体が色情報を保持（現在色は使用しない）
- ブラシサイズに応じてスタンプサイズ変更
- 回転・密度・散布対応
- 不透明度変更可能
- テクスチャ内の透明部分は透過

### スタンプ使用時の色アイコン

スタンプ選択中は色アイコンに白縁取りの赤斜線を重ねて表示（🚫）。タップすると「スタンプは色情報を保持しているため色変更できません」のトーストを表示。ブラシ・トーンへ戻ると通常表示へ戻る。

## 消しゴム

消しゴムを長押し（または上スワイプ）すると切替。

- ブラシ消しゴム：通常消しゴム
- トーン消しゴム：トーン形状そのままで透明色を描画

スタンプは消しゴムに表示しない。

---

## バケツ

バケツを長押し（または上スワイプ）すると切替。

- ベタ塗り：通常バケツ
- トーン塗り：トーンをループ配置して塗る

---

## 自動塗り対象

| ツール | 自動塗り対象 |
|--------|------------|
| ベタ塗り | ○ |
| トーン | ○ |
| ブラシ | ✕ |
| スタンプ | ✕ |

ブラシやスタンプはランダム性や色情報を持つため、自動塗りでは使用しない。自動塗りプリセットでトーンを使う場合はバケツトーンエンジンを使用する。

---

## フォルダ管理

ブラシ・トーン・スタンプすべてフォルダ管理対応。

- フォルダは1階層のみ（フォルダの中にフォルダは作成不可）
- フォルダ内へ自由に移動可能
- フォルダに入れない素材（ルート配置）も可能

| 操作 | 内容 |
|------|------|
| 新規作成 | フォルダを追加 |
| 名前変更 | フォルダ名を変更 |
| 並び替え | ドラッグで順序変更 |
| お気に入り登録 | フォルダごとお気に入りに登録可能 |
| 削除 | 確認ダイアログを表示・中の素材はルートへ戻す |

---

## お気に入り

- 登録対象：ブラシ・トーン・スタンプ単体 / フォルダ
- ★タブでお気に入りのみ表示
- フォルダをお気に入り登録すると、そのフォルダ内の素材をまとめて表示できる

---

## 検索

- 🔍タップで検索バーが展開される
- 検索対象：名前 / フォルダ名
- 検索中はフォルダ構造に関係なく一致した素材・フォルダを一覧表示

---

## フェード仕様

ストロークが進むにつれて不透明度・サイズが減少する。

| 設定 | 内容 |
|------|------|
| OFF | フェードなし |
| 弱 / 中 / 強 | プリセット |
| カスタム | 開始値（%）/ 終了値（%）/ 距離（px）を個別設定 |

---

## ストローク減衰仕様

- 筆圧ではなく、描き続けるほどインクが減るような表現
- ストローク後半で自然に薄くなる（インク切れ表現）

---

## 混色仕様

混色はブラシ単位で設定する。混色モードは描画機能であり、パフォーマンス品質設定とは独立させる。すべての品質設定で利用可能とし、品質設定によるグレーアウト・非表示・使用禁止は行わない。

- モード：OFF / 知覚的混色 / にじみ
- 知覚的混色：ブラシ色と描画先の既存色を、色相環を回るように知覚色空間で混ぜる。単純なRGB値の直線平均は使用しない。
- 色相補間：OKLCH、または同等の知覚色空間を使用し、色相角を360度周期として最短方向へ循環補間する。色相環の中心を直線的に横切ることで中間色が灰色へ寄る方式は禁止。
- 色の見え方：黄＋青は緑、赤＋黄は橙、シアン＋マゼンタは青〜紫方向へ移るなど、色相環上を自然に移動する。混色しただけで彩度が一律に大きく落ちる挙動を避ける。色の組み合わせに応じた自然な彩度・明度の変化は許容する。
- 明度・彩度：混色率に応じて連続的に変化させる。色域外の色はRGB値を単純に強制クリップせず、色相・明度を可能な限り保つ色域マッピングを行う。
- 無彩色：片方がほぼ無彩色の場合は有彩色側の色相を不必要に回転させない。両方が無彩色の場合は色相を計算しない。
- 混色率：0〜100%。0%では混色による変化を最小、100%では設定された混色効果を最大にする。
- 明るさ補正：5段階（とても低い / 低い / 中 / 高い / とても高い）。知覚的混色時のみ表示し、デフォルトは「中」。混色後の明るさを作品に合わせて調整できるようにする。
- にじみ：既存色をストローク方向へ少し引っ張る従来のにじみ表現。知覚的混色とは別モードとして維持する。
- 旧「簡易混色」のようにRGBを直接平均する処理を、知覚的混色の代わりとして実装しない。

### ブラシごとの設定

ブラシ作成・編集画面で混色モードをブラシ単位で設定する。

```
混色：OFF / 知覚的混色 / にじみ
混色率：0〜100%（スライダー）
明るさ補正：とても低い / 低い / 中 / 高い / とても高い
```

### 描画範囲・処理負荷

- ブラシスタンプ周辺の必要なピクセルだけを解析し、キャンバス全体を毎回走査しない。
- 描画先レイヤー以外のピクセルを直接変更しない。既存のレイヤー合成・アルファ処理の仕様と矛盾しない形で混色結果を描画先へ反映する。
- タッチ・ペン入力、筆圧、ブラシ不透明度、混色率、Undo/Redoに一貫して対応する。
- 低スペック端末でも描画の追従性を保つ。必要に応じて局所キャッシュやスタンプ単位の再利用を行うが、色相循環の結果や基本品質を別物にしない。
- 透過部分は不透明色として混ぜず、アルファ値を考慮して処理する。

## 傾き検知

- Android OS標準のペン入力APIで傾き情報を取得
- ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画
- 処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わない

### 品質設定との連携

| 品質 | 傾き検知 |
|------|---------|
| 低品質 | OFF |
| 中品質 | OFF |
| 高品質 | ブラシ変形に反映 |
| カスタム | 個別設定（ON/OFF） |

---

## ブラシ画像からのブラシ作成

- 画像ファイルを読み込んでブラシ形状として登録できる
- 他のお絵描きアプリのブラシ画像を流用可能
- 初期実装に含む

---

## ブラシ保存・ID管理

- カスタムブラシはアプリ内の `Brushes/` フォルダに保存
- ブラシIDは4桁連番で管理（例：Brush0001）
- UUIDは使用しない

|------|------|

## 消しゴム（詳細）

- ブラシ形状をそのまま利用（Gペン消し・エアブラシ消しなども可能）
- サイズ・不透明度・手ぶれ補正はブラシと同じ設定項目を持つ

---

## スポイト

- 長押しでスポイト発動（ジェスチャー設定と連携）
- ブラシ使用中に長押しで一時的にスポイトへ切替・離すとブラシへ戻る

---

## ブラシサイズ・不透明度のUI配置

キャンバス画面のツールバー上（Undo・Redoと同じ列）に配置し、描画エリアを最大限確保する。

```
戻る　　　　　　　　　Undo  Redo
ブラシサイズ  不透明度
```
