# 17\_ブラシ仕様

## 基本方針

- ラスターベース描画のみ（ベクターなし）
- タッチ入力・ペン入力双方を入力ソースとして抽象化しブラシエンジンへ渡す
- 低スペック端末でも快適動作
- アプリ終了後も最後に使用したブラシを記憶・復元する

---

## ブラシ・トーン・スタンプの役割

| 機能     | 色情報             | サイズ変化             | 主用途                   |
| -------- | ------------------ | ---------------------- | ------------------------ |
| ブラシ   | 現在色             | ブラシサイズに連動     | 自由描画                 |
| トーン   | 現在色             | 常に一定サイズでループ | 規則パターン・漫画トーン |
| スタンプ | スタンプ画像が保持 | ブラシサイズに連動     | 色付き素材・装飾         |

---

## ペンツールの構成

ペンボタンを長押し（または上スワイプ）するとタブUIを表示。

```
ブラシタブ  |  トーンタブ  |  スタンプタブ
```

通常タップ：現在選択中のブラシ・トーン・スタンプで描画。

## トーンタブ

### 管理項目

- トーン一覧
- お気に入り
- お気に入りのみ表示（チェックボックス）
- トーン検索
- 自作トーン
- 読み込み
- 書き出し

### トーン仕様

- 現在色で描画（色情報を保持しない）
- ブラシサイズを変更してもトーンパターン自体のサイズは変化しない
- テクスチャは一定サイズでループ表示
- パターン原点・位相・向きはキャンバスの絶対ピクセル座標に固定し、ストローク開始位置や描画回数でずらさない
- 同一トーンを同じ場所へ何度描いても模様の描画位置・空白位置・パターン密度は変化しない（アンチエイリアス部分や不透明度のalpha合成は通常どおり累積してよい）
- 異なるトーン同士はそれぞれ固定パターンとして重ねられ、ディザリングや疑似グラデーション表現に利用できる
- 回転なし・密度なし・散布なし
- 不透明度変更可能
- ドットモード対応
- テクスチャ内の透明部分は透過
- 編集可能なのは名前・テクスチャ画像のみ
- タイルの大きさは模様の繰り返しの間隔の倍数（`toneTileSize`）。並べた継ぎ目で模様が途切れない
- 網点・同心円・波線・和柄・布柄の縁は画素の中の覆う割合で描く（アンチエイリアス）。網点の点はセルの真ん中の円で、インクの量は以前の2値の網点と同じ（「網点 50%」の実際のインクは約35%。名前の割合に合わせるかは所有者の判断を待っている）
- 紙・布の質感（水彩紙・画用紙・キャンバス地）は、左上から照らした凹凸の影に色が乗る濃淡のあるトーン。タイルは96〜128pxで、64pxより繰り返しが目立たない
- 組み込みの画像（`assets/tones`）は名前から作る模様と同じ（`tool/build_builtin_tone_images_test.dart`が作り直す）

## スタンプタブ

### 管理項目

- スタンプ一覧
- お気に入り
- お気に入りのみ表示（チェックボックス）
- スタンプ検索
- 自作スタンプ
- 読み込み
- 書き出し

### スタンプ仕様

- スタンプ画像自体が色情報を保持（現在色は使用しない）
- ブラシサイズに応じてスタンプサイズ変更
- 回転・密度・散布対応
- 不透明度変更可能
- テクスチャ内の透明部分は透過
- 描く大きさに合わせてなめらかに描く：テクスチャより小さく描くときは描く大きさまで面積で平均してから、画素の中心でバイリニアに読む（細い光の筋が点線に切れない）。大きく描くときは描く大きさ（最大512px）のテクスチャを作る（`stampTextureSizeFor`）。組み込みの図形・葉っぱ・草・花びらは描く大きさで形から描き直す（`builtInStampShapes`。画像は形を128pxで描いたもの）
- ピクセルモードのスタンプは一番近いテクセルを写す（ドットがぼけない）

### スタンプ使用時の色アイコン

スタンプ選択中は色アイコンに白縁取りの赤斜線を重ねて表示（🚫）。タップすると「スタンプは色情報を保持しているため色変更できません」のトーストを表示。ブラシ・トーンへ戻ると通常表示へ戻る。

## 自動塗り対象

| ツール   | 自動塗り対象 |
| -------- | ------------ |
| ベタ塗り | ○            |
| トーン   | ○            |
| ブラシ   | ✕            |
| スタンプ | ✕            |

ブラシやスタンプはランダム性や色情報を持つため、自動塗りでは使用しない。自動塗りプリセットでトーンを使う場合はバケツトーンエンジンを使用する。

## フォルダ管理

ブラシ・トーン・スタンプすべてフォルダ管理対応。

- フォルダは1階層のみ（フォルダの中にフォルダは作成不可）
- フォルダ内へ自由に移動可能
- フォルダに入れない素材（ルート配置）も可能

| 操作           | 内容                                         |
| -------------- | -------------------------------------------- |
| 新規作成       | フォルダを追加                               |
| 名前変更       | フォルダ名を変更                             |
| 並び替え       | ドラッグで順序変更                           |
| お気に入り登録 | フォルダごとお気に入りに登録可能             |
| 削除           | 確認ダイアログを表示・中の素材はルートへ戻す |

## お気に入り

- 登録対象：ブラシ・トーン・スタンプ単体 / フォルダ
- ★タブでお気に入りのみ表示
- フォルダをお気に入り登録すると、そのフォルダ内の素材をまとめて表示できる

- 検索対象：名前 / フォルダ名
- 検索中はフォルダ構造に関係なく一致した素材・フォルダを一覧表示

## フェード仕様

線の始点と終点に向かって透けていき、その間はブラシの不透明度のまま描く（所有者の定義、2026-11-27「エアブラシが360度全体に向かって透けていくペンだとしたら、フェードは始点と終点に向かって透けていくがそれ以外は不透明度100%になるペンと考えてください。」）。

- 始点から距離（px）の間は開始値（%）から100%へ、終点までの距離の間は100%から終了値（%）へ、なめらかな曲線で変わる。その間は線の長さで薄れない（線の途中で薄くするのはストローク減衰）。
- 透け方は線に沿ってだけ変わり、太さと線を横切る形は変えない（重なったスタンプで真ん中に濃い筋が立たない）。
- 2つの距離の和より短い線は、和を線の長さに合わせて縮め、2つの変わり方が100%で出会う（開始値・終了値より薄くならない）。
- 筆圧で決まる不透明度にフェードを掛ける。
- 縁取りペンにはフェードは無い（端の形は入り抜きで変える）。
- 終点の変わり方は線の長さで決まるので、ペンを離した後に、終点の距離から届く所だけを描き直して反映する（短い線・縁取りペン・混色は線全体を描き直す）。

| 設定     | 内容                                                        |
| -------- | ----------------------------------------------------------- |
| OFF      | フェードなし                                                |
| 弱       | 開始値・終了値50%、距離40px                                 |
| 中       | 開始値・終了値20%、距離80px                                 |
| 強       | 開始値・終了値0%、距離150px                                 |
| カスタム | 入り（始点）と抜き（終点）の値（%）と距離（px）を別々に設定 |

## 入り抜き仕様

線の始点と終点に向かって太さを細くし、その間はブラシの太さのまま描く。色・不透明度は変えない（フェードとは別の設定。以前はカスタムのフェードが端の太さも細くしていたので、その働きを入り抜きとして残した。所有者の方針「今できる機能を削る行為でなければ、いくらでもブラッシュアップしてよい」、2026-11-27）。

- 始点から距離（px）の間は入りの値（%、端での太さ）から100%へ、終点までの距離の間は100%から抜きの値へ、フェードと同じなめらかな曲線で変わる。
- 2つの距離の和より短い線は、和を線の長さに合わせて縮め、100%で出会う（縁取りペンでは縮めない）。
- 筆圧で決まる太さに入り抜きを掛ける。マウス（筆圧なし）でも細い入り・抜きを描ける。
- 縁取りペンでは、縁取りを含む全体の形が細くなり、縁取り線の太さと透明度は変えない。
- 弱・中・強はフェードと同じ値（弱：50%・40px、中：20%・80px、強：0%・150px）、カスタムは入り・抜きの値と距離を別々に設定。
- 以前の版で保存したブラシは読むときに移す：縁取りの無いブラシのカスタムのフェード→同じ値の入り抜き（フェードは切る）、縁取りペンのフェード→入り抜き。縁取りの無いブラシの弱・中・強はフェードのまま。

## 紙の目（紙目・粒子）

乾いた画材（鉛筆・木炭・パステル・チョーク・ガッシュ）が紙の凹凸に引っかかる表現。

- 紙の凹凸はキャンバスに固定した256px四方の繰り返し模様（`lib/engine/paper_tooth.dart`、数pxの凸がかたまる形。大きさの違う3つのぼかしたノイズと短い繊維を重ね、高さを0〜255に均等に割り振る）。同じ場所には何度描いても同じ凹凸が出る。
- 画材は凸に乗り、乗った所は選んだ色のまま（全体を薄くしない）。強く押すと凹みにも入り、凹みは少し薄いだけの細かな質感になる。軽い筆圧と線の縁では凹みが紙のまま残る。紙目・粒子が強いほど凹みが多い（筆圧が無いとき・マウスは強く押したのと同じ）。
- ふち滲み（縁のぶれ）も同じ凹凸に沿って縁を内外へ動かす（以前は乱数で、同じ線を描き直すたびに縁が変わり、重なったスタンプで縁がぼやけて太った）。細いペン先では動く幅を半径の4割ほどまでにして、細い線が途切れないようにする。

## 毛のすじ・かすれ

油彩の平筆・丸筆・乾いた筆・ナイフの跡（所有者の依頼、2026-11-27「テクスチャや仕組みのクオリティアップ」）。`lib/engine/bristle_marks.dart`。

- 画素ごとに、線を横切る位置（どの毛が通ったか）と線に沿った位置（筆がどこまで進んだか）で決める。重なったスタンプがどれも同じ値を出すので、跡は線に沿って走り、スタンプの弧が出ない。同じ線は何度描いても同じ跡になる（線の始めの位置で筆の状態を決める）。
- 毛のすじ：毛（約1.5px間隔）と毛の束（幅の約1割）が線に沿ってしばらく細くなっては戻るので、すじの長さ・太さはそろわない。手の揺れで少し波打つ。ほとんどの毛は選んだ色のまま、細い毛はわずかに薄く、ときどき毛が抜けて下の色が見える。縁は細い繊維にほつれ、筆が広がる外側ほど束が割れる。強いほどすじが多い。
- かすれ：筆は絵の具を含んだ状態で始まり、線を進むほど乾いて、かすれの強さまで乾く（それ以上は乾かない＝長い線でも消えない）。軽い筆圧ほど乾き、外側の毛から長い繊維になって切れ、終わりは毛1本ずつの細い跡になる。真ん中は最後まで残る。
- 毛のすじが0でかすれがあるブラシはナイフ：強く押すと平らで縁のくっきりした絵の具（点状の抜けは無い）、軽く押すと（または絵の具を置き切ると）線の向きの細いすじで薄く削れて下の色が見える。
- 押しただけ（タップ）は真ん中が詰まり、毛のすじは少しだけ、縁に繊維が出る。
- どちらも線の向きが要るので、最初のスタンプを線の向きが分かってから置く。入力の点の間では、向きを前の区間からなめらかに回す（刃や平筆の跡が点ごとに折れない）。ピクセルモード・縁取りペン・消しゴムには掛けない。
- 組み込み：平筆（毛のすじ55・かすれ40）、油彩筆（60・25）、かすれ筆（70・75）、ペインティングナイフ（0・35）、ガッシュ（25・20）。

## 混色仕様

混色はブラシ単位で設定する。パフォーマンス品質設定とは独立させ、すべての品質で使用可能とする。

- モード（ブラシカスタムのラジオボタン）：デジタル / 油彩風混色 / 水彩風混色（ユーザー指定の名称。「油彩」「水彩」と言い切ると本物の画材の再現と誤認されるため「〜風」）。旧「にじみ」は廃止し、保存済みの「にじみ」は水彩風混色、「アナログ風」（旧「簡易混色」を含む）は油彩風混色として読み込む。
- デジタル：混ぜずにそのまま塗る。
- 油彩風混色：下の色と絵の具のように混ざる。色相は画家の色相環（赤・橙・黄・緑・青・紫のRYB）の短い方を回り、赤＋青＝紫、青＋黄＝緑、赤＋黄＝橙になる（どの赤・青・黄でも。暖色寄りの赤＋青が茶色になる物理的な顔料計算ではなく、常識的な混色。ユーザー指定）。補色どうし（赤と緑、青と橙、黄と紫）は絵の具と同じく落ち着いた中間色になる。彩度は2色の直線補間を保ち、明度はKubelka–Munk分光混色（spectral.js 3.0.0の分光データ、MIT License）と直線補間の中間で、明るい方の色より明るくならない（デジタルの色相環補間のように途中で急に明るくならない）。混色度合いは2色を結ぶ経路のOKLabでの長さの割合で測る。スタンプごとに筆の下の絵の具を拾って筆の色に混ぜ、色延びの距離だけ引きずる（新しい絵の具が戻って選択色へ近づく）。
- 水彩風混色：透明な絵の具を重ねる。描いている間は同じストロークの中で重ならない1回のウォッシュで、紙の目と顔料のむら（どちらもキャンバスに固定された模様）が出る。むらは広くかすかな濃淡で、斑点のようなまだらにはしない（むらを既定より上げたときだけ斑が強くなる）。ペンを離すと乾き、縁は紙の目と水の届き方で決まる：水が少なければ紙の目に沿ってくっきり、水分量・にじみ・境界のぼかしが大きいほど筆の外へ不揃いに広がり、筆の跡の内外にわたって柔らかくにじむ（エアブラシのような均一なぼかしにはしない。所有者の指定、2026-11-27）。組み込みの水彩ブラシはぼかし・縁のぶれを使わない。乾いた縁に色が溜まる表現はブラシではなく描画フィルター「水彩境界」で付ける（ユーザー指定。描いた後に調整できるように）。下の絵の具の上では色相環どおりに混ざって（黄の上に青＝緑）透明な一層ぶん深くなる。同じ色を重ねたとき、不透明度100%なら濃くならずに同じ色の範囲が広がり（複数のストロークでベタ塗りしても塗りムラにならない。ユーザー指定）、不透明度を下げているときは重ねた分だけ深くなる。違う色は100%どうしでも混ざる。混色度合いが高いほど濡れた色どうしが溶け合い、深くならない。乾かす処理はペンを離した時点（Undoの記録が閉じる前）に行い、1回のUndoで戻る。
- 半透明の既存色（筆跡の縁など）は、不透明度に応じて混ざる量が減る。
- 混色度合い：0〜100（筆圧ON時は弱・強）。
- 油彩風混色のみ：色延び 0〜100（初期値30。拾った色を最大でブラシ幅の6倍まで運ぶ。0なら拾わない）、輝度補正 1〜5（初期値3。3は補正なし、1〜2は暗め、4〜5は明るめ。混色の中間ほど強く、端点の色は変えない）。
- 水彩風混色のみ：水分量（初期値50。多いほど薄く、むらが出て、少し広がる）、絵具量（初期値60。多いほど濃い）、にじみ（初期値50。乾くときに筆の外へどこまで、どれだけ不揃いに広がるか）、いずれも0〜100。
- ブラシスタンプ周辺の局所ピクセルのみを解析し、キャンバス全体を毎回走査しない（水彩風混色の乾かす処理は、そのストロークの範囲だけ）。筆圧、不透明度、Undo/Redoと整合させる。

### ブラシごとの設定

```
混色：デジタル / 油彩風混色 / 水彩風混色
混色度合い：0〜100%
油彩風混色：色延び0〜100（初期値30）、輝度補正1〜5（初期値3）
水彩風混色：水分量・絵具量・にじみ 0〜100（初期値50・60・50）
```

## 傾き検知

- Android OS標準のペン入力APIで傾き情報を取得
- ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画
- 処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わない

### 品質設定との連携

| 品質     | 傾き検知           |
| -------- | ------------------ |
| 低品質   | OFF                |
| 中品質   | OFF                |
| 高品質   | ブラシ変形に反映   |
| カスタム | 個別設定（ON/OFF） |

## ブラシ保存・ID管理

- カスタムブラシはアプリ内の `Brushes/` フォルダに保存
- ブラシIDは4桁連番で管理（例：Brush0001）
- UUIDは使用しない
- 組み込みから外したブラシのID（スプレー Brush0013、所有者の判断 2026-11-27）は使い回さない。前の版の保存・引き継ぎに残っていても、読み込むときに一覧・使っているブラシ（隣のブラシへ移る）・早替えツール・ショートカット・覚えた太さ／不透明度から外す。利用者が作った複製は残す。
