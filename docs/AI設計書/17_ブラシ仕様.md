# 17_ブラシ仕様

## 基本方針

- ラスターベース描画のみ（ベクターなし）
- タッチ入力・ペン入力双方を入力ソースとして抽象化しブラシエンジンへ渡す
- 低スペック端末でも快適動作
- アプリ終了後も最後に使用したブラシを記憶・復元する

---

## 初期実装ブラシ

| ブラシ | 特徴 |
|--------|------|
| ペン | 標準的な描画ブラシ |
| Gペン | 入り抜きのある漫画向けブラシ |
| エアブラシ | ふんわりとしたグラデーション描画 |
| 混色ブラシ | 簡易混色を使った色混ぜブラシ |

ドットペンは独立したブラシ種別ではなく、ブラシ設定のドットペンモード（チェックボックス）で切替する。

---

## ブラシ設定項目

| 項目 | 内容 |
|------|------|
| サイズ | 1〜500px・スライダー |
| 不透明度 | 1〜100%・スライダー |
| 間隔 | スタンプ間隔を調整・スライダー |
| ぼかし半径 | 0〜100・スライダー・デフォルト0 |
| 手ぶれ補正 | ON/OFF・強度調整 |
| ドットペンモード | チェックボックスでON/OFF（ON時：アンチエイリアス完全OFF・ピクセル単位描画） |
| 筆圧反映 | OFF / サイズ / 不透明度 / サイズ＋不透明度（ブラシ個別設定） |
| 筆圧反映度 | 0〜100%・スライダー（ブラシ個別設定） |
| フェード | OFF / 弱 / 中 / 強 / カスタム |
| ストローク減衰 | ON/OFF |
| 混色 | OFF / 簡易混色 |
| 混色率 | 0〜100%・スライダー |

筆圧カーブ（弱 / 普通 / 強 / カスタム）はアプリ全体の設定画面で管理する。ブラシ個別の筆圧反映・反映度とは別物。

---

## フェード仕様

ストロークが進むにつれて不透明度・サイズが減少する。

| 設定 | 内容 |
|------|------|
| OFF | フェードなし |
| 弱 / 中 / 強 | プリセット |
| カスタム | 開始値（%）/ 終了値（%）/ 距離（px）を個別設定 |

---

## ストローク減衰仕様

- 筆圧ではなく、描き続けるほどインクが減るような表現
- ストローク後半で自然に薄くなる（インク切れ表現）

---

## 混色仕様

- モードはOFF / 簡易混色の2択
- 簡易混色：ブラシ直下の現在色と選択色を混色率に応じて混ぜる（軽量・ブラシ直下のみ解析）
- にじみは簡易混色の一形態として混色率で表現する
- 本格混色（周囲ピクセル解析）は将来追加候補

### 品質設定との連携

| 品質 | 混色 |
|------|------|
| 低品質 | 簡易混色のみ |
| 中品質以上 | 簡易混色 |
| 将来 | 本格混色追加時に高品質で自動有効 |

---

## 傾き検知

- Android OS標準のペン入力APIで傾き情報を取得
- ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画
- 処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わない

### 品質設定との連携

| 品質 | 傾き検知 |
|------|---------|
| 低品質 | OFF |
| 中品質 | OFF |
| 高品質 | ブラシ変形に反映 |
| カスタム | 個別設定（ON/OFF） |

---

## ブラシ画像からのブラシ作成

- 画像ファイルを読み込んでブラシ形状として登録できる
- 他のお絵描きアプリのブラシ画像を流用可能
- 初期実装に含む

---

## ブラシ保存・ID管理

- カスタムブラシはアプリ内の `Brushes/` フォルダに保存
- ブラシIDは4桁連番で管理（例：Brush0001）
- UUIDは使用しない

---

## ブラシ一覧UI

```
★ お気に入り    🔍 検索

────────────────────────

📁 線画
  ・Gペン
  ・丸ペン

📁 水彩
  ・エアブラシ
  ・混色ブラシ

📁 自作
  ・ブラシA

────────────────────────

```

- ブラシ一覧はポップアップで表示（常時表示ではない）
- ブラシ変更時は現在色・現在サイズでプレビューを表示

---

## ブラシフォルダ

- フォルダは1階層のみ（フォルダの中にフォルダは作成不可）
- ブラシはフォルダ内へ自由に移動可能
- フォルダに入れないブラシ（ルート配置）も可能

| 操作 | 内容 |
|------|------|
| 新規作成 | フォルダを追加 |
| 名前変更 | フォルダ名を変更 |
| 並び替え | ドラッグで順序変更（カテゴリ内のみ・カテゴリ跨ぎ不可） |
| お気に入り登録 | フォルダごとお気に入りに登録可能 |
| 削除 | 確認ダイアログを表示・中のブラシはルートへ戻す |

---

## お気に入り

- 登録対象：ブラシ単体 / ブラシフォルダ
- ★タブでお気に入りのブラシ・フォルダのみ表示
- フォルダをお気に入り登録すると、そのフォルダ内のブラシをまとめて表示できる

---

## 検索

- 🔍タップで検索バーが展開される
- 検索対象：ブラシ名 / フォルダ名
- 検索中はフォルダ構造に関係なく一致したブラシ・フォルダを一覧表示

---

## ブラシ管理操作

| 操作 | 内容 |
|------|------|
| 並び替え | ドラッグで順序変更（フォルダ内のみ） |
| 編集 | 設定項目を変更 |
| 複製 | ブラシをコピーして追加 |
| 削除 | ブラシを削除 |
| 保存 | カスタムブラシとして保存 |

---

## 消しゴム

- ブラシ形状をそのまま利用（Gペン消し・エアブラシ消しなども可能）
- サイズ・不透明度・手ぶれ補正はブラシと同じ設定項目を持つ

---

## スポイト

- 長押しでスポイト発動（ジェスチャー設定と連携）
- ブラシ使用中に長押しで一時的にスポイトへ切替・離すとブラシへ戻る

---

## ブラシサイズ・不透明度のUI配置

キャンバス画面のツールバー上（Undo・Redoと同じ列）に配置し、描画エリアを最大限確保する。

```
戻る　　　　　　　　　Undo  Redo
ブラシサイズ  不透明度
```
