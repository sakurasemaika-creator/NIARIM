# 17\_ブラシ仕様

## 基本方針

- ラスターベース描画のみ（ベクターなし）
- タッチ入力・ペン入力双方を入力ソースとして抽象化しブラシエンジンへ渡す
- 低スペック端末でも快適動作
- アプリ終了後も最後に使用したブラシを記憶・復元する

---

## ブラシ・トーン・スタンプの役割

| 機能     | 色情報             | サイズ変化             | 主用途                   |
| -------- | ------------------ | ---------------------- | ------------------------ |
| ブラシ   | 現在色             | ブラシサイズに連動     | 自由描画                 |
| トーン   | 現在色             | 常に一定サイズでループ | 規則パターン・漫画トーン |
| スタンプ | スタンプ画像が保持 | ブラシサイズに連動     | 色付き素材・装飾         |

---

## ペンツールの構成

ペンボタンを長押し（または上スワイプ）するとタブUIを表示。

```
ブラシタブ  |  トーンタブ  |  スタンプタブ
```

通常タップ：現在選択中のブラシ・トーン・スタンプで描画。

---

## ブラシタブ

### 管理項目

- ブラシ一覧
- お気に入り
- お気に入りのみ表示（チェックボックス）
- ブラシ検索
- 自作ブラシ
- 読み込み
- 書き出し

### ブラシ設定項目

| 項目             | 内容                                                                        |
| ---------------- | --------------------------------------------------------------------------- |
| サイズ           | 1〜500px・スライダー                                                        |
| 不透明度         | 1〜100%・スライダー                                                         |
| 間隔             | スタンプ間隔を調整・スライダー                                              |
| ぼかし半径       | 0〜100・スライダー・デフォルト0                                             |
| 手ぶれ補正       | ON/OFF・強度調整                                                            |
| ドットペンモード | チェックボックスでON/OFF（ON時：アンチエイリアス完全OFF・ピクセル単位描画） |
| 筆圧反映         | OFF / サイズ / 不透明度 / サイズ＋不透明度（ブラシ個別設定）                |
| 筆圧反映度       | 0〜100%・スライダー（ブラシ個別設定）                                       |
| フェード         | OFF / 弱 / 中 / 強 / カスタム                                               |
| ストローク減衰   | ON/OFF                                                                      |
| 混色             | デジタル / 油彩風混色 / 水彩風混色                                          |
| 混色度合い       | 0〜100%・スライダー                                                         |
| 色延び・輝度補正 | 油彩風混色のみ（色延び0〜100・初期値30、輝度補正1〜5・初期値3）             |
| 水分量ほか       | 水彩風混色のみ（水分量・絵具量・縁の濃さ、0〜100）                          |
| 回転             | ON/OFF                                                                      |
| 密度             | スライダー                                                                  |
| 散布             | スライダー                                                                  |

筆圧カーブ（弱 / 普通 / 強 / カスタム）はアプリ全体の設定画面で管理する。

---

## トーンタブ

### 管理項目

- トーン一覧
- お気に入り
- お気に入りのみ表示（チェックボックス）
- トーン検索
- 自作トーン
- 読み込み
- 書き出し

### トーン仕様

- 現在色で描画（色情報を保持しない）
- ブラシサイズを変更してもトーンパターン自体のサイズは変化しない
- テクスチャは一定サイズでループ表示
- パターン原点・位相・向きはキャンバスの絶対ピクセル座標に固定し、ストローク開始位置や描画回数でずらさない
- 同一トーンを同じ場所へ何度描いても模様の描画位置・空白位置・パターン密度は変化しない（アンチエイリアス部分や不透明度のalpha合成は通常どおり累積してよい）
- 異なるトーン同士はそれぞれ固定パターンとして重ねられ、ディザリングや疑似グラデーション表現に利用できる
- 回転なし・密度なし・散布なし
- 不透明度変更可能
- ドットモード対応
- テクスチャ内の透明部分は透過
- 編集可能なのは名前・テクスチャ画像のみ

---

## スタンプタブ

### 管理項目

- スタンプ一覧
- お気に入り
- お気に入りのみ表示（チェックボックス）
- スタンプ検索
- 自作スタンプ
- 読み込み
- 書き出し

### スタンプ仕様

- スタンプ画像自体が色情報を保持（現在色は使用しない）
- ブラシサイズに応じてスタンプサイズ変更
- 回転・密度・散布対応
- 不透明度変更可能
- テクスチャ内の透明部分は透過

### スタンプ使用時の色アイコン

スタンプ選択中は色アイコンに白縁取りの赤斜線を重ねて表示（🚫）。タップすると「スタンプは色情報を保持しているため色変更できません」のトーストを表示。ブラシ・トーンへ戻ると通常表示へ戻る。

---

## 消しゴム

消しゴムを長押し（または上スワイプ）すると切替。

- ブラシ消しゴム：通常消しゴム
- トーン消しゴム：トーン形状そのままで透明色を描画

スタンプは消しゴムに表示しない。

---

## バケツ

バケツを長押し（または上スワイプ）すると切替。

- ベタ塗り：通常バケツ
- トーン塗り：トーンをループ配置して塗る

---

## 自動塗り対象

| ツール   | 自動塗り対象 |
| -------- | ------------ |
| ベタ塗り | ○            |
| トーン   | ○            |
| ブラシ   | ✕            |
| スタンプ | ✕            |

ブラシやスタンプはランダム性や色情報を持つため、自動塗りでは使用しない。自動塗りプリセットでトーンを使う場合はバケツトーンエンジンを使用する。

---

## フォルダ管理

ブラシ・トーン・スタンプすべてフォルダ管理対応。

- フォルダは1階層のみ（フォルダの中にフォルダは作成不可）
- フォルダ内へ自由に移動可能
- フォルダに入れない素材（ルート配置）も可能

| 操作           | 内容                                         |
| -------------- | -------------------------------------------- |
| 新規作成       | フォルダを追加                               |
| 名前変更       | フォルダ名を変更                             |
| 並び替え       | ドラッグで順序変更                           |
| お気に入り登録 | フォルダごとお気に入りに登録可能             |
| 削除           | 確認ダイアログを表示・中の素材はルートへ戻す |

---

## お気に入り

- 登録対象：ブラシ・トーン・スタンプ単体 / フォルダ
- ★タブでお気に入りのみ表示
- フォルダをお気に入り登録すると、そのフォルダ内の素材をまとめて表示できる

---

## 検索

- 🔍タップで検索バーが展開される
- 検索対象：名前 / フォルダ名
- 検索中はフォルダ構造に関係なく一致した素材・フォルダを一覧表示

---

## フェード仕様

ストロークが進むにつれて不透明度・サイズが減少する。

| 設定         | 内容                                           |
| ------------ | ---------------------------------------------- |
| OFF          | フェードなし                                   |
| 弱 / 中 / 強 | プリセット                                     |
| カスタム     | 開始値（%）/ 終了値（%）/ 距離（px）を個別設定 |

---

## ストローク減衰仕様

- 筆圧ではなく、描き続けるほどインクが減るような表現
- ストローク後半で自然に薄くなる（インク切れ表現）

---

## 混色仕様

混色はブラシ単位で設定する。パフォーマンス品質設定とは独立させ、すべての品質で使用可能とする。

- モード（ブラシカスタムのラジオボタン）：デジタル / 油彩風混色 / 水彩風混色（ユーザー指定の名称。「油彩」「水彩」と言い切ると本物の画材の再現と誤認されるため「〜風」）。旧「にじみ」は廃止し、保存済みの「にじみ」は水彩風混色、「アナログ風」（旧「簡易混色」を含む）は油彩風混色として読み込む。
- デジタル：混ぜずにそのまま塗る。
- 油彩風混色：下の色と絵の具のように混ざる。色相は画家の色相環（赤・橙・黄・緑・青・紫のRYB）の短い方を回り、赤＋青＝紫、青＋黄＝緑、赤＋黄＝橙になる（どの赤・青・黄でも。暖色寄りの赤＋青が茶色になる物理的な顔料計算ではなく、常識的な混色。ユーザー指定）。補色どうし（赤と緑、青と橙、黄と紫）は絵の具と同じく落ち着いた中間色になる。彩度は2色の直線補間を保ち、明度はKubelka–Munk分光混色（spectral.js 3.0.0の分光データ、MIT License）と直線補間の中間で、明るい方の色より明るくならない（デジタルの色相環補間のように途中で急に明るくならない）。混色度合いは2色を結ぶ経路のOKLabでの長さの割合で測る。スタンプごとに筆の下の絵の具を拾って筆の色に混ぜ、色延びの距離だけ引きずる（新しい絵の具が戻って選択色へ近づく）。
- 水彩風混色：透明な絵の具を重ねる。描いている間は同じストロークの中で重ならない1回のウォッシュで、紙の目と顔料のむらが出る。ペンを離すと乾き、水分量に応じて筆より少し外へ不規則ににじみ、濡れた縁の内側に色が溜まる（縁の濃さ）。下の絵の具の上では色相環どおりに混ざって（黄の上に青＝緑）透明な一層ぶん深くなり、同じ色を重ねるほど深くなる。混色度合いが高いほど濡れた色どうしが溶け合い、深くならない。乾かす処理はペンを離した時点（Undoの記録が閉じる前）に行い、1回のUndoで戻る。
- 半透明の既存色（筆跡の縁など）は、不透明度に応じて混ざる量が減る。
- 混色度合い：0〜100（筆圧ON時は弱・強）。
- 油彩風混色のみ：色延び 0〜100（初期値30。拾った色を最大でブラシ幅の6倍まで運ぶ。0なら拾わない）、輝度補正 1〜5（初期値3。3は補正なし、1〜2は暗め、4〜5は明るめ。混色の中間ほど強く、端点の色は変えない）。
- 水彩風混色のみ：水分量（初期値50。多いほど薄く、にじみが広く、むらが出る）、絵具量（初期値60。多いほど濃い）、縁の濃さ（初期値50）、いずれも0〜100。
- ブラシスタンプ周辺の局所ピクセルのみを解析し、キャンバス全体を毎回走査しない（水彩風混色の乾かす処理は、そのストロークの範囲だけ）。筆圧、不透明度、Undo/Redoと整合させる。

### ブラシごとの設定

```
混色：デジタル / 油彩風混色 / 水彩風混色
混色度合い：0〜100%
油彩風混色：色延び0〜100（初期値30）、輝度補正1〜5（初期値3）
水彩風混色：水分量・絵具量・縁の濃さ 0〜100（初期値50・60・50）
```

## 傾き検知

- Android OS標準のペン入力APIで傾き情報を取得
- ペンを寝かせた方向にブラシ形状を引き伸ばし、ペン先側を濃く・手前側を薄く描画
- 処理方式：ブラシスタンプ生成時に変形するだけで毎ピクセル計算は行わない

### 品質設定との連携

| 品質     | 傾き検知           |
| -------- | ------------------ |
| 低品質   | OFF                |
| 中品質   | OFF                |
| 高品質   | ブラシ変形に反映   |
| カスタム | 個別設定（ON/OFF） |

---

## ブラシ画像からのブラシ作成

- 画像ファイルを読み込んでブラシ形状として登録できる
- 他のお絵描きアプリのブラシ画像を流用可能
- 初期実装に含む

---

## ブラシ保存・ID管理

- カスタムブラシはアプリ内の `Brushes/` フォルダに保存
- ブラシIDは4桁連番で管理（例：Brush0001）
- UUIDは使用しない

## ブラシ管理操作

| -------- | ------------------------------------ |
| 並び替え | ドラッグで順序変更（フォルダ内のみ） |

## 消しゴム（詳細）

- ブラシ形状をそのまま利用（Gペン消し・エアブラシ消しなども可能）
- サイズ・不透明度・手ぶれ補正はブラシと同じ設定項目を持つ

---

## スポイト

- 長押しでスポイト発動（ジェスチャー設定と連携）
- ブラシ使用中に長押しで一時的にスポイトへ切替・離すとブラシへ戻る

---

## ブラシサイズ・不透明度のUI配置

キャンバス画面のツールバー上（Undo・Redoと同じ列）に配置し、描画エリアを最大限確保する。

```
戻る　　　　　　　　　Undo  Redo
ブラシサイズ  不透明度
```
