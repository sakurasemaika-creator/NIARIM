# 27\_キャンバス表示仕様

## 描画領域と描画領域外の区別

キャンバスは描画領域と描画領域外を明確に区別して表示する。

---

## 倍率OFF（drawingAreaScale == 1.0）

描画領域 = 書き出し領域となる。

### 表示

| 領域                     | 表示                              |
| ------------------------ | --------------------------------- |
| 描画領域（書き出し領域） | 白 または 透過（市松模様）        |
| 描画領域外               | 暗いグレー（`#3A3A3A`）・描画不可 |

```
■■■■■■■■■■■■■■
■■□□□□□□□□■■
■■□□□□□□□□■■
■■□□□□□□□□■■
■■■■■■■■■■■■■■

■ = 暗いグレー（描画不可）
□ = 描画領域（白 or 市松模様）
```

---

## 倍率ON（drawingAreaScale > 1.0）

描画領域は設定倍率に応じて拡張される。

### 表示

| 領域         | 表示                       |
| ------------ | -------------------------- |
| 描画領域全体 | 白 または 透過（市松模様） |
| 書き出し範囲 | 赤枠で表示（中央配置）     |

```
□□□□□□□□□□□□□□□□□□□□

□□□□┌──────┐□□□□
□□□□│      │□□□□
□□□□│      │□□□□
□□□□└──────┘□□□□

□□□□□□□□□□□□□□□□□□□□

□ = 描画可能領域（白 or 市松模様）
赤枠 = 書き出し範囲
```

- 赤枠外も通常どおり描画できる
- 赤枠内のみが動画として書き出される

---

## キャンバスのパン・ズーム・回転

キャンバスモードでは、描画領域をパン・ピンチズーム・2本指回転できる。

- 縮小下限は等倍の **1/5（0.2倍）** とする。
- 回転角度は180度等の固定角だけに限定せず、30度・45度・60度など任意の斜め角度を連続的に扱う。
- `drawingAreaScale == 1.0` の通常モードでは、回転するのは描画領域（キャンバス）であり、その背後にある暗いグレーの描画不可領域は画面側に固定する。
- `drawingAreaScale > 1.0` の拡張描画モードでは、拡張された赤枠外の領域も「背景」ではなく正式な描画可能領域であるため、赤枠内の書き出し領域と同じ座標系・同じTransformでパン・ズーム・回転する。拡張描画領域だけを画面固定してはならない。
- 拡張描画領域のさらに外側にある暗いグレー部分は描画不可の安全背景であり、キャンバスのTransformには含めない。
- パンは描画領域の境界で制限する。大きなドラッグ、斜め回転中のドラッグ、最小0.2倍でのドラッグでも境界を突き抜けてはならない。
- 最小0.2倍かつ30度・45度・60度等の斜め回転状態でも、描画不可背景のさらに外側（透明、黒、別色、未描画面等）が画面内へ露出してはならない。
- UI（トップバー、ツールバー、各種パネル等）はキャンバスTransformに含めず、画面へ固定する。

### 回転時の二層構造

```
画面固定：UI + 描画不可の安全背景
             ↓
       ┌───────────────┐
       │   ／ 描画領域 ／   │ ← パン・ズーム・回転
       │ ／（拡張ON時は赤枠外も含む）│
       └───────────────┘
```

拡張ON時の赤枠外を「背面背景」と呼ぶ場合でも、実装上は描画可能キャンバスの一部として扱うこと。画面固定の安全背景と混同しない。

### 必須の実操作監査

この項目は数式テストや `flutter test` が緑であることだけで完了判定してはならない。`test/canvas_angle_boundary_visual_audit_test.dart` を本物の `CanvasArea` に対して実行し、PNGをすべて実際に目視すること。

最低限、次の **16パターン**を独立状態から確認する。

- 通常描画範囲 (`drawingAreaScale == 1.0`)：`+30° / +45° / +60° / +90° / -30° / -45° / -60° / -90°`
- 拡張描画範囲 (`drawingAreaScale > 1.0`)：同じ8角度
- 各ケースで `0.2倍まで縮小 → 指定角度へ回転 → 描画領域端へ極端にドラッグ → PNG保存` を行う。
- PNGでは、キャンバスの角度が実際に斜めになっていること、通常時の安全背景が固定されていること、拡張時の赤枠外描画領域がキャンバスと一緒に回転していること、背景のさらに外側が露出していないことを確認する。
- 複数PNGが意図せず同一画像になっていないことも確認する。疑似入力が相殺されて回転していない画像は証拠として採用しない。
- この16枚を確認できていない状態では、本項目を「最終完了」と記録しない。

## 描画可能範囲

描画可能範囲は描画領域全体とする。赤枠外でも以下はすべて通常どおり利用できる。

- ペン
- 消しゴム
- 塗りつぶし
- 画像配置
- 動画素材
- テキスト
- ウォーターマーク

---

## 背景表示設定

背景表示は表示用のみであり、書き出し結果には影響しない。

| 設定値                         | 表示                                                        |
| ------------------------------ | ----------------------------------------------------------- |
| `CanvasBackground.white`       | 白背景                                                      |
| `CanvasBackground.transparent` | 市松模様（セルサイズ 16px、明色 `#F2F2F2`・暗色 `#A7A7A7`） |

- 切替ボタンはキャンバス画面トップバーに配置する
- この設定はキャンバス表示のみに反映される
