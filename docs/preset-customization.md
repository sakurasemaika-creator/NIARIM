# プリセットとユーザーカスタムの共通仕様

プリセットは公開された設定値と素材の組み合わせです。同じ設定・素材の
ユーザーカスタムは、同じ描画処理を使用します。ブラシやフィルターのID・名前・
画像ファイル名によって描画アルゴリズムを切り替えません。

新しいプリセットに既存の設定で表現できない機能が必要な場合は、共通モデルと
カスタム画面に機能を追加します。保存・複製・読み込み・書き出し・記録した操作の
再実行でも、その設定を保持します。

## 共通のブラシ設定

- ペン先：円形、中空の四角、六角形、チェーンの輪、ボールチェーン。
- 間隔：従来のpx指定、またはブラシの太さに対する比率。
- チェーン：縦横比、輪の太さ。
- 扁平なペン先：有効／無効と角度。
- 画像素材：複数追加、並べ替え、削除。登録順またはランダムでストロークごとに選択。
- 画像の描画部分：暗い部分、明るい部分、不透明な部分。保存場所によらず同じ解釈。
- 縁取りと5種類の折りたたみ：プリセットとカスタムで同じ描画経路を使用。

髪の毛の標準プリセットは抜き0％、前髪の標準プリセットは従来の設定を使用します。
これは通常の入り抜き設定であり、プリセット専用の毛先処理ではありません。

## 三日月カール

描いた中心線を移動したり、波・渦巻きを自動生成したりしません。描き始めは通常の
縁取りで、入力が実際に曲がったときに輪郭を処理します。連続した同方向のカーブは
実際の接線の半回転を基準につなぎ、270°ごとの検出イベントで過去の形状を
作り直しません。続きのカーブは実際の曲がりに応じて成長し、丸い蓋を挿入しません。

## 共通のフィルター設定

ノイズはフィルム粒子・カラーノイズ・VHSを選択できます。シード値も共通設定で、
同じ設定なら複製後も同じ結果になります。プレビュー・本適用・記録再生は共通の
ノイズ処理を使用します。プリズムもFilterKindで指定し、IDに依存しません。

旧データに設定が存在しない場合だけ、読み込み時に互換移行します。移行後は明示的な
共通設定として保存し、ユーザーが変更した値を優先します。

## 確認方法

`brush_custom_reproduction_test.dart`と`filter_custom_reproduction_test.dart`で、
別IDへの複製と素材の保存場所の変更によって出力が変わらないことを確認します。
入り抜き・カールの接続・画面・使用例は本番DrawingEngineのPNGも開いて確認します。
自動テストの成功だけで視覚品質の完了判定をしません。
