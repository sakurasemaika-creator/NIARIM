# NIARIM ミッション報酬増額・交換コイン端数切り上げ（2026-11-10）

リリース前の `dev_branch` 向け仕様。旧ミッション達成者向け互換コードは不要。
**10コインはリワード広告1回の報酬であり、ミッション単発報酬の上限ではない。**

## 単調増加

- 制作時間15件: 1時間2コイン → 100時間7 → 250時間9 → 1,000時間14 → 100,000時間48。
- フォロワー12件: 10人2 → 100人4 → 500人6 → 10,000人11 → 100万人32。
- 作品公開・ブックマーク24件: 投稿2 → 10件3 → 20件4 → … → 1,000件26。
- ランキング4件: 50位以内2、10位以内3、3位以内5、1位7が基準。公開作品数に応じ2倍/3倍/4倍/5倍で最大35コイン。上限10を撤廃。
- 作品数×ブックマーク480件: 作品段階indexをi、ブックマーク段階indexをjとしたとき、報酬は `2 + i + j`。最低2～最高44、**どちらの軸が1段階でも上がれば必ず+1**。過去用のLEGACY_GRID_BITSは削除。
- 広場閲覧: 毎日 1→2→3→4、毎週5→7→10、毎月13→17→23。
- 定期ログイン: 毎週2→3→4、毎月5→7→10。
- 累計ログイン54節目: 5日5 → 50日14 → 100日19 → 150日40 → 500日54 → 600日60 → 1,000日76 → 1,100日80 → 3,600日205。毎日のログイン1コインは変更しない。

## 特典交換必要コインの丸め

単価ごとに **1の位を切り上げて10コイン単位** にする。`Math.ceil(raw / 10) * 10`（Dartも同じ）。例えば1時間のエンドカード67→70、1日286→290、1週2163→2170。全特典12種類の時間/日/週/月単価に適用し、もともと10コイン単位の月額などは据え置く。期間が複数単位なら、丸め済み単価 × 単位数。

正式なPremium 1か月交換はサーバーの承認見積もりが必要であり、価格設定も10コイン単位を必須とする。参考価格は正式オファーを起動しない。

## 維持するもの

- リワード広告1回10コイン、広告の暫定1日1回の設定。
- 認証済み・サーバー検証による不正防止、重複受取防止、運営承認まで本番付与を停止する仕組み。
- 特典の月額基本価格・特典種類および正式な交換の別途承認。
