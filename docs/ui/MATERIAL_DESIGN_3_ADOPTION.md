# Material Design 3 adoption — NIARIM app

The local skill is a UI design/review guide, not a blanket redesign authorization. Preserve existing NIARIM visual identity, behavior, approved specs and localization.

**Specialist creation surfaces:** canvas, timeline, frame strip, layer panels, brush controls and animation workflows remain purpose-built. Do not replace them wholesale with generic M3 controls/cards. Balance touch-target guidance with precision drawing and timeline input; verify reach, gesture conflicts, keyboard/DeX and screen-reader semantics. Use semantic theme roles where compatible; no runtime package is required to install this skill. Adapt tablet/DeX layouts structurally. Expressive styling and motion are optional and restrained.

For UI work: classify conventional vs creation UI; read the relevant skill guidance; preserve features/translations; inspect compact phone/tablet/expanded windows; review empty/loading/error/disabled/selected/focus states; run scoped tests/lint/analyze and capture screens when appropriate. Report applied principles, exceptions and verified checks.
