# 確定仕様: 横方向反復・縁取り・折り返し・定規スナップ

ユーザー添付「貼り付けたマークダウン（1）(20260916-110058).md」を全文確認した上で、実装と再開に必要な確定要件を保存する。これは通常の機能追加であり、全面監査ではない。仕様内の実装判断は自律的に進め、逐一確認のため停止しない。

## 作業範囲と禁止事項

- `sakurasemaika-creator/NIARIM` の最新 `dev_branch` とAGENTSを基準にする。main変更、force push、他作業の破棄は禁止。
- モデルだけ・UIだけで完了にしない。実描画、入力、保存、複製、ブラシ入出力、プリセット、定規拘束、テスト、描画確認、キャプチャ、Help/Tips/通常仕様書まで含める。
- 全面監査用Route/State/Policyをこの機能追加で読んだり変更したりしない。
- 既存アーキテクチャを尊重し、巨大ファイルへ複雑な計算を詰め込まず小さな責務に分離する。無関係な大規模リファクタリングはしない。
- スマートフォン向け。毎PointerEventでキャンバス全体をCPU走査しない。局所領域、ストローク単位キャッシュ、既存タイル更新を使い、通常ブラシの高速経路を維持する。長いストロークで入力履歴を無制限に蓄積しない。
- 実行していない検証を成功とせず、テストのskip/deleteや仕様の簡略化で完了扱いにしない。

## 横方向反復とネット

- ON/OFF、整数個数1〜10、間隔。モデルconstructor/JSONでも1〜10へclamp。不正値で過剰描画しない。OFFまたはcount1は単列。
- 各地点のストローク接線Tに垂直な局所法線N方向に配置する。固定キャンバスX/Y方向は禁止。奇数・偶数とも中心対称（4列なら中心を挟んで2列ずつ）。曲線で法線へ追従。
- spacing、rotation、density、scatter、筆圧、fade/taper、customImagePath、pixelModeと共存させる。
- 組み込み「ネット」は黒い正方形の内部が正方形に抜けた素材を使い、進行方向反復と横方向反復を実利用する。名前だけの普通ブラシは不可。網・フェンス・格子・窓など規則構造を描けること。
- 水平、垂直、斜め、緩い曲線、急曲線、1/複数/10列、間隔変更の実描画を確認する。

## 縁取りと専用スポイト

- ブラシ詳細へ縁取りON/OFF、幅、色。縁取り色の既定値は完全な黒 `0xFF000000`。
- 内部の塗り色は通常の現在色を使う。Brushへ塗り色を固定保存しない。通常カラーピッカーを恒常的な2色UIへ変更しない。
- 縁取り色はブラシ固有設定。色変更・専用スポイトで現在色を変更しない。OFFの既存ブラシは従来どおり。
- ブラシ詳細にカラーピッカーとスポイトを両方用意する。既存の表示合成色サンプル、画面/文書座標変換、キャンセル、透明色扱いを再利用し、適用先だけ分離する。
- 自然な経路: 詳細→スポイト→キャンバスタップ→縁取り色反映。キャンセルでは色を変更しない。通常スポイトを壊さない。
- 外周と内部の重なりを適切に合成し、カーブ、急角度、スタンプ間、自己交差で内部の隙間や黒い継ぎ目を残さない。塗り色変更、縁取り色/幅変更、両色選択経路を実描画で確認する。

## 折り返しとY字

- 縁取りONのみに従属する折り返しON/OFF。OFFの従属UIは非表示/無効。第三色は追加せず縁取り色で描く。
- 設定: 発生角度、Y枝角、Y長さ%、Y太さ%、Y終点入り抜き範囲%。発生角度の既定値は約90°。
- 急カーブの**内側だけ**にY字を置き、髪束・帯・リボンの重なりを表す。左右どちらでも内側を計算し、画面固定方向や外側へ出さない。
- 隣接2点の角度だけで即発火させない。実移動距離、平滑化した局所接線、短区間の累積方向変化を評価する。
- 判定距離はPointerEvent等のscreen/local logical座標を使う。固定document pxや入力イベント数で判定しない。キャンバス1000/10000px、ズーム倍率、DPI、イベント密度が変わっても同程度の操作感。
- 微細ジッターでは発火させず、意味のある画面距離移動後に設定角度を超えたとき発火する。画面距離ベースcooldown/hysteresisで同一カーブ周辺に大量生成しない。
- 判定は画面空間、Y生成はキャンバス空間へ分離し正しく変換する。
- Y長さ/太さは、その地点の筆圧・入り抜き反映後の実効ブラシ幅との比率で保存する。長さ60%なら幅20で12。固定canvas px保存は禁止。ブラシサイズや筆圧へ追従し、極端にはみ出す値は制限する。
- Y終点入り抜きは各枝長の割合。0%はなし、100%はほぼ全体で細くする。中間値も調整可能。終端に丸いダマを残さない。既存の自然なeaseがあれば使う。
- 枝角変更が見た目に反映され、左右とも正しい内側になること。

## 髪の毛プリセットとUI

- 「髪の毛」は縁取りON/黒、内部は現在色、折り返しON/約90°、筆圧によるサイズ変化/入り抜きON。Y長さ/太さは幅比、終点taperはONの初期値。枝角は実描画で自然な値へ調整。
- 通常線は現在色で塗られた黒外周の髪束、急カーブで内側Yによる折り返しを表現する。
- 細/中/太、弱/強筆圧、左/右/S字、緩い/約90°/90°超/連続急カーブ、入り/抜き、Y長さ/太さ/枝角/taper変更を実描画で確認。
- 既存の折りたたみセクション・編集可能スライダー等を再利用し、長大な雑な設定一覧にしない。狭いスマホ画面でoverflowさせない。

## データと互換性

- Brushへ横反復enabled/count/spacing、outline enabled/width/color、fold enabled/trigger angle、Y branch angle/length ratio/width ratio/end taper ratioを追加する。constructor/defaults/copyWith/JSON/複製/保存/入出力/プリセットを漏れなく更新。
- 内部塗り色は新規保存フィールドにしない。
- 正式リリース前なので不要な大規模migrationを作らない。ただし現存する開発JSON、`.niabrush`、fixture、プロジェクト、既存プリセットを壊さない。
- 新フィールドがなければ横反復OFF/count1、縁取りOFF/黒、折り返しOFF。既存ブラシが勝手に新機能ONにならない。
- `.niabrush`保存→再読込で全設定を保持し、現在存在する旧形式も合理的に読む。

## 定規スナップ

- 定規選択パネルへSwitch等の明確なON/OFFを置く。深い設定画面へ隠さない。色だけで状態を表さない。
- ONは通常の拘束/吸着。OFFは同じ定規を表示し続け、位置/形状/消失点を編集可能なまま、ブラシを自由描画にする。削除と同一視しない。
- 配置→ON描画→OFF自由描画→再ON拘束が同じ定規で可能。OFF後に直線→2点透視等の種類変更をしても勝手にONへ戻さない。
- 既存ライフサイクル/仕様書に沿う場所へ状態を保持し、定規を保存する設計ならスナップも同じ保存経路へ統合する。
- 既存全定規を確認し、ON/OFF/再ON、表示/編集維持、種類変更、保存/復元を検証する。
