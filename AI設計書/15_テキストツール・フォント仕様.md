# 15_テキストツール・フォント仕様

## 基本方針

- テキストは編集可能なテキストオブジェクトとして保持する
- ラスター専用アプリのため、編集時のみ文字情報を保持し、表示時はキャッシュ画像を使用する
- ラスタライズも可能

---

## 作成方法

```
ツールバー → テキスト → キャンバスタップ → 入力 → 配置
```

---

## レイヤー

- テキストレイヤーとして作成される（テキスト1 / テキスト2 / テキスト3 …）
- 通常レイヤーとは別アイコンで表示

---

## 編集可能項目

| 項目 | 内容 |
|------|------|
| 文字内容 | 自由編集 |
| フォント | 一覧から選択 |
| サイズ | スライダー |
| 色 | 通常カラーパレット・スポイト対応 |
| 太字 | ON/OFF |
| 斜体 | ON/OFF（フォント対応時のみ） |
| 行間 | スライダー |
| 文字間隔 | スライダー |
| 横書き・縦書き | 切替 |
| 揃え | 左・中央・右 |

---

## アウトライン（初期実装）

| 項目 | 内容 |
|------|------|
| アウトライン ON/OFF | チェックボックスで切替 |
| アウトライン色 | 自由選択 |
| 太さ | スライダー（0〜20px） |

標準プリセット例：白文字＋黒縁 3px

主な用途：アニメ字幕 / セリフ / タイトル / MV歌詞

---

## フォント

### 初期フォント

- Android標準フォントを使用

### ユーザーフォント追加

```
設定 → フォント管理 → ＋追加
```

対応形式：TTF / OTF

保存場所：アプリ内 Fonts フォルダ

---

## フォント管理

| 機能 | 内容 |
|------|------|
| 一覧表示 | インストール済みフォントを一覧表示 |
| 検索 | フォント名で検索 |
| 追加 | TTF / OTF を追加 |
| 削除 | フォントを削除 |
| 名前変更 | 表示名を変更 |
| 詳細表示 | フォント名・種類・容量を表示 |

---

## エラー表示

| 状況 | メッセージ |
|------|-----------|
| 未対応フォント | 「このフォントは読み込めません。」 |
| 破損フォント | 「フォントが破損しています。」 |

---

## プロジェクト共有

- 「フォントを含める」を選択した場合のみフォントを同梱
- 不足フォントがある場合：「不足フォントがあります。○○.ttf」と表示し再検索を促す

---

## ラスタライズ

```
三点メニュー → ラスタライズ
```

- 通常レイヤーに変換される
- ラスタライズ後は文字情報の編集不可

---

## アニメーション

通常レイヤーと同様に以下に対応：

- 位置
- 回転
- 拡大縮小
- 不透明度

---

## 描画フィルター・演出フィルター

| フィルター種別 | 対応 |
|--------------|------|
| 描画フィルター（現在レイヤー / 現在フォルダ / 参照レイヤー / 選択範囲） | ○ |
| 演出フィルター（フレーム全体） | ○ |

---

## Undo

通常対応。

---

## パフォーマンス

- 編集時のみ文字情報を保持
- 描画時はキャッシュ画像を使用
- アウトラインもキャッシュ化するため毎フレーム再計算しない
- 低スペック端末でも軽量動作

---

## 初回説明・ヘルプ

| タイミング | 内容 |
|-----------|------|
| 初回タップ時 | 「文字を自由に配置できます。フォントや色、アウトラインも変更できます。」 |
| ヘルプページ | GIF付きで機能を説明 |

---

## 初期実装しない機能（将来追加候補）

- ワープ文字
- グラデーション文字
- OpenType高度機能
- 文字ごとのアニメーション
- 縦中横
- ルビ
